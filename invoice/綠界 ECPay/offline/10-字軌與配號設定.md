# 字軌與配號設定

## 應用場景

特店取得財政部配號結果後，需建立當年度或下年度的字軌，並在開立發票前設定字軌區間。

## API 介接資訊

### 介接網址

| 環境 | URL |
|------|-----|
| 測試環境 | https://einvoice-stage.ecpay.com.tw/B2CInvoice/AddInvoiceWordSetting |
| 正式環境 | https://einvoice.ecpay.com.tw/B2CInvoice/AddInvoiceWordSetting |

### 傳輸協定

- **Content Type**：application/json
- **HTTP Method**：POST

## 特店傳入參數 (JSON 格式)

| 參數名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| PlatformID | String | 10 | 否 | 特約合作平台商代號；一般特店請帶空值 |
| MerchantID | String | 10 | 是 | 特店編號 |
| RqHeader | Object | - | 是 | 傳入資料 |
| Timestamp | String | 10 | 是 | 傳入時間 (Unix TimeStamp, GMT+8) |
| Data | String | - | 是 | 加密資料 (JSON 格式) |

### RqHeader 結構

| 參數名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| Timestamp | String | 10 | 是 | 時間戳 (GMT+8) |
| Revision | String | - | 是 | 版本號 |

## Data 參數說明 (JSON 格式)

| 參數名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| MerchantID | String | 10 | 是 | 特店編號 |
| InvoiceTerm | Int | - | 是 | 發票期別 (1-6) |
| InvoiceYear | String | 3 | 是 | 發票年度 (當年/明年) |
| InvType | String | 2 | 是 | 字軌類別 |
| InvoiceCategory | String | 1 | 是 | 發票種類 (固定為 4) |
| InvoiceHeader | String | 2 | 是 | 發票字軌 |
| InvoiceStart | String | 8 | 是 | 起始發票編號 (尾數 00 或 50) |
| InvoiceEnd | String | 8 | 是 | 結束發票編號 (尾數 49 或 99) |
| MachineID | String | 10 | 是 | 發票機台 ID |

### InvoiceTerm 列舉值

| 值 | 說明 |
|----|------|
| 1 | 1-2 月 |
| 2 | 3-4 月 |
| 3 | 5-6 月 |
| 4 | 7-8 月 |
| 5 | 9-10 月 |
| 6 | 11-12 月 |

### InvType 列舉值

| 值 | 說明 |
|----|------|
| 07 | 一般稅額發票 |
| 08 | 特種稅額發票 |

### InvoiceCategory 列舉值

| 值 | 說明 |
|----|------|
| 4 | 離線發票 |

## 特店傳入參數範例

```json
{
    "MerchantID": "2000132",
    "RqHeader": {
        "Timestamp": "1525168923",
        "Revision": "1.0.0"
    },
    "Data": "加密資料"
}
```

## Data 參數範例

```json
{
    "MerchantID": "2000132",
    "InvoiceTerm": "1",
    "InvoiceYear": "109",
    "InvType": "07",
    "InvoiceCategory": "4",
    "InvoiceHeader": "TW",
    "InvoiceStart": "10000000",
    "InvoiceEnd": "10000049",
    "MachineID": "A123345"
}
```

## 綠界回傳參數 (JSON 格式)

| 參數名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| PlatformID | String | 10 | 特約合作平台商代號 |
| MerchantID | String | 10 | 特店編號 |
| RpHeader | Object | - | 傳入資料 |
| Timestamp | String | 10 | 傳入時間 |
| TransCode | Int | - | 回傳代碼 (1 = 成功) |
| TransMsg | String | 200 | 回傳訊息 |
| Data | String | - | 加密資料 (JSON 格式) |

### RpHeader 結構

| 參數名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| Timestamp | String | 10 | 時間戳 (GMT+8) |

## 綠界回傳參數範例

```json
{
    "MerchantID": "2000132",
    "RpHeader": {
        "Timestamp": "1525169058"
    },
    "TransCode": 1,
    "TransMsg": "",
    "Data": "加密資料"
}
```

## 回傳 Data 參數 (JSON 格式)

| 參數名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| RtnCode | Int | - | 回應代碼 (1 = 成功) |
| RtnMsg | String | 200 | 回應訊息 |
| TrackID | String | 10 | 字軌號碼 ID |

## 回傳 Data 參數範例

```json
{
    "RtnCode": 1,
    "RtnMsg": "成功",
    "TrackID": "1234567890"
}
```

## 重要注意事項

1. **號碼分組規則**：電子發票號碼為 50 個一組，起始號尾數須為 00 或 50，結尾號尾數須為 49 或 99。
2. **避免重複設定**：勿於多個發票系統設定相同字軌號碼，以免發票編號重複。
3. **時間驗證**：驗證時間區間為 10 分鐘內有效，逾期 API request 將失敗。
4. **字軌狀態**：新增字軌後，狀態預設為已審核通過且會自動啟用一組字軌。
5. **參數加密**：Data 參數需進行加密，詳見加密方法說明文件。
