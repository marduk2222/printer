# 查詢財政部配號結果

## 應用場景

特店可透過 API 查詢財政部整合服務平台授權於綠界之發票號碼配號結果。

## API 介接網址

| 環境 | URL |
|------|-----|
| 正式環境 | https://einvoice.ecpay.com.tw/B2CInvoice/GetGovInvoiceWordSetting |
| 測試環境 | https://einvoice-stage.ecpay.com.tw/B2CInvoice/GetGovInvoiceWordSetting |

## HTTPS 傳輸協定

- **Content Type**：application/json
- **HTTP Method**：POST

## 特店傳入參數 (JSON 格式)

| 參數名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| PlatformID | String | 10 | 否 | 特約合作平台商代號。一般特店或賣家身分請帶空值；若隸屬平台商則帶平台商的 MerchantID |
| MerchantID | String | 10 | 是 | 特店編號 |
| RqHeader | Object | - | 是 | 傳入資料 |
| Timestamp | String | 10 | 是 | 傳入時間 (GMT+8 時間戳)，驗證時間區間為 10 分鐘內有效 |
| Data | String | - | 是 | 加密資料 (加密過 JSON 格式) |

## Data 參數 (JSON 格式)

| 參數名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| MerchantID | String | 10 | 是 | 特店編號 |
| InvoiceYear | String | 3 | 是 | 發票年度 (民國年格式，如 110)，僅可查詢去年、當年與明年 |

## 特店傳入參數範例

```json
{
    "MerchantID": "2000132",
    "RqHeader": {
        "Timestamp": "1525168923",
        "Revision": "1.0.0"
    },
    "Data": "加密資料"
}
```

## Data 參數範例

```json
{
    "MerchantID": "2000132",
    "InvoiceYear": "110"
}
```

## 綠界回傳參數 (JSON 格式)

| 參數名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| PlatformID | String | 10 | 特約合作平台商代號 |
| MerchantID | String | 10 | 特店編號 |
| RpHeader | Object | - | 傳入資料 |
| Timestamp | String | 10 | 傳輸時間 (GMT+8 時間戳) |
| TransCode | Int | - | 回傳代碼，1 代表接收成功 |
| TransMsg | String | 200 | 回傳訊息 |
| Data | String | - | 加密資料 (加密過 JSON 格式) |

## 綠界回傳參數範例

```json
{
    "MerchantID": "2000132",
    "RpHeader": {
        "Timestamp": "1525169058"
    },
    "TransCode": 1,
    "TransMsg": "",
    "Data": "加密資料"
}
```

## 回傳 Data 參數 (JSON 格式)

| 參數名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| RtnCode | Int | - | 回應代碼，1 代表執行成功 |
| RtnMsg | String | 200 | 回應訊息 |
| InvoiceInfo | Array[Object] | - | 發票配號結果清單 |

### InvoiceInfo 物件結構

| 參數名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| InvoiceTerm | Int | - | 發票期別 (1:1-2 月, 2:3-4 月, 3:5-6 月, 4:7-8 月, 5:9-10 月, 6:11-12 月) |
| InvType | String | 2 | 字軌類別 (07: 一般稅額發票, 08: 特種稅額發票) |
| InvoiceHeader | String | 2 | 發票字軌名稱 (如：KK) |
| InvoiceStart | String | 8 | 起始發票編號 (8 碼，尾數需為 00 或 50) |
| InvoiceEnd | String | 8 | 結束發票編號 (8 碼，尾數需為 49 或 99) |
| Number | Int | - | 申請本數 (一本為 50 個發票號碼) |

## 回傳 Data 參數範例

```json
{
    "RtnCode": 1,
    "RtnMsg": "成功",
    "InvoiceInfo": [
        {
            "InvoiceTerm": 1,
            "InvType": "07",
            "InvoiceHeader": "KK",
            "InvoiceStart": "10000000",
            "InvoiceEnd": "10000049",
            "Number": 1
        }
    ]
}
```

## 注意事項

1. 如查無資料，可能的原因為取字軌號碼時並未授權於綠界，或字軌尚未取號完成。
2. 驗證時間區間為 10 分鐘內有效，超過此時間 API request 將無法建立。
3. 特店需進行主機時間校正，避免時差造成 API request 失敗。
