# 上傳作廢發票

## 應用場景

營業人 (特店) 可使用此功能將已作廢的發票傳送至綠界，由綠界將作廢資料上傳至財政部電子發票整合服務平台。

## API 介接網址

| 環境 | 網址 |
|------|------|
| 正式環境 | https://einvoice.ecpay.com.tw/B2CInvoice/OfflineInvalid |
| 測試環境 | https://einvoice-stage.ecpay.com.tw/B2CInvoice/OfflineInvalid |

## HTTPS 傳輸協定

- **Content Type**：application/json
- **HTTP Method**：POST

## 特店傳入參數 (JSON 格式)

| 欄位名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| PlatformID | String | 10 | 否 | 特約合作平台商代號。一般特店或賣家身分，此參數請帶放空值；若隸屬於特約平台商的一般特店，請帶放平台商的 MerchantID |
| MerchantID | String | 10 | 是 | 特店編號 |
| RqHeader | Object | - | 是 | 傳入資料 |
| Timestamp | String | 10 | 是 | 傳入時間 (GMT+8 時間戳)。驗證時間區間為 10 分鐘內有效 |
| Data | String | - | 是 | 加密資料 (加密過 JSON 格式) |

## 特店傳入參數範例

```json
{
    "MerchantID": "2000132",
    "RqHeader": {
        "Timestamp": "1525168923",
        "Revision": "1.0.0"
    },
    "Data": "加密資料"
}
```

## Data 參數說明 (JSON 格式)

| 欄位名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| MerchantID | String | 10 | 是 | 特店編號 |
| InvoiceNo | String | 10 | 是 | 發票號碼 (2 碼字軌+8 碼數字) |
| InvoiceDate | String | 20 | 是 | 發票開立日期 (yyyy-MM-dd) |
| Reason | String | 20 | 是 | 作廢原因 |
| CancelDate | String | 20 | 是 | 發票作廢時間 (yyyy-MM-dd HH:mm:ss) |

## Data 參數範例

```json
{
    "MerchantID": "2000132",
    "InvoiceNo": "UV11100016",
    "InvoiceDate": "2021-01-14",
    "Reason": "發票作廢",
    "CancelDate": "2021-01-15 15:12:03"
}
```

## 綠界回傳參數 (JSON 格式)

| 欄位名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| PlatformID | String | 10 | 特約合作平台商代號 |
| MerchantID | String | 10 | 特店編號 |
| RpHeader | Object | - | 傳入資料 |
| Timestamp | String | 10 | 傳輸時間戳 (GMT+8) |
| TransCode | Int | - | 回傳代碼。1 代表 API 傳輸資料接收成功，實際執行結果狀態請參考 RtnCode |
| TransMsg | String | 200 | 回傳訊息 |
| Data | String | - | 加密資料 (加密過 JSON 格式) |

## 綠界回傳參數範例

```json
{
    "MerchantID": "2000132",
    "RpHeader": {
        "Timestamp": "1525169058"
    },
    "TransCode": 1,
    "TransMsg": "",
    "Data": "加密資料"
}
```

## Data 參數 (回傳，JSON 格式)

| 欄位名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| RtnCode | Int | - | 回應代碼。1 代表 API 執行成功，其餘代碼為失敗，請參考交易訊息代碼表 |
| RtnMsg | String | 200 | 回應訊息 |
| InvoiceNo | String | 10 | 發票號碼。作廢成功則回傳發票號碼；作廢失敗則回傳空值 |

## 回傳 Data 參數範例

```json
{
    "RtnCode": 1,
    "RtnMsg": "成功",
    "InvoiceNo": "KK12345678"
}
```

## 重要注意事項

- 驗證時間區間為 10 分鐘內有效，超過此驗證時間則 API request 將無法建立
- 特店需進行主機「時間校正」，避免產生時差造成 API request 失敗
