# 查詢發票機台

## 應用場景

特店可查詢管理發票機台 API 或廠商後台設定的發票機台資訊。

## API 介接網址

| 環境 | URL |
|------|-----|
| 測試環境 | https://einvoice-stage.ecpay.com.tw/B2CInvoice/QueryOfflineMerchantPosSetting |
| 正式環境 | https://einvoice.ecpay.com.tw/B2CInvoice/QueryOfflineMerchantPosSetting |

## HTTPS 傳輸協定

- **Content Type**：application/json
- **HTTP Method**：POST

## 特店傳入參數 (JSON 格式)

| 欄位名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| PlatformID | String | 10 | 否 | 特約合作平台商代號。一般特店身分請帶空值；若隸屬特約平台商，請帶放平台商的 MerchantID |
| MerchantID | String | 10 | 是 | 特店編號 |
| RqHeader | Object | - | 是 | 傳入資料 |
| Timestamp | String | 10 | 是 | 傳入時間 (Unix TimeStamp, GMT+8)。驗證時間區間為 10 分鐘內有效 |
| Data | String | - | 是 | 加密資料 (加密過的 JSON 格式) |

## Data 參數說明

| 欄位名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| MerchantID | String | 10 | 是 | 特店編號 |

## 特店傳入參數範例

```json
{
    "MerchantID": "2000132",
    "RqHeader": {
        "Timestamp": "1525168923",
        "Revision": "1.0.0"
    },
    "Data": "加密資料"
}
```

## Data 參數範例

```json
{
    "MerchantID": "2000132"
}
```

## 綠界回傳參數 (JSON 格式)

| 欄位名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| PlatformID | String | 10 | 特約合作平台商代號 |
| MerchantID | String | 10 | 特店編號 |
| RpHeader | Object | - | 傳入資料 |
| Timestamp | String | 10 | 傳輸時間 (Unix TimeStamp, GMT+8) |
| TransCode | Int | - | 回傳代碼。1 代表 API 傳輸資料接收成功 |
| TransMsg | String | 200 | 回傳訊息 |
| Data | String | - | 加密資料 (加密過的 JSON 格式) |

## 回傳參數範例

```json
{
    "MerchantID": "2000132",
    "RpHeader": {
        "Timestamp": "1525169058"
    },
    "TransCode": 1,
    "TransMsg": "",
    "Data": "加密資料"
}
```

## 回傳 Data 參數說明

| 欄位名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| RtnCode | Int | - | 回應代碼。1 代表 API 執行成功，其餘為失敗 |
| RtnMsg | String | 200 | 回應訊息 |
| MachineIDList | Array[Object] | - | 發票機台清單 |

### MachineIDList 物件結構

| 欄位名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| MachineID | String | 10 | 發票機台 ID |
| CreateTime | String | 20 | 建立時間 (格式：yyyy/MM/dd HH:mm) |
| Remark | String | 100 | 備註 |

## 回傳 Data 參數範例

```json
{
    "RtnCode": 1,
    "RtnMsg": "成功",
    "MachineIDList": [
        {
            "MachineID": "ABCD",
            "CreateTime": "2021/10/07 10:10:12",
            "Remark": ""
        },
        {
            "MachineID": "EFGH",
            "CreateTime": "2021/10/08 10:10:12",
            "Remark": ""
        }
    ]
}
```

## 重要注意事項

- 驗證時間區間為 10 分鐘內有效，若超過此驗證時間則此次 API request 將無法建立
- 特店需進行主機「時間校正」，避免主機產生時差，造成 API request 失敗
- 失敗代碼請參考交易訊息代碼表
- 加密方法詳見參數加密方式說明文件
