# 上傳開立發票

## 應用場景

特店開立發票後，需將發票上傳至綠界並由綠界代為上傳至財政部電子發票平台。

## 重要注意事項

- 依據財政部之規定，請於開立發票 48 小時內上傳發票
- 發票資料內容主要由廠商傳送，請確認發票資料的正確性之後再進行上傳

## API 介接網址

| 環境 | 網址 |
|------|------|
| 正式環境 | https://einvoice.ecpay.com.tw/B2CInvoice/OfflineIssue |
| 測試環境 | https://einvoice-stage.ecpay.com.tw/B2CInvoice/OfflineIssue |

## HTTPS 傳輸協定

- Content Type：application/json
- HTTP Method：POST

## 特店傳入參數 (JSON 格式)

| 欄位名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| PlatformID | String | 10 | 否 | 特約合作平台商代號。一般特店請帶放空值；若隸屬平台商，帶放平台商的 MerchantID |
| MerchantID | String | 10 | 是 | 特店編號 |
| RqHeader | Object | - | 是 | 傳入資料 |
| Timestamp | String | 10 | 是 | 傳入時間，轉換為時間戳 (GMT+8)，驗證時間區間為 10 分鐘內有效 |
| Data | String | - | 是 | 加密資料 (JSON 格式) |

## 特店傳入參數範例

```json
{
    "MerchantID": "2000132",
    "RqHeader": {
        "Timestamp": "1525168923",
        "Revision": "1.0.0"
    },
    "Data": "加密資料"
}
```

## Data 參數說明 (JSON 格式)

| 欄位名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| MerchantID | String | 10 | 是 | 特店編號 |
| MachineID | String | 10 | 是 | 發票機台 ID |
| InvoiceNo | String | 10 | 是 | 發票號碼 (2 碼字軌+8 碼數字) |
| InvoiceDate | String | 20 | 是 | 發票開立日期 (yyyy-MM-dd HH:mm:ss)，不可大於當下上傳時間 |
| RelateNumber | String | 50 | 是 | 特店自訂編號，需為唯一值不可重覆使用，不可使用特殊符號 |
| TaxType | String | 1 | 是 | 課稅類別：1 = 應稅；2 = 零稅率；3 = 免稅；4 = 應稅 (特種稅率)；9 = 混合應稅與免稅或零稅率 |
| ZeroTaxRateReason | String | 2 | 條件 | 零稅率原因 (自 115 年 1 月 1 日起，TaxType 為 2 或 9 時必填)：71-79 分別代表不同零稅率原因 |
| SalesAmount | Int | 12 | 是 | 發票總金額 (含稅)，請帶整數，僅限新台幣 |
| TaxAmount | Number | 11 | 否 | 稅額合計，請帶整數，差距不得超過 1 元；若未填由綠界代為計算 |
| InvType | String | 2 | 是 | 字軌類別：07 = 一般稅額發票；08 = 特種稅額發票 |
| RandomNumber | String | 4 | 是 | 隨機碼 (防偽用)，只限數字，不可使用流水號；建議每萬張發票不可重覆 |
| Items | Array[Object] | - | 是 | 商品 (可多筆，最多支援 200 項) |
| CustomerIdentifier | String | 8 | 否 | 統一編號 |
| CustomerID | String | 20 | 否 | 客戶編號 |
| CustomerName | String | 60 | 否 | 客戶名稱 (中、英文及數字) |
| CustomerAddr | String | 100 | 否 | 客戶地址 |
| CustomerPhone | String | 20 | 否 | 客戶手機號碼 |
| CustomerEmail | String | 80 | 否 | 客戶信箱 |
| ClearanceMark | String | 1 | 條件 | 通關方式 (TaxType=2 時必填)：1 = 非經海關出口；2 = 經海關出口 |
| SpecialTaxType | String | 1 | 條件 | 特種稅額類別：TaxType 為 1/2/9 時帶 0；TaxType 為 3 時帶 8；TaxType 為 4 時帶 1-8 |
| vat | String | 1 | 否 | 商品單價是否含稅 |
| InvoiceRemark | String | 200 | 否 | 發票備註 |
| Print | String | 1 | 是 | 列印註記：0 = 不列印；1 = 要列印 (統一編號或載具有值時) |
| Donation | String | 1 | 是 | 捐贈註記：0 = 不捐贈；1 = 要捐贈 |
| LoveCode | String | 7 | 條件 | 捐贈碼 (捐贈=1 時必填)，3-7 碼阿拉伯數字，首位可為零 |
| CarrierType | String | 1 | 否 | 載具類別：空字串 = 無載具；1 = 綠界電子發票載具；2 = 自然人憑證；3 = 手機條碼；4 = 悠遊卡；5 = 一卡通 |
| CarrierNum | String | 64 | 條件 | 載具編號 (CarrierType=4 或 5 時必填)，帶入實體卡片隱碼 (內碼)，半形字元 |
| CarrierNum2 | String | 64 | 條件 | 第二載具編號 (CarrierType=4 或 5 時必填)，帶入實體卡片顯碼 (外碼)，用於發票查詢識別 |

### Items 參數說明 (商品)

| 欄位名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| ItemSeq | Int | - | 否 | 商品序號 |
| ItemName | String | 500 | 是 | 商品名稱 |
| ItemCount | Number | 8 整數+7 小數 | 是 | 商品數量 |
| ItemWord | String | 6 | 是 | 商品單位 |
| ItemPrice | Number | - | 是 | 商品單價 |
| ItemTaxType | String | 1 | 條件 | 商品課稅別 (TaxType=9 時必填)：1 = 應稅；2 = 零稅率；3 = 免稅 |
| ItemAmount | Number | - | 否 | 商品合計 |
| ItemRemark | String | 120 | 否 | 商品備註 |

> 注意：TaxType=9 時，免稅和零稅率發票不能同時開立，商品課稅類別只能為「應稅+免稅」或「應稅+零稅率」。

## 綠界回傳參數 (JSON 格式)

| 欄位名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|

## 列舉值

### TaxType (課稅類別) 列表

| 代碼 | 說明 |
|------|------|
| 1 | 應稅 |
| 2 | 零稅率 |
| 3 | 免稅 |
| 4 | 應稅 (特種稅率) |
| 9 | 混合應稅與免稅或零稅率時 (限收銀機發票無法分辨時使用，需通過申請核可) |

### ZeroTaxRateReason (零稅率原因) 列表

自 115 年 1 月 1 日起，當課稅類別 [TaxType] 為 2 (零稅率) 或 9 (混合應稅與零稅率) 時必填：

| 代碼 | 說明 |
|------|------|
| 71 | 第一款 外銷貨物 |
| 72 | 第二款 與外銷有關之勞務，或在國內提供而在國外使用之勞務 |
| 73 | 第三款 依法設立之免稅商店銷售與過境或出境旅客之貨物 |
| 74 | 第四款 銷售與保稅區營業人供營運之貨物或勞務 |
| 75 | 第五款 國際間之運輸。但外國運輸事業在中華民國境內經營國際運輸業務者，應以各該國對中華民國國際運輸事業予以相等待遇或免徵類似稅捐者為限 |
| 76 | 第六款 國際運輸用之船舶、航空器及遠洋漁船 |
| 77 | 第七款 銷售與國際運輸用之船舶、航空器及遠洋漁船所使用之貨物或修繕勞務 |
| 78 | 第八款 保稅區營業人銷售與課稅區營業人未輸往課稅區而直接出口之貨物 |
| 79 | 第九款 保稅區營業人銷售與課稅區營業人存入自由港區事業或海關管理之保稅倉庫、物流中心以供外銷之貨物 |
