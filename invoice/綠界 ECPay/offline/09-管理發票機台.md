# 管理發票機台

## 應用場景

設定字軌前必須先至綠界設定開立電子發票的機台資料。

## 傳輸協定

- **Content Type**：application/json
- **HTTP Method**：POST

## API 端點

| 環境 | URL |
|------|-----|
| 測試環境 | https://einvoice-stage.ecpay.com.tw/B2CInvoice/OfflineMerchantPosSetting |
| 正式環境 | https://einvoice.ecpay.com.tw/B2CInvoice/OfflineMerchantPosSetting |

## 特店傳入參數 (JSON 格式)

| 欄位名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| PlatformID | String | 10 | 否 | 特約合作平台商代號。一般特店請帶空值；若隸屬平台商則帶平台商 MerchantID |
| MerchantID | String | 10 | 是 | 特店編號 |
| RqHeader | Object | - | 是 | 傳入資料 |
| Timestamp | String | 10 | 是 | 傳入時間戳 (GMT+8)，驗證有效期 10 分鐘 |
| Data | String | - | 是 | 加密資料 (加密過 JSON 格式) |

## 特店傳入參數範例

```json
{
    "MerchantID": "2000132",
    "RqHeader": {
        "Timestamp": "1525168923",
        "Revision": "1.0.0"
    },
    "Data": "加密資料"
}
```

## Data 參數 (JSON 格式)

| 欄位名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| ActionType | Int | - | 是 | 管理功能類別：1 = 新增、2 = 修改、3 = 刪除 |
| MachineID | String | 10 | 否 | 發票機台 ID；已設定字軌配號時無法修改或刪除 |
| Remark | String | 100 | 否 | 備註 |

## Data 參數範例

```json
{
    "ActionType": 1,
    "MachineID": "ABCD"
}
```

## 綠界回傳參數 (JSON 格式)

| 欄位名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| PlatformID | String | 10 | 特約合作平台商代號 |
| MerchantID | String | 10 | 特店編號 |
| RpHeader | Object | - | 傳入資料 |
| Timestamp | String | 10 | 傳輸時間戳 (GMT+8) |
| TransCode | Int | - | 回傳代碼 (1 = 接收成功) |
| TransMsg | String | 200 | 回傳訊息 |
| Data | String | - | 加密資料 (加密過 JSON 格式) |

## 回傳參數範例

```json
{
    "MerchantID": "2000132",
    "RpHeader": {
        "Timestamp": "1525169058"
    },
    "TransCode": 1,
    "TransMsg": "",
    "Data": "加密資料"
}
```

## 回傳 Data 參數 (JSON 格式)

| 欄位名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| RtnCode | Int | - | 回應代碼 (1 = 成功，其餘為失敗) |
| RtnMsg | String | 200 | 回應訊息 |

## 回傳 Data 參數範例

```json
{
    "RtnCode": "1",
    "RtnMsg": "成功"
}
```

## 重要注意事項

- 驗證時間區間為 10 分鐘內有效，若超過此驗證時間則此次 API request 將無法建立。
- 特店需進行主機時間校正，避免產生時差。
- 勿使用特殊符號作為機台 ID。
- 機台已設定字軌配號時無法進行修改 ID 與刪除操作。
