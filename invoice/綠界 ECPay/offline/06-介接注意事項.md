# 介接注意事項

## 呼叫綠界 API 注意事項

1. **防火牆設定**：需確保伺服器防火牆未阻擋回傳通知
2. **連接協議**：僅支持 HTTPS 443 埠，需使用合法 DNS
3. **傳送方式**：必須採用 Http POST 方式
4. **伺服器埠口**：確認支援 HTTP 80 及 HTTPS 443 埠
5. **金鑰安全**：不得將 HashKey、HashIV 存放於前端代碼
6. **網址編碼**：回傳網址不支援中文網址，網址參數請使用 punycode 編碼
7. **服務申請**：使用電子發票服務須提出申請
8. **加密通訊**：支援 TLS 1.2 協議
9. **錯誤排除**：HTTP 500 狀態碼可能原因包括資料格式錯誤或加解密失敗
