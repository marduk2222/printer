# 設定字軌號碼狀態

## 應用場景

營業人新增字軌後，預設狀態為已審核且自動啟用。此 API 允許特店在需要時停用、暫停或重新啟用字軌。

## API 端點

| 環境 | URL |
|------|-----|
| 正式 | https://einvoice.ecpay.com.tw/B2CInvoice/UpdateInvoiceWordStatus |
| 測試 | https://einvoice-stage.ecpay.com.tw/B2CInvoice/UpdateInvoiceWordStatus |

## 傳輸設定

- **Content Type**：application/json
- **HTTP Method**：POST
- **Protocol**：HTTPS

## 請求參數 (JSON)

| 參數 | 型態 | 長度 | 必填 | 說明 |
|------|------|------|------|------|
| PlatformID | String | 10 | 否 | 平台商代號；一般特店留空 |
| MerchantID | String | 10 | 是 | 特店編號 |
| RqHeader | Object | - | 是 | 傳入資料物件 |
| Timestamp | String | 10 | 是 | 時間戳 (GMT+8)，驗證時間區間為 10 分鐘內有效 |
| Data | String | - | 是 | 加密資料，為加密過的 JSON 格式內容 |

## Data 參數內容 (JSON)

| 參數 | 型態 | 長度 | 必填 | 說明 |
|------|------|------|------|------|
| MerchantID | String | 10 | 是 | 特店編號 |
| TrackID | String | 10 | 是 | 新增字軌後取得的 TrackID |
| InvoiceStatus | Int | - | 是 | 發票字軌狀態：0 = 停用；1 = 暫停；2 = 啟用 |

## 回應參數 (JSON)

| 參數 | 型態 | 長度 | 說明 |
|------|------|------|------|
| PlatformID | String | 10 | 平台商代號 |
| MerchantID | String | 10 | 特店編號 |
| RpHeader | Object | - | 回傳資料物件 |
| Timestamp | String | 10 | 回傳時間戳 |
| TransCode | Int | - | 傳輸代碼 (1 = 接收成功) |
| TransMsg | String | 200 | 傳輸訊息 |
| Data | String | - | 加密資料 |

## Data 回傳參數 (JSON)

| 參數 | 型態 | 長度 | 說明 |
|------|------|------|------|
| RtnCode | Int | - | 回應代碼 (1 = 執行成功；其他 = 失敗) |
| RtnMsg | String | 200 | 回應訊息 |

## 範例

### 請求範例

```json
{
    "MerchantID": "2000132",
    "RqHeader": {
        "Timestamp": "1525168923",
        "Revision": "1.0.0"
    },
    "Data": "加密資料"
}
```

### Data 內容範例

```json
{
    "MerchantID": "2000123",
    "TrackID": "1234567890",
    "InvoiceStatus": 2
}
```

### 回應範例

```json
{
    "MerchantID": "2000132",
    "RpHeader": {
        "Timestamp": "1525169058"
    },
    "TransCode": 1,
    "TransMsg": "",
    "Data": "加密資料"
}
```

### 回傳 Data 範例

```json
{
    "RtnCode": 1,
    "RtnMsg": "成功"
}
```

## 重要注意事項

- 特店需進行主機時間校正，避免時差導致 API 請求失敗
- 停用狀態設定後，該字軌區間無法上傳發票
- 驗證時間區間限 10 分鐘內，參考資源：http://www.epochconverter.com/
- 加密方式詳見技術文件參數加密說明章節
- 錯誤代碼參考：交易訊息代碼表
