# 查詢字軌

## 應用場景

特店可使用此 API 查詢字軌號碼以及字軌的使用情況。

## API 介接網址

| 環境 | URL |
|------|-----|
| 正式環境 | https://einvoice.ecpay.com.tw/B2CInvoice/GetInvoiceWordSetting |
| 測試環境 | https://einvoice-stage.ecpay.com.tw/B2CInvoice/GetInvoiceWordSetting |

## 傳輸協定

- **Content Type**：application/json
- **HTTP Method**：POST

## 特店傳入參數 (JSON 格式)

| 參數名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| PlatformID | String | 10 | 否 | 特約合作平台商代號。平台商身分或一般特店請帶放空值 |
| MerchantID | String | 10 | 是 | 特店編號 |
| RqHeader | Object | - | 是 | 傳入資料 |
| Timestamp | String | 10 | 是 | 傳入時間 (GMT+8 時間戳) |
| Data | String | - | 是 | 加密資料 (JSON 格式) |

### 特店傳入參數範例

```json
{
  "MerchantID": "2000132",
  "RqHeader": {
    "Timestamp": "1525168923",
    "Revision": "1.0.0"
  },
  "Data": "加密資料"
}
```

## Data 參數說明 (JSON 格式)

| 參數名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| MerchantID | String | 10 | 是 | 特店編號 |
| InvoiceYear | String | 3 | 是 | 發票年度 (民國年)，可查詢去年、當年與明年 |
| InvoiceTerm | Int | - | 是 | 發票期別：0 (全部)、1 (1-2 月)、2 (3-4 月)、3 (5-6 月)、4 (7-8 月)、5 (9-10 月)、6 (11-12 月) |
| UseStatus | Int | - | 是 | 發票字軌狀態：0 (全部)、1 (未啟用-審核通過)、2 (使用中)、3 (已停用)、4 (暫停中)、5 (待審核)、6 (審核不通過) |
| InvoiceCategory | Int | - | 是 | 發票類別：固定填寫 4 (離線發票) |
| InvType | String | 2 | 否 | 字軌類別：07 (一般稅額發票)、08 (特種稅額發票) |
| InvoiceHeader | String | 2 | 否 | 發票字軌 |

### Data 參數範例

```json
{
  "MerchantID": "2000132",
  "InvoiceTerm": 0,
  "InvoiceYear": "109",
  "UseStatus": 1,
  "InvoiceCategory": 4
}
```

## 綠界回傳參數 (JSON 格式)

| 參數名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| PlatformID | String | 10 | 特約合作平台商代號 |
| MerchantID | String | 10 | 特店編號 |
| RpHeader | Object | - | 回傳資料 |
| Timestamp | String | 10 | 回傳時間 (GMT+8 時間戳) |
| TransCode | Int | - | 回傳代碼：1 代表資料接收成功 |
| TransMsg | String | 200 | 回傳訊息 |
| Data | String | - | 加密資料 (JSON 格式) |

### 綠界回傳參數範例

```json
{
  "MerchantID": "2000132",
  "RpHeader": {
    "Timestamp": "1525169058"
  },
  "TransCode": 1,
  "TransMsg": "",
  "Data": "加密資料"
}
```

## Data 參數 (JSON 格式) - 回傳資料

| 參數名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| RtnCode | Int | - | 回應代碼：1 為執行成功 |
| RtnMsg | String | 200 | 回應訊息 |
| InvoiceInfo | Array[Object] | - | 發票資訊陣列 |

### InvoiceInfo 物件欄位

| 欄位名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| TrackID | String | 10 | 字軌號碼 ID |
| InvoiceYear | String | 3 | 發票年度 |
| InvoiceTerm | Int | - | 發票期別：1 (1-2 月)、2 (3-4 月)、3 (5-6 月)、4 (7-8 月)、5 (9-10 月)、6 (11-12 月) |
| InvoiceCategory | Int | - | 發票類別：4 (離線發票) |
| InvType | String | 2 | 字軌類別：07 (一般稅額發票)、08 (特種稅額發票) |
| InvoiceHeader | String | 2 | 發票字軌 |
| InvoiceStart | String | 8 | 起始發票編號 |
| InvoiceEnd | String | 8 | 結束發票編號 |
| InvoiceNo | String | 8 | 目前已使用號碼 |
| UseStatus | Int | - | 使用狀態：1 (未啟用)、2 (使用中)、3 (已停用)、4 (暫停中)、5 (待審核)、6 (審核不通過) |
| MachineID | String | 10 | 發票機台 ID |
| ProductServiceId | String | 10 | 產品服務別代號 (由 A-Z、a-z、0-9 組成，長度 1-10 字符) |

## 時間戳驗證注意事項

- 驗證時間區間為 10 分鐘內有效，超過此驗證時間則 API request 將無法建立
- 特店需進行主機時間校正，避免主機時差造成 API request 失敗
