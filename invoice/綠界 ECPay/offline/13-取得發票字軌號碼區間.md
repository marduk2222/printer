# 取得發票字軌號碼區間

## 應用場景

此 API 用於取得發票字軌號碼，以區間形式回傳，包含字軌及發票起訖號碼。特店若僅需了解可開立的字軌區間並自行組成電子發票內容，可選用此 API。

## API 介接網址

| 環境 | URL |
|------|-----|
| 正式環境 | https://einvoice.ecpay.com.tw/B2CInvoice/GetOfflineInvoiceWordSetting |
| 測試環境 | https://einvoice-stage.ecpay.com.tw/B2CInvoice/GetOfflineInvoiceWordSetting |

## 傳輸協定

- **Content Type**：application/json
- **HTTP Method**：POST

## 特店傳入參數 (JSON 格式)

| 欄位名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| PlatformID | String | 10 | 否 | 特約合作平台商代號；一般特店或平台商本身請帶放空值 |
| MerchantID | String | 10 | 是 | 特店編號 |
| RqHeader | Object | - | 是 | 傳入資料 |
| Timestamp | String | 10 | 是 | 傳入時間戳 (GMT+8)，驗證時間區間為 10 分鐘內有效 |
| Data | String | - | 是 | 加密資料 (JSON 格式) |

### 傳入參數範例

```json
{
    "MerchantID": "2000132",
    "RqHeader": {
        "Timestamp": "1525168923",
        "Revision": "1.0.0"
    },
    "Data": "加密資料"
}
```

## Data 參數說明 (JSON 格式)

| 欄位名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| MerchantID | String | 10 | 是 | 特店編號 |
| InvoiceYear | String | 3 | 是 | 發票年度（僅可設定當年與明年） |
| InvoiceTerm | Int | - | 是 | 發票期別（不可帶入小於當年期別） |
| InvoiceStatus | Int | - | 是 | 發票字軌狀態 |
| MachineID | String | 10 | 是 | 發票機台 ID |

### InvoiceTerm 列舉值

| 值 | 說明 |
|----|------|
| 1 | 1-2 月 |
| 2 | 3-4 月 |
| 3 | 5-6 月 |
| 4 | 7-8 月 |
| 5 | 9-10 月 |
| 6 | 11-12 月 |

### InvoiceStatus 列舉值

| 值 | 說明 |
|----|------|
| 1 | 啟用 |
| 2 | 備用字軌 |

### Data 參數範例

```json
{
    "MerchantID": "2000132",
    "InvoiceYear": "109",
    "InvoiceTerm": 1,
    "InvoiceStatus": 1,
    "MachineID": "A123456"
}
```

## 綠界回傳參數 (JSON 格式)

| 欄位名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| PlatformID | String | 10 | 特約合作平台商代號 |
| MerchantID | String | 10 | 特店編號 |
| RpHeader | Object | - | 傳入資料 |
| Timestamp | String | 10 | 傳入時間戳 (GMT+8) |
| TransCode | Int | - | 回傳代碼 (1 代表 API 傳輸資料接收成功，實際執行結果參考 RtnCode) |
| TransMsg | String | 200 | 回傳訊息 |
| Data | String | - | 加密資料 (JSON 格式) |

### 綠界回傳參數範例

```json
{
    "MerchantID": "2000132",
    "RpHeader": {
        "Timestamp": "1525169058"
    },
    "TransCode": 1,
    "TransMsg": "",
    "Data": "加密資料"
}
```

## Data 參數 (回傳，JSON 格式)

| 欄位名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| RtnCode | Int | - | 回應代碼 (1 代表成功，其餘為失敗，參考交易訊息代碼表) |
| RtnMsg | String | 200 | 回應訊息 |
| InvoiceHeader | String | 2 | 發票字軌 |
| InvoiceStart | String | 8 | 起始發票編號 |
| InvoiceEnd | String | 8 | 結束發票編號 |
| InvoiceStatus | Int | - | 發票字軌狀態：1 (啟用)、2 (備用字軌) |
| Times | Int | - | 已取用次數（相同字軌） |

### 回傳 Data 參數範例

```json
{
    "RtnCode": 1,
    "RtnMsg": "成功",
    "InvoiceHeader": "AA",
    "InvoiceStart": "10000000",
    "InvoiceEnd": "10000049",
    "InvoiceStatus": 1,
    "Times": 1
}
```

## 重要注意事項

- 時間驗證區間為 10 分鐘內有效
- 特店需進行主機「時間校正」，避免時差造成 API 失敗
- 加密方法詳見技術文件相關章節
