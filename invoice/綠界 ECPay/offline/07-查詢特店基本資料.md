# 查詢特店基本資料

## 應用場景

透過 API 查詢特店基本資訊。

## API 端點

| 環境 | URL |
|------|-----|
| 測試 | https://einvoice-stage.ecpay.com.tw/B2CInvoice/GetOfflineMerchantInfo |
| 正式 | https://einvoice.ecpay.com.tw/B2CInvoice/GetOfflineMerchantInfo |

## 傳輸規格

- **Protocol**：HTTPS
- **Content Type**：application/json
- **HTTP Method**：POST

## 請求參數 (JSON 格式)

| 欄位 | 型別 | 長度 | 必填 | 說明 |
|------|------|------|------|------|
| PlatformID | String | 10 | 否 | 特約合作平台商代號，一般特店請留空 |
| MerchantID | String | 10 | 是 | 特店編號 |
| RqHeader | Object | - | 是 | 傳入資料物件 |
| Timestamp | String | 10 | 是 | 時間戳 (GMT+8)，驗證區間 10 分鐘內有效 |
| Data | String | - | 是 | 加密 JSON 資料 |

## 請求範例

```json
{
  "MerchantID": "2000132",
  "RqHeader": {
    "Timestamp": "1525168923",
    "Revision": "1.0.0"
  },
  "Data": "加密資料"
}
```

## 回傳參數 (JSON 格式)

| 欄位 | 型別 | 長度 | 說明 |
|------|------|------|------|
| RtnCode | Int | - | 執行代碼，1 為成功，其餘為失敗 |
| RtnMsg | String | 200 | 執行訊息 |
| MerchantName | String | 20 | 特店名稱 |
| MerchantIdentifier | String | 8 | 特店統一編號 |

## 回傳範例

```json
{
  "RtnCode": 1,
  "RtnMsg": "成功",
  "MerchantName": "綠界STAGE測試股份有限公司",
  "MerchantIdentifier": "53538851"
}
```
