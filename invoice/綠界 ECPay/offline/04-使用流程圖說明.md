# 使用流程圖說明

## 主要流程步驟

1. **查詢財政部配號結果** — 透過 API 取得配號結果
2. **管理發票機台** — 設定機台 ID
3. **設定字軌與配號** — 設定號碼區間並記錄 TrackID
4. **開始開立發票**，包含四個子步驟：
   - 取得啟用中的字軌號碼區間
   - 字軌用完時啟用備用字軌
   - 重複上述步驟
   - 注意字軌狀態變更規則
