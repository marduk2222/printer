# 發送發票通知 (離線)

## 應用場景

此 API 用於發送開立發票通知。若不使用此 API，亦可透過廠商後台功能處理。

> 注意事項：測試環境下綠界不會主動發送任何通知，使用廠商後台補發通知功能也不會通知。

## API 介接網址

| 環境 | URL |
|------|-----|
| 測試環境 | https://einvoice-stage.ecpay.com.tw/B2CInvoice/InvoiceNotify |
| 正式環境 | https://einvoice.ecpay.com.tw/B2CInvoice/InvoiceNotify |

## HTTPS 傳輸協定

- **Content Type**：application/json
- **HTTP Method**：POST

## 特店傳入參數 (JSON 格式)

| 欄位名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| PlatformID | String | 10 | 否 | 特約合作平台商代號。一般特店或賣家身分，此參數請帶放空值；若隸屬於特約平台商的一般特店，請帶放平台商的 MerchantID |
| MerchantID | String | 10 | 是 | 特店編號 |
| RqHeader | Object | - | 是 | 傳入資料 |
| RqHeader.Timestamp | Number | - | 是 | 傳入時間（時間戳 GMT+8）。驗證時間區間為 10 分鐘內有效 |
| Data | String | - | 是 | 加密資料（加密過的 JSON 格式） |

### 特店傳入參數範例

```json
{
  "MerchantID": "2000132",
  "RqHeader": {
    "Timestamp": 1525168923
  },
  "Data": "加密資料"
}
```

## Data 參數說明 (JSON 格式)

> 請先將 JSON 字串進行 urlencode 後再進行 AES 加密

| 欄位名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| MerchantID | String | 10 | 是 | 特店編號 |
| InvoiceNo | String | 10 | 是 | 發票號碼（固定 10 碼） |
| Phone | String | 20 | 條件 | 發送簡訊號碼（數字格式）。與 NotifyMail 擇一選填 |
| NotifyMail | String | 200 | 條件 | 發送電子郵件。與 Phone 擇一選填；可帶入多組 Email，以分號區隔（如：aa@aa.aa;bb@bb.bb） |
| Notify | String | 1 | 是 | 發送方式：S（簡訊）、E（電子郵件）、A（皆通知） |
| InvoiceTag | String | 2 | 是 | 發送內容類型：OI（發票開立） |
| Notified | String | 1 | 是 | 發送對象：C（客戶）、M（特店）、A（皆發送） |

### Data 參數範例

```json
{
  "MerchantID": 2000132,
  "InvoiceNo": "UV11100016",
  "Phone": "0912345678",
  "NotifyMail": "test@ecpay.com.tw",
  "Notify": "E",
  "InvoiceTag": "OI",
  "Notified": "A"
}
```

## 綠界回傳參數 (JSON 格式)

| 欄位名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| PlatformID | String | 10 | 特約合作平台商代號 |
| MerchantID | String | 10 | 特店編號 |
| RpHeader | Object | - | 回傳資料 |
| RpHeader.Timestamp | Number | - | 回傳時間（Unix timestamp GMT+8） |
| TransCode | Int | - | 回傳代碼：1 代表 API 傳輸資料接收成功，實際執行結果請參考 RtnCode |
| TransMsg | String | 200 | 回傳訊息 |
| Data | String | - | 加密資料（加密過的 JSON 格式） |

### 綠界回傳參數範例

```json
{
  "MerchantID": "2000132",
  "RpHeader": {
    "Timestamp": 1525169058
  },
  "TransCode": 1,
  "TransMsg": "",
  "Data": "加密資料"
}
```

## Data 參數說明 (回傳)

> 請先將 Data 進行 AES 解密後再做 urldecode

| 欄位名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| RtnCode | Int | - | 回應代碼：1 代表 API 執行成功，其餘代碼均為失敗 |
| RtnMsg | String | 200 | 回應訊息 |
| MerchantID | String | 10 | 特店編號 |

### Data 參數範例

```json
{
  "MerchantID": 2000132,
  "RtnMsg": "發送通知成功",
  "RtnCode": 1
}
```
