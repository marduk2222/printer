# B2B 電子發票 API - 作廢發票確認

## 應用場景

本 API 用於特店收到作廢發票訊息後，傳送確認參數給綠界科技。綠界於隔日上傳至財政部平台，完成發票作廢交換。

## API 介接網址

| 環境 | URL |
|------|-----|
| 測試環境 | https://einvoice-stage.ecpay.com.tw/B2BInvoice/InvalidConfirm |
| 正式環境 | https://einvoice.ecpay.com.tw/B2BInvoice/InvalidConfirm |

## 特店 Request 參數

| 欄位名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| PlatformID | String | 10 | 否 | 特約合作平台商代號，一般廠商放空值 |
| MerchantID | String | 10 | 是 | 特店編號 |
| RqHeader.Timestamp | Number | - | 是 | Unix TimeStamp，驗證時間區間為 10 分鐘內 |
| Data | String | - | 是 | 加密的 JSON 格式資料 |

## Data 加密參數

| 欄位名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| MerchantID | String | 10 | 是 | 特店編號 |
| InvoiceNumber | String | 10 | 是 | 發票號碼 |
| InvoiceDate | String | 20 | 是 | 發票開立日期（yyyy-mm-dd） |
| Remark | String | 200 | 否 | 備註 |

## Request 範例

```json
{
    "MerchantID": "2000132",
    "RqHeader": {
        "Timestamp": "1525168923"
    },
    "Data": "…"
}
```

Data 內容範例：

```json
{
    "MerchantID": "2000132",
    "InvoiceNumber": "VG11000002",
    "InvoiceDate": "2019/09/22",
    "Remark": ""
}
```

## 綠界 Response 參數

| 欄位名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| PlatformID | String | 10 | 特約合作平台商代號 |
| MerchantID | String | 10 | 特店編號 |
| RpHeader.Timestamp | Number | - | 回傳時間（Unix timestamp） |
| TransCode | Int | - | 回傳代碼，1 表示接收成功 |
| TransMsg | String | 200 | 回傳訊息 |
| Data | String | - | 加密的 JSON 格式資料 |

## Response 範例

```json
{
    "MerchantID": "3002607",
    "RpHeader": {
        "Timestamp": 1234564848
    },
    "TransCode": 1,
    "TransMsg": "Success",
    "Data": "…"
}
```

Data 解密後範例：

```json
{
    "RtnCode": 1,
    "RtnMsg": "新增成功"
}
```

## 回應代碼說明

| RtnCode | 說明 |
|---------|------|
| 1 | 成功 |
| 其他 | 失敗 |
