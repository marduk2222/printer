# B2B 電子發票 API - 交易對象維護

## 應用場景

B2B 電子發票分為交換與存證模式，在串接此規格文件前，必須先用此 API 設定交易對象（買方、賣方或買賣方）。

## API 端點

| 環境 | URL |
|------|-----|
| 測試環境 | https://einvoice-stage.ecpay.com.tw/B2BInvoice/MaintainMerchantCustomerData |
| 正式環境 | https://einvoice.ecpay.com.tw/B2BInvoice/MaintainMerchantCustomerData |

## 主要參數

Request 層級（JSON 格式）包括 MerchantID、RqHeader（含 Timestamp）與加密 Data。

### Data 參數關鍵欄位

| 欄位 | 型別 | 說明 |
|------|------|------|
| Identifier | String(8) | 統一編號，必填，固定 8 碼數字 |
| type | Int | 交易對象：1=買方、2=賣方、3=買賣方 |
| ExchangeMode | Int | 開立模式：0=存證、1=交換 |
| EmailAddress | String | 電子信箱，支援多個以分號分隔 |

## Response 結構

返回值包含 RtnCode（1=成功）與相應訊息，數據採 JSON 加密格式。

完整參數表（含長度、必填、說明、預設值）請至 https://developers.ecpay.com.tw/14830/ 查看。
