# B2B 電子發票 API - 查詢作廢折讓發票

## 應用場景

特店可使用此 API 查詢已作廢折讓發票資訊。根據財政部規定，只有買方可以上傳作廢折讓發票。

## API 介接網址

| 環境 | URL |
|------|-----|
| 測試環境 | https://einvoice-stage.ecpay.com.tw/B2BInvoice/GetAllowanceInvalid |
| 正式環境 | https://einvoice.ecpay.com.tw/B2BInvoice/GetAllowanceInvalid |

## 特店 Request 參數說明

| 欄位名稱 | 型別 | 長度 | 必填 | 說明 | 預設值 |
|---------|------|------|------|------|--------|
| PlatformID | String | 10 | 否 | 特約合作平台商代號 | 空值 |
| MerchantID | String | 10 | 是 | 特店編號 | - |
| RqHeader | Object | - | 是 | 傳入資料 | - |
| RqHeader.Timestamp | Number | - | 是 | 傳入時間（Unix TimeStamp） | - |
| Data | String | - | 是 | 加密資料（JSON 格式） | - |

### Request 參數範例

```json
{
  "MerchantID": "2000132",
  "RqHeader": {
    "Timestamp": 1234567890
  },
  "Data": "…"
}
```

## Data 參數說明（加密前）

| 欄位名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| MerchantID | String | 10 | 是 | 特店編號 |
| AllowanceNo | String | 16 | 是 | 綠界折讓編號（固定 16 碼） |

### Data 參數範例

```json
{
  "MerchantID": "2000132",
  "AllowanceNo": "1909241702402030"
}
```

## 綠界 Response 參數說明

| 欄位名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| PlatformID | String | 10 | 特約合作平台商代號 |
| MerchantID | String | 10 | 特店編號 |
| RpHeader | Object | - | 回傳資料 |
| RpHeader.Timestamp | Number | - | 回傳時間（Unix timestamp） |
| TransCode | Int | - | 回傳代碼（1=成功） |
| TransMsg | String | 200 | 回傳訊息 |
| Data | String | - | 加密資料（JSON 格式） |

### Response 參數範例

```json
{
  "MerchantID": "2000132",
  "RpHeader": {
    "Timestamp": "1525169058"
  },
  "TransCode": 1,
  "TransMsg": "",
  "Data": "…"
}
```

## Data 解密後參數說明

| 欄位名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| RtnCode | Int | - | 回應代碼（1=成功） |
| RtnMsg | String | 200 | 回應訊息 |
| RtnData | String | - | 回應資料 |

### Data 解密後參數範例

```json
{
  "RtnCode": 1,
  "RtnMsg": "查詢成功",
  "RtnData": "…"
}
```

## RtnData 參數說明

| 欄位名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| MerchantID | String | 10 | 特店編號 |
| AllowanceNo | String | 16 | 綠界折讓編號（固定 16 碼） |
| AllowanceNumber | String | 16 | 廠商折讓單號碼 |
| SellerId | String | 8 | 賣方統編 |
| BuyerId | String | 8 | 買方統編 |
| CancelDate | String | 20 | 作廢日期（yyyy-mm-dd） |
| CancelReason | String | 20 | 作廢原因 |
| Upload_Status | String | 1 | 上傳狀態（0=未上傳、1=已上傳、2=上傳失敗） |
| Upload_Date | String | 20 | 上傳時間（yyyy-mm-dd） |
| ExchangeStatus | String | 1 | 發票確認狀態（0=未確認、1=已確認） |
| Remark | String | 200 | 備註 |

### RtnData 參數範例

```json
{
  "MerchantID": "200132",
  "AllowanceNo": "1909241702402030",
  "AllowanceNumber": "19092234024023330",
  "SellerId": "23165448",
  "BuyerId": "",
  "CancelDate": "2019-09-25",
  "CancelReason": "",
  "Upload_Status": "",
  "Upload_Date": "null",
  "ExchangeStatus": "1",
  "Remark": ""
}
```

## 注意事項

- 驗證時間區間為 10 分鐘內有效
- 請在加密前對參數值進行 URLEncode
- Upload_Status 和 Upload_Date 在 B2B 發票種類為 0 時不顯示
- ExchangeStatus 若為空值表示未設定
