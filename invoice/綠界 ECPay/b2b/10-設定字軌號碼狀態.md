# B2B 電子發票 API - 設定字軌號碼狀態

## 應用場景

營業人新增字軌後，系統預設為「已審核且未啟用」狀態。如欲使用字軌，必須先設定狀態將字軌啟用。在開立發票之前，必須先將已新增完成的字軌做狀態的設定。

## API 端點

| 環境 | URL |
|------|-----|
| 測試環境 | https://einvoice-stage.ecpay.com.tw/B2BInvoice/UpdateInvoiceWordStatus |
| 正式環境 | https://einvoice.ecpay.com.tw/B2BInvoice/UpdateInvoiceWordStatus |

## Request 參數規格

### 主層級參數（JSON）

| 參數名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| PlatformID | String | 10 | 否 | 特約合作平台商代號，一般廠商請放空值 |
| MerchantID | String | 10 | 是 | 特店編號 |
| RqHeader | Object | - | 是 | 傳入資料容器 |
| Data | String | - | 是 | 加密過的 JSON 格式資料 |

### RqHeader 物件參數

| 參數名稱 | 型別 | 必填 | 說明 |
|---------|------|------|------|
| Timestamp | Number | 是 | 傳入時間戳（GMT+8 Unix TimeStamp） |

時間驗證注意事項：驗證時間區間暫訂為 10 分鐘內有效，若超過此驗證時間則此次訂單將無法建立。

### Data 加密資料內容（JSON）

| 參數名稱 | 型別 | 長度 | 必填 | 說明 | 預設值 |
|---------|------|------|------|------|--------|
| MerchantID | String | 10 | 是 | 特店編號 | - |
| TrackID | String | 10 | 是 | 字軌號碼 ID（新增字軌後取得） | - |
| InvoiceStatus | Int | - | 是 | 發票字軌狀態 | - |

#### InvoiceStatus 狀態值

- `0`: 停用
- `1`: 暫停
- `2`: 啟用

備註：如狀態設定為停用，該字軌區間無法上傳發票。

### Request 範例

外層 JSON 範例：

```json
{
  "MerchantID": "2000132",
  "RqHeader": {
    "Timestamp": 1234567890
  },
  "Data": "…"
}
```

Data 加密內容範例：

```json
{
  "MerchantID": "2000123",
  "TrackID": "1234567890",
  "InvoiceStatus": 2
}
```

## Response 參數規格

### 主層級參數（JSON）

| 參數名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| PlatformID | String | 10 | 特約合作平台商代號 |
| MerchantID | String | 10 | 特店編號 |
| RpHeader | Object | - | 回傳資料容器 |
| TransCode | Int | - | 回傳代碼 |
| TransMsg | String | 200 | 回傳訊息 |
| Data | String | - | 加密過的 JSON 格式資料 |

### RpHeader 物件參數

| 參數名稱 | 型別 | 說明 |
|---------|------|------|
| Timestamp | Number | 回傳時間戳（Unix Timestamp） |

TransCode 說明：1 代表 API 傳輸資料（MerchantID, RqHeader, Data）接收成功，實際的 API 執行結果狀態請參考 RtnCode。

### Data 加密資料內容（JSON）

| 參數名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| RtnCode | Int | - | 回應代碼（1 為成功，其餘為失敗） |
| RtnMsg | String | 200 | 回應訊息 |

### Response 範例

外層 JSON 範例：

```json
{
  "MerchantID": "3002607",
  "RpHeader": {
    "Timestamp": 1234564848
  },
  "TransCode": 1,
  "TransMsg": "Success",
  "Data": "…"
}
```

Data 加密內容範例：

```json
{
  "RtnCode": 1,
  "RtnMsg": "成功"
}
```
