# B2B 電子發票 API - 交易訊息代碼一覽表

## 抓取狀況

頁面實際內容為一張示意圖（無文字代碼表），未在 HTML 中提供完整代碼清單。

## 頁面說明

頁面提供「交易狀態代碼查詢示意圖」並指示：

> 因錯誤代碼一直在新增，詳細的錯誤代碼，請到廠商後台 → 電子發票 → 系統開發管理 → 錯誤代碼查詢

## 取得完整錯誤代碼方式

1. 登入綠界廠商後台（測試環境：https://vendor-stage.ecpay.com.tw、正式環境：https://vendor.ecpay.com.tw）
2. 前往「電子發票 → 系統開發管理 → 錯誤代碼查詢」
3. 在後台動態查詢最新的交易訊息代碼

## 通則

依各 API 章節，回應通常含：

- TransCode：1=API 傳輸成功，其餘為傳輸失敗（請參考 RtnCode）
- RtnCode：1=API 執行成功，其餘為失敗
- RtnMsg：對應的中文訊息

完整訊息對應請至綠界後台查詢。
