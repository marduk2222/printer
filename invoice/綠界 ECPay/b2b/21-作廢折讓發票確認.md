# B2B 電子發票 API - 作廢折讓發票確認

## 應用場景

當特店在開立折讓發票後發現內容錯誤，需要進行作廢折讓時，特店將作廢折讓確認參數傳送給綠界。綠界隔日上傳至財政部電子發票整合服務平台，完成交換並通知交易相對人。

## API 介接網址

| 環境 | URL |
|------|-----|
| 測試環境 | `https://einvoice-stage.ecpay.com.tw/B2BInvoice/CancelAllowanceConfirm` |
| 正式環境 | `https://einvoice.ecpay.com.tw/B2BInvoice/CancelAllowanceConfirm` |

## 特店 Request 參數（JSON 格式）

| 欄位 | 型別 | 必填 | 說明 |
|------|------|------|------|
| PlatformID | String(10) | 否 | 特約合作平台商代號，一般廠商請放空值 |
| MerchantID | String(10) | 是 | 特店編號 |
| RqHeader | Object | 是 | 傳入資料 |
| RqHeader.Timestamp | Number | 是 | 傳入時間（Unix TimeStamp），驗證區間為 10 分鐘內有效 |
| Data | String | 是 | 加密過的 JSON 格式資料 |

### Request 參數範例

```json
{
    "MerchantID": "2000132",
    "RqHeader": {
        "Timestamp": 1234567890
    },
    "Data": "…"
}
```

## Data 參數說明（JSON 格式）

| 欄位 | 型別 | 必填 | 說明 |
|------|------|------|------|
| MerchantID | String(10) | 是 | 特店編號 |
| AllowanceNo | String(16) | 是 | 綠界折讓編號，固定 16 碼 |
| Remark | String(200) | 否 | 備註 |

### Data 參數範例

```json
{
    "MerchantID": "2000132",
    "AllowanceNo": "1909241702402030",
    "Remark": "Cancel_Allowance_Reamrk"
}
```

## 綠界 Response 參數（JSON 格式）

| 欄位 | 型別 | 說明 |
|------|------|------|
| PlatformID | String(10) | 特約合作平台商代號 |
| MerchantID | String(10) | 特店編號 |
| RpHeader | Object | 回傳資料 |
| RpHeader.Timestamp | Number | 回傳時間（Unix timestamp） |
| TransCode | Int | 回傳代碼，1 表示傳輸成功 |
| TransMsg | String(200) | 回傳訊息 |
| Data | String | 加密過的 JSON 格式資料 |

### Response 參數範例

```json
{
    "MerchantID": "3002607",
    "RpHeader": {
        "Timestamp": 1234564848
    },
    "TransCode": 1,
    "TransMsg": "Success",
    "Data": "…"
}
```

## Data 回傳參數說明（JSON 格式）

| 欄位 | 型別 | 說明 |
|------|------|------|
| RtnCode | Int | 回應代碼，1 為成功，其餘為失敗 |
| RtnMsg | String(200) | 回應訊息 |

### Data 回傳參數範例

```json
{
    "RtnCode": 1,
    "RtnMsg": "新增成功"
}
```

## 重要注意事項

- 時間驗證區間為 10 分鐘內有效，超過此時間訂單無法建立
- 特店需進行主機時間校正，避免時差導致 API 無法正常運作
- 加密方法詳見參數加密方式說明文件
