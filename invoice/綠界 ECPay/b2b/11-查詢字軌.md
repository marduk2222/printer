# B2B 電子發票 API - 查詢字軌

## 應用場景

特店系統可使用此 API 查詢字軌號碼以及字軌的使用情況。

## API 端點

| 環境 | URL |
|------|-----|
| 測試 | https://einvoice-stage.ecpay.com.tw/B2BInvoice/GetInvoiceWordSetting |
| 正式 | https://einvoice.ecpay.com.tw/B2BInvoice/GetInvoiceWordSetting |

## Request 參數（JSON 格式）

| 參數名 | 型別 | 長度 | 必填 | 說明 |
|--------|------|------|------|------|
| PlatformID | String | 10 | 否 | 特約合作平台商代號 |
| MerchantID | String | 10 | 是 | 特店編號 |
| RqHeader | Object | - | 是 | 傳入資料物件 |
| RqHeader.Timestamp | Number | - | 是 | 傳入時間（Unix TimeStamp，驗證區間 10 分鐘） |
| Data | String | - | 是 | 加密資料（JSON 格式） |

### Request 範例

```json
{
  "MerchantID": "2000132",
  "RqHeader": {
    "Timestamp": 1234567890
  },
  "Data": "…"
}
```

## Data 參數（加密前）

| 參數名 | 型別 | 長度 | 必填 | 說明 |
|--------|------|------|------|------|
| MerchantID | String | 10 | 是 | 特店編號 |
| InvoiceYear | String | 3 | 是 | 發票年度（民國年，如 111） |
| InvoiceTerm | Int | - | 是 | 發票期別：0(全部)、1(1-2月)、2(3-4月)、3(5-6月)、4(7-8月)、5(9-10月)、6(11-12月) |
| UseStatus | Int | - | 是 | 字軌使用狀態：0(全部)、1(未啟用)、2(使用中)、3(已停用)、4(暫停中)、5(待審核)、6(審核不通過) |
| InvoiceCategory | Int | - | 是 | 發票類別（固定填 2：B2B） |
| InvType | String | 2 | 否 | 字軌類別：07(一般稅額)、08(特種稅額) |
| InvoiceHeader | String | 2 | 否 | 字軌名稱 |

### Data 範例

```json
{
  "MerchantID": 2000132,
  "InvoiceTerm": 0,
  "InvoiceYear": "111",
  "UseStatus": 1,
  "InvoiceCategory": 2
}
```

## Response 參數（JSON 格式）

| 參數名 | 型別 | 長度 | 說明 |
|--------|------|------|------|
| PlatformID | String | 10 | 特約合作平台商代號 |
| MerchantID | String | 10 | 特店編號 |
| RpHeader | Object | - | 回傳資料物件 |
| RpHeader.Timestamp | Number | - | 回傳時間（Unix timestamp） |
| TransCode | Int | - | 回傳代碼（1=成功） |
| TransMsg | String | 200 | 回傳訊息 |
| Data | String | - | 加密資料（JSON 格式） |

### Response 範例

```json
{
  "MerchantID": "3002607",
  "RpHeader": {
    "Timestamp": 1234564848
  },
  "TransCode": 1,
  "TransMsg": "Success",
  "Data": "…"
}
```

## Data 參數（解密後）

| 參數名 | 型別 | 長度 | 說明 |
|--------|------|------|------|
| RtnCode | Int | - | 回應代碼（1=成功） |
| RtnMsg | String | 200 | 回應訊息 |
| InvoiceInfo | Array[Object] | - | 發票資訊陣列 |

### InvoiceInfo 物件結構

| 欄位名 | 型別 | 長度 | 說明 |
|--------|------|------|------|
| TrackID | String | 10 | 字軌號碼 ID |
| InvoiceYear | String | 3 | 發票年度 |
| InvoiceTerm | Int | - | 發票期別（1-6） |
| InvoiceCategory | Int | - | 發票類別（2：B2B） |
| InvType | String | 2 | 字軌類別：07(一般稅額)、08(特種稅額) |
| InvoiceHeader | String | 2 | 字軌名稱 |
| InvoiceStart | String | 8 | 起始發票編號 |
| InvoiceEnd | String | 8 | 結束發票編號 |
| InvoiceNo | String | 8 | 目前已使用號碼 |
| UseStatus | Int | - | 使用狀態：1(未啟用)、2(使用中)、3(已停用)、4(暫停中)、5(待審核)、6(審核不通過) |
| InvoiceLastDate | String | 20 | 發票最後開立時間（yyyy-MM-dd HH:mm:ss） |

## 重要注意事項

- 驗證時間區間暫訂為 10 分鐘內有效
- 合作特店須進行主機時間校正
- 僅可查詢去年、當年與明年的發票年度
- InvoiceYear 格式為民國年
