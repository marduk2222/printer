# B2B 電子發票 API - 作廢折讓發票

## 應用場景

當賣方已開立折讓發票後發現內容有誤時，可使用此功能進行作廢。賣方透過系統將作廢折讓發票參數傳送至綠界，綠界上傳至財政部平台並通知買方。

重點限制：

- 需等待交易相對人（營業人）確認交換完成後，作廢折讓發票才會生效
- 僅有賣方可上傳作廢折讓發票，買方無法主動進行折讓作廢申請

## API 端點

| 環境 | URL |
|------|-----|
| 測試 | https://einvoice-stage.ecpay.com.tw/B2BInvoice/CancelAllowance |
| 正式 | https://einvoice.ecpay.com.tw/B2BInvoice/CancelAllowance |

## Request 參數結構

### 外層參數（JSON）

| 欄位 | 型別 | 長度 | 必填 | 說明 | 預設值 |
|------|------|------|------|------|--------|
| PlatformID | String | 10 | N | 特約合作平台商代號 | 空值 |
| MerchantID | String | 10 | Y | 特店編號 | - |
| RqHeader | Object | - | Y | 傳入資料 | - |
| Data | String | - | Y | 加密資料 | - |

### RqHeader 參數

| 欄位 | 型別 | 必填 | 說明 |
|------|------|------|------|
| Timestamp | Number | Y | 傳入時間（Unix TimeStamp） |

時間驗證說明：驗證時間區間為 10 分鐘內有效，超過此區間訂單無法建立。

### Data 參數（加密前 JSON）

| 欄位 | 型別 | 長度 | 必填 | 說明 |
|------|------|------|------|------|
| MerchantID | String | 10 | Y | 特店編號 |
| AllowanceNo | String | 16 | Y | 綠界折讓編號（固定 16 碼） |
| Reason | String | 20 | Y | 折讓作廢原因 |
| Remark | String | 200 | N | 備註 |

注意：加密前須對參數值進行 URLEncode。

### Request 範例

```json
{
  "MerchantID": "2000132",
  "RqHeader": {
    "Timestamp": 1234567890
  },
  "Data": "…"
}
```

### Data 參數範例（加密前）

```json
{
  "MerchantID": "2000132",
  "AllowanceNo": "1909241702402030",
  "Reason": "Cancel_Allowance_Reason",
  "Remark": "Cancel_Allowance_Reamrk"
}
```

## Response 參數結構

### 外層參數（JSON）

| 欄位 | 型別 | 長度 | 說明 |
|------|------|------|------|
| PlatformID | String | 10 | 特約合作平台商代號 |
| MerchantID | String | 10 | 特店編號 |
| RpHeader | Object | - | 回傳資料 |
| TransCode | Int | - | 回傳代碼（1 = 傳輸成功） |
| TransMsg | String | 200 | 回傳訊息 |
| Data | String | - | 加密資料 |

### RpHeader 參數

| 欄位 | 型別 | 說明 |
|------|------|------|
| Timestamp | Number | 回傳時間（Unix timestamp） |

### Data 參數（解密後 JSON）

| 欄位 | 型別 | 長度 | 說明 |
|------|------|------|------|
| RtnCode | Int | - | 回應代碼（1 = 成功） |
| RtnMsg | String | 200 | 回應訊息 |

### Response 範例

```json
{
  "MerchantID": "3002607",
  "RpHeader": {
    "Timestamp": 1234564848
  },
  "TransCode": 1,
  "TransMsg": "Success",
  "Data": "…"
}
```

### Data 參數範例（解密後）

```json
{
  "RtnCode": 1,
  "RtnMsg": "新增成功"
}
```

## 重要注意事項

1. 發票若已被折讓過，無法直接作廢發票，請先確認該發票所開立的折讓單是否全部已作廢
2. 合作特店須進行主機時間校正，避免時差導致 API 無法正常運作
3. 平台商使用時，MerchantID 欄位僅限帶入已綁定子廠商的特店編號
