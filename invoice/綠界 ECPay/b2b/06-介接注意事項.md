# B2B 電子發票 API - 介接注意事項

## 呼叫綠界 API 的注意事項（10 項）

1. **防火牆設定**：確認伺服器防火牆未阻擋綠界回傳通知
2. **連接協議**：只提供 https (443 port) 連線方式，並請使用合法的 DNS 進行介接
3. **資料傳送方式**：確認使用 HTTP POST 方式傳送交易參數
4. **埠口設定**：特店伺服器 URL 須支援 HTTP 80 和 HTTPS 443
5. **金鑰安全**：勿將金鑰資訊（HashKey、HashIV）存放或顯示於前端網頁內
6. **網址編碼**：回傳網址需用 punycode 編碼處理中文網址
7. **服務申請**：電子發票服務需事先向綠界申請
8. **加密協議**：支援 TLS 1.1 以上的加密通訊
9. **防火牆 Domain 設定**：列出測試及正式環境的 domain 與 port 配置
10. **API 速率限制**：高速呼叫會返回 HTTP 403，需降速並等候 30 分鐘

完整詳細請至 https://developers.ecpay.com.tw/14825/ 查看。
