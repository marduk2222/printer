# B2B 電子發票 API - 查詢作廢發票確認

## 概述

商家可透過此 API 查詢已作廢發票的確認狀態，涵蓋銷項及進項發票，以整合至自有系統提供快速查詢服務。

## API 端點

| 環境 | URL |
|------|-----|
| 測試 | `https://einvoice-stage.ecpay.com.tw/B2BInvoice/GetInvalidConfirm` |
| 正式 | `https://einvoice.ecpay.com.tw/B2BInvoice/GetInvalidConfirm` |

## 主要參數說明

### Request 結構

- MerchantID（String, 10 碼）：特店編號，必填
- RqHeader：包含 Timestamp（Unix TimeStamp），必填
- Data：加密後的 JSON 資料，必填

### Data 參數

- InvoiceCategory（Int）：0=銷項、1=進項，必填
- InvoiceNumber（String, 10 碼）：發票號碼
- InvoiceDate（String）：yyyy-mm-dd 格式，與發票號碼配搭
- RelateNumber（String, 20 碼）：自訂編號

### Response RtnData 參數

- CancelDate、CancelReason、ConfirmDate：作廢相關日期與原因
- Upload_Status：上傳狀態碼（0/1/2）
- ConfirmRemark：備註說明

## 重要注意事項

驗證時間區間暫訂為 10 分鐘內有效，超過此期限訂單將無法建立。商家應進行主機時間校正，避免時差問題導致 API 失效。
