# B2B 電子發票 API - 發票列印

## 應用場景

特店使用此 API 取得發票列印網址。該列印網址的有效時間為，從呼叫此列印 API 開始計算 1 小時內有效。

## API 端點

| 環境 | URL |
|------|-----|
| 測試 | `https://einvoice-stage.ecpay.com.tw/B2BInvoice/InvoicePrint` |
| 正式 | `https://einvoice.ecpay.com.tw/B2BInvoice/InvoicePrint` |

## 重要參數概覽

### Request 主要欄位

- MerchantID（必填）
- RqHeader.Timestamp（必填）
- 加密 Data 參數

### Response 關鍵訊息

- RtnCode（1 為成功）
- InvoiceHtml（列印網址）

## 注意事項

- 加密前對參數值進行 URLEncode
- 合作特店須進行主機時間校正
- 驗證時間區間暫訂為 10 分鐘內有效

完整參數表（含長度、必填、說明、預設值與 Request/Response 範例）請至 https://developers.ecpay.com.tw/14993/ 查閱。
