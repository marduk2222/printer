# B2B 電子發票 API - 發送發票通知

## 應用場景

B2B 電子發票應在任何發票狀態變動時通知交易雙方，特店可主動發送通知，或透過廠商後台功能處理。

## API 端點

| 環境 | URL |
|------|-----|
| 測試 | https://einvoice-stage.ecpay.com.tw/B2BInvoice/Notify |
| 正式 | https://einvoice.ecpay.com.tw/B2BInvoice/Notify |

重要提示：測試環境下綠界不會「主動」發送任何通知，需於廠商管理後台使用「補發通知」。

## 請求參數（Request）

### 外層參數（JSON）

| 參數名 | 型別 | 長度 | 必填 | 說明 |
|--------|------|------|------|------|
| PlatformID | String | 10 | 否 | 特約合作平台商代號；一般廠商留空值 |
| MerchantID | String | 10 | 是 | 特店編號 |
| RqHeader | Object | - | 是 | 傳入資料物件 |
| Data | String | - | 是 | 加密資料（JSON 格式） |

### RqHeader 參數

| 參數名 | 型別 | 必填 | 說明 |
|--------|------|------|------|
| Timestamp | Number | 是 | 傳入時間（Unix TimeStamp）；驗證有效期為 10 分鐘 |

### Data 參數（加密前，需 URLEncode）

| 參數名 | 型別 | 長度 | 必填 | 說明 |
|--------|------|------|------|------|
| MerchantID | String | 10 | 是 | 特店編號 |
| InvoiceDate | String | 20 | 是 | 發票開立日期（yyyy-mm-dd 格式） |
| InvoiceNumber | String | 10 | 是 | 發票號碼 |
| AllowanceNo | String | 16 | 否 | 折讓單編號（固定 16 碼） |
| NotifyMail | String | 200 | 是 | 發送電子郵件；多組用半形分號（;）區隔；需符合標準 Email 格式 |
| InvoiceTag | String | 1 | 是 | 發送內容類型（詳見下表） |
| Notified | String | 1 | 是 | 發送對象：C（客戶）、M（特店）、A（皆發送） |

### InvoiceTag 發送內容類型

| 代碼 | 內容 |
|------|------|
| 1 | 發票開立 |
| 2 | 發票作廢 |
| 3 | 發票退回 |
| 4 | 開立折讓 |
| 5 | 作廢折讓 |
| 6 | 開立發票確認 |
| 7 | 作廢發票確認 |
| 8 | 退回發票確認 |
| 9 | 折讓確認 |
| 10 | 作廢折讓確認 |

### 請求範例

```json
{
  "MerchantID": "2000132",
  "RqHeader": {
    "Timestamp": 1234567890
  },
  "Data": "…"
}
```

### Data 參數範例（JSON，加密前）

```json
{
  "MerchantID": "2000132",
  "InvoiceDate": "2019-09-04",
  "InvoiceNumber": "VG11000000",
  "NotifyMail": "abc5678@gmail.com; def5678@gmail.com",
  "InvoiceTag": 1,
  "Notified": "C"
}
```

## 回應參數（Response）

### 外層參數（JSON）

| 參數名 | 型別 | 長度 | 說明 |
|--------|------|------|------|
| PlatformID | String | 10 | 特約合作平台商代號 |
| MerchantID | String | 10 | 特店編號 |
| RpHeader | Object | - | 回傳資料物件 |
| TransCode | Int | - | 回傳代碼（1 為傳輸成功） |
| TransMsg | String | 200 | 回傳訊息 |
| Data | String | - | 加密資料 |

### RpHeader 參數

| 參數名 | 型別 | 說明 |
|--------|------|------|
| Timestamp | Number | 回傳時間（Unix timestamp） |

### Data 參數（加密）

| 參數名 | 型別 | 長度 | 說明 |
|--------|------|------|------|
| RtnCode | Int | - | 回應代碼（1 為成功） |
| RtnMsg | String | 200 | 回應訊息 |

### 回應範例

```json
{
  "MerchantID": "2000132",
  "RpHeader": {
    "Timestamp": "1525169058"
  },
  "TransCode": 1,
  "TransMsg": "",
  "Data": "…"
}
```

### Data 參數範例（JSON，解密後）

```json
{
  "RtnCode": 1,
  "RtnMsg": "發送完成"
}
```

## 重要注意事項

1. 時間校正：合作特店須進行主機「時間校正」，避免主機產生時差
2. 驗證時間區間：10 分鐘內有效
3. URLEncode：請在加密前對參數值進行 URLEncode
4. Email 格式驗證：採用正規表達式驗證標準 Email 格式
