# B2B 電子發票 API - 查詢退回發票確認

## 應用場景

特店可使用此 API 查詢已退回發票是否完成確認資訊，包括銷項發票及進項發票。

## API 端點

| 環境 | URL |
|------|-----|
| 測試 | https://einvoice-stage.ecpay.com.tw/B2BInvoice/GetRejectConfirm |
| 正式 | https://einvoice.ecpay.com.tw/B2BInvoice/GetRejectConfirm |

## Request 參數結構

### 最外層參數

| 參數名 | 型別 | 長度 | 必填 | 說明 |
|--------|------|------|------|------|
| PlatformID | String | 10 | 否 | 特約合作平台商代號；一般廠商放空值 |
| MerchantID | String | 10 | 是 | 特店編號 |
| RqHeader | Object | - | 是 | 傳入資料 |
| Data | String | - | 是 | 加密過的 JSON 格式資料 |

### RqHeader 物件

| 參數名 | 型別 | 必填 | 說明 |
|--------|------|------|------|
| Timestamp | Number | 是 | 傳入時間（Unix TimeStamp）；驗證時間區間為 10 分鐘內有效 |

### Data 內容（加密前 JSON）

| 參數名 | 型別 | 長度 | 必填 | 說明 |
|--------|------|------|------|------|
| MerchantID | String | 10 | 是 | 特店編號 |
| InvoiceCategory | Int | - | 是 | B2B 發票種類：0=銷項發票；1=進項發票 |
| InvoiceNumber | String | 10 | 條件必填 | 發票號碼；當 RelateNumber 為空值時需填 |
| InvoiceDate | String | 20 | 條件必填 | 發票開立日期（yyyy-mm-dd）；當 InvoiceNumber 有值時必填 |
| RelateNumber | String | 20 | 條件必填 | 自訂編號；當 InvoiceNumber 為空值時需填 |

特店 Request 範例：

```json
{
    "MerchantID": "2000132",
    "RqHeader": {
        "Timestamp": 1234567890
    },
    "Data": "…"
}
```

Data 範例（加密前）：

```json
{
    "MerchantID": "2000132",
    "InvoiceCategory": 0,
    "InvoiceNumber": "SA37758327",
    "InvoiceDate": "2019-08-31",
    "RelateNumber": "2019081602"
}
```

## Response 參數結構

### 最外層參數

| 參數名 | 型別 | 長度 | 說明 |
|--------|------|------|------|
| PlatformID | String | 10 | 特約合作平台商代號 |
| MerchantID | String | 10 | 特店編號 |
| RpHeader | Object | - | 回傳資料 |
| TransCode | Int | - | 回傳代碼（1=傳輸成功） |
| TransMsg | String | 200 | 回傳訊息 |
| Data | String | - | 加密過的 JSON 格式資料 |

### RpHeader 物件

| 參數名 | 型別 | 說明 |
|--------|------|------|
| Timestamp | Number | 回傳時間（Unix timestamp） |

### Data 內容（加密前 JSON）

| 參數名 | 型別 | 長度 | 說明 |
|--------|------|------|------|
| RtnCode | Int | - | 回應代碼（1=成功；其餘為失敗） |
| RtnMsg | String | 200 | 回應訊息 |
| RtnData | String | - | 回應資料 |

綠界 Response 範例：

```json
{
    "MerchantID": "2000132",
    "RpHeader": {
        "Timestamp": "1525169058"
    },
    "TransCode": 1,
    "TransMsg": "",
    "Data": "…"
}
```

Data 範例（加密前）：

```json
{
    "RtnCode": 1,
    "RtnMsg": "查詢成功",
    "RtnData": "…"
}
```

### RtnData 內容（加密前 JSON）

| 參數名 | 型別 | 長度 | 說明 |
|--------|------|------|------|
| MerchantID | String | 10 | 特店編號 |
| InvoiceNumber | String | 10 | 發票號碼 |
| Buyer_Identifier | String | 8 | 買方統編 |
| Seller_Identifier | String | 8 | 賣方統編 |
| RejectDate | String | 20 | 退回日期（yyyy-mm-dd） |
| RejectReason | String | 20 | 退回原因 |
| ConfirmDate | String | 20 | 退回確認日期（yyyy-mm-dd）；未設定時為 null |
| Upload_Status | String | 1 | 上傳狀態：0=未上傳；1=已上傳；2=上傳失敗；InvoiceCategory=0 時為空值 |
| Upload_Date | String | 20 | 上傳時間（yyyy-mm-dd）；InvoiceCategory=0 時為 null |
| ConfirmRemark | String | 200 | 備註 |

RtnData 範例：

```json
{
    "MerchantID": "2000132",
    "InvoiceNumber": "VG11000002",
    "Buyer_Identifier": "23165448",
    "Seller_Identifier": "",
    "RejectDate": "2019-09-02",
    "RejectReason": "",
    "ConfirmDate": "2019-09-03",
    "Upload_Status": "",
    "Upload_Date": "2019-09-02",
    "ConfirmRemark": ""
}
```

## 重要注意事項

1. 時間驗證：驗證時間區間為 10 分鐘內有效；超過此區間訂單無法建立
2. 時間校正：合作特店須進行主機時間校正
3. URLEncode：加密前需對 Data 參數值進行 URLEncode
4. 加密方式：詳見[參數加密方式說明](https://developers.ecpay.com.tw/?p=15008)
