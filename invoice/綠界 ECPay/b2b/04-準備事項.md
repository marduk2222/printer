# B2B 電子發票 API - 準備事項

## 抓取狀況

WebFetch 受限於引用字元上限，以下為抓取代理回傳之摘要。

## 兩大前置準備

1. **財政部授權設定**
   - 「授權綠界：使用綠界電子發票加值中心前，請務必至財政部電子發票整合服務平台完成授權綠界」
   - 需完成接收設定配置

2. **字軌與配號設定**
   - 須於財政部平台取得專用字軌
   - 在綠界廠商後台新增字軌並等待審核
   - 審核通過後需啟用字軌
   - 詳細操作請參考綠界官方 PDF 文件

完整內容請至 https://developers.ecpay.com.tw/14815/ 查看。
