# B2B 電子發票 API - 查詢發票

## API 端點

| 環境 | URL |
|------|-----|
| 測試環境 | https://einvoice-stage.ecpay.com.tw/B2BInvoice/GetIssue |
| 正式環境 | https://einvoice.ecpay.com.tw/B2BInvoice/GetIssue |

## 應用場景

該 API 允許特店（營業人）查詢已開立發票資訊，包括銷項及進項發票，綠界會以回傳參數方式回覆該張發票資料。

## Request 參數結構（JSON）

### 頂層參數

| 參數名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| PlatformID | String | 10 | 否 | 特約合作平台商代號，一般廠商放空值 |
| MerchantID | String | 10 | 是 | 特店編號 |
| RqHeader | Object | - | 是 | 傳入資料物件 |
| RqHeader.Timestamp | Number | - | 是 | Unix TimeStamp，驗證區間 10 分鐘內有效 |
| Data | String | - | 是 | 加密過的 JSON 資料 |

### Data 參數（加密前，需先 URLEncode）

| 參數名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| MerchantID | String | 10 | 是 | 特店編號 |
| InvoiceCategory | Int | - | 是 | B2B 發票種類：0=銷項、1=進項 |
| InvoiceNumber | String | 10 | 是 | 發票號碼 |
| InvoiceDate | String | 20 | 是 | 發票開立日期（格式：yyyy-mm-dd） |
| RelateNumber | String | 20 | 否 | 自訂編號，唯一值不可重覆 |

### Request 範例

```json
{
  "MerchantID": "2000132",
  "RqHeader": {
    "Timestamp": 1234567890
  },
  "Data": "…"
}
```

Data 參數範例（加密前）：

```json
{
  "MerchantID": "2000132",
  "InvoiceCategory": 0,
  "InvoiceNumber": "SA37758327",
  "InvoiceDate": "2019-08-31",
  "RelateNumber": "2019081602"
}
```

## Response 參數結構（JSON）

### 頂層參數

| 參數名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| PlatformID | String | 10 | 特約合作平台商代號 |
| MerchantID | String | 10 | 特店編號 |
| RpHeader | Object | - | 回傳資料物件 |
| RpHeader.Timestamp | Number | - | 回傳時間（Unix timestamp） |
| TransCode | Int | - | 回傳代碼，1=API 傳輸成功，請參考 RtnCode 確認執行結果 |
| TransMsg | String | 200 | 回傳訊息 |
| Data | String | - | 加密過的 JSON 回傳資料 |

### Response 範例

```json
{
  "MerchantID": "2000132",
  "RpHeader": {
    "Timestamp": "1525169058"
  },
  "TransCode": 1,
  "TransMsg": "",
  "Data": "…"
}
```

### Data 參數（解密後）

| 參數名稱 | 型別 | 說明 |
|---------|------|------|
| RtnCode | Int | 回應代碼，1=成功，其餘=失敗 |
| RtnMsg | String | 回應訊息 |
| RtnData | String | 回應資料（加密） |

Data 參數範例：

```json
{
  "RtnCode": 1,
  "RtnMsg": "查詢成功",
  "RtnData": "…"
}
```

## RtnData 參數詳解（解密後）

### 基本資訊

| 參數名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| MerchantID | String | 10 | 特店編號 |

| InvoiceDate | String | 10 | 發票開立日期（yyyy-mm-dd） |

### 買方資訊

|---------|------|------|------|
| Seller_Identifier | String | 8 | 賣方統編（InvoiceCategory=0 時為空值） |

### 稅務與金額資訊

| 參數名稱 | 型別 | 長度 | 說明 |

### 狀態資訊

| 參數名稱 | 型別 | 長度 | 說明 |

## 零稅率原因代碼列表

自 115 年 1 月 1 日起，當課稅類別為零稅率或混合應稅與零稅率時，必須填寫：

| 代碼 | 說明 |
|------|------|
| 71 | 第一款 外銷貨物 |
| 72 | 第二款 與外銷有關之勞務 |
| 73 | 第三款 依法設立之免稅商店銷售 |
| 74 | 第四款 銷售與保稅區營業人供營運之貨物或勞務 |
| 75 | 第五款 國際間之運輸 |
| 76 | 第六款 國際運輸用之船舶、航空器及遠洋漁船 |
| 77 | 第七款 銷售與國際運輸用船舶所使用貨物或修繕勞務 |
| 78 | 第八款 保稅區營業人銷售與課稅區營業人未輸往課稅區而直接出口之貨物 |
| 79 | 第九款 保稅區營業人銷售與課稅區營業人存入自由港區事業之貨物 |

## 重要注意事項

1. 時間驗證：驗證時間區間暫訂為 10 分鐘內有效，若超過此驗證時間則此次訂單將無法建立。
2. 時間校正：合作特店須進行主機時間校正，避免時差導致 API 無法正常運作。
3. URLEncode：Data 參數需在加密前進行 URLEncode。
4. 加密方法：請參考參數加密方式說明文件。
