# B2B 電子發票 API - 查詢折讓發票確認

## 概述

該 API 允許特店（營業人）查詢已開立的折讓發票是否完成確認。

## API 端點

| 環境 | URL |
|------|-----|
| 測試環境 | https://einvoice-stage.ecpay.com.tw/B2BInvoice/GetAllowanceConfirm |
| 正式環境 | https://einvoice.ecpay.com.tw/B2BInvoice/GetAllowanceConfirm |

## Request 參數結構

主要包含以下欄位：

- **MerchantID**：特店編號（必填）
- **PlatformID**：平台商代號（選填，非平台商應放空值）
- **RqHeader.Timestamp**：傳入時間戳（必填，Unix TimeStamp 格式）
- **Data**：加密的 JSON 資料（必填）

Data 內容包括 MerchantID 與 AllowanceNo（16 碼固定長度的綠界折讓編號）。

## Response 參數結構

回傳包含加密的 Data 物件，解密後包含：

| 欄位 | 型別 | 說明 |
|------|------|------|
| RtnCode | Int | 1 為成功 |
| RtnMsg | String(200) | 回應訊息 |
| MerchantID | String(10) | 特店編號 |
| Seller_Identifier | String(8) | 賣方統編 |
| Buyer_Identifier | String(8) | 買方統編 |
| AllowanceDate | String(20) | 折讓日期（yyyy-mm-dd） |
| ConfirmDate | String(20) | 確認日期或 null |
| Upload_Status | String(1) | 上傳狀態（0/1/2） |
| Upload_Date | String(20) | 上傳日期 |
| ConfirmRemark | String(200) | 備註 |

## 重要注意事項

時間驗證區間為 10 分鐘內有效，需進行主機時間校正以避免時差問題。參數值需在加密前進行 URLEncode 處理。

完整欄位定義請至 https://developers.ecpay.com.tw/14973/ 查閱。
