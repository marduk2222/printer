# B2B 電子發票 API - 查詢退回發票

## 應用場景

特店（營業人）可透過此 API 查詢已退回發票資訊，包括銷項發票及進項發票。

## API 端點

- 測試環境：`https://einvoice-stage.ecpay.com.tw/B2BInvoice/GetReject`
- 正式環境：`https://einvoice.ecpay.com.tw/B2BInvoice/GetReject`

## Request 參數結構

### 最上層參數（JSON 格式）

| 欄位 | 型別 | 長度 | 必填 | 說明 |
|------|------|------|------|------|
| PlatformID | String | 10 | 否 | 特約合作平台商代號，一般廠商請放空值 |
| MerchantID | String | 10 | 是 | 特店編號 |
| RqHeader | Object | - | 是 | 傳入資料物件 |
| Data | String | - | 是 | 加密過的 JSON 格式資料 |

### RqHeader 物件參數

| 欄位 | 型別 | 必填 | 說明 |
|------|------|------|------|
| Timestamp | Number | 是 | 傳入時間（Unix TimeStamp），驗證區間為 10 分鐘內有效 |

### Data 參數（加密前的 JSON 內容）

| 欄位 | 型別 | 長度 | 必填 | 說明 |
|------|------|------|------|------|
| MerchantID | String | 10 | 是 | 特店編號 |
| InvoiceCategory | Int | - | 是 | B2B 發票種類：0=銷項發票、1=進項發票 |
| InvoiceNumber | String | 10 | 條件 | 發票號碼（RelateNumber 為空時需有值） |
| InvoiceDate | String | 20 | 條件 | 發票開立日期（格式：yyyy-mm-dd），InvoiceNumber 有值時必填 |
| RelateNumber | String | 20 | 條件 | 自訂編號（InvoiceNumber 為空時需有值） |

### Request 範例

```json
{
    "MerchantID": "2000132",
    "RqHeader": {
        "Timestamp": 1234567890
    },
    "Data": "…"
}
```

### Data 參數範例（加密前）

```json
{
    "MerchantID": "2000132",
    "InvoiceCategory": 0,
    "InvoiceNumber": "SA37758327",
    "InvoiceDate": "2019-08-31",
    "RelateNumber": "2019081602"
}
```

## Response 參數結構

### 最上層參數（JSON 格式）

| 欄位 | 型別 | 長度 | 說明 |
|------|------|------|------|
| PlatformID | String | 10 | 特約合作平台商代號 |
| MerchantID | String | 10 | 特店編號 |
| RpHeader | Object | - | 回傳資料物件 |
| TransCode | Int | - | 回傳代碼（1=API 傳輸成功，請參考 RtnCode 查看執行結果） |
| TransMsg | String | 200 | 回傳訊息 |
| Data | String | - | 加密過的 JSON 格式資料 |

### RpHeader 物件參數

| 欄位 | 型別 | 說明 |
|------|------|------|
| Timestamp | Number | 回傳時間（Unix timestamp） |

### Response 範例

```json
{
    "MerchantID": "2000132",
    "RpHeader": {
        "Timestamp": "1525169058"
    },
    "TransCode": 1,
    "TransMsg": "",
    "Data": "…"
}
```

### Data 參數（加密前的 JSON 內容）

| 欄位 | 型別 | 長度 | 說明 |
|------|------|------|------|
| RtnCode | Int | - | 回應代碼（1=成功，其餘為失敗） |
| RtnMsg | String | 200 | 回應訊息 |
| RtnData | String | - | 回應資料（包含發票退回詳細資訊） |

### Data 參數範例（加密前）

```json
{
    "RtnCode": 1,
    "RtnMsg": "查詢成功",
    "RtnData": "…"
}
```

## RtnData 回應資料結構

| 欄位 | 型別 | 長度 | 說明 |
|------|------|------|------|
| MerchantID | String | 10 | 特店編號 |
| InvoiceNumber | String | 10 | 發票號碼 |
| Buyer_Identifier | String | 8 | 買方統編 |
| Seller_Identifier | String | 8 | 賣方統編 |
| RejectDate | String | 20 | 退回日期（格式：yyyy-mm-dd） |
| RejectReason | String | 20 | 退回原因 |
| Upload_Status | String | 1 | 上傳狀態（InvoiceCategory=1 時為空）：0=未上傳、1=已上傳、2=上傳失敗 |
| Upload_Date | String | 20 | 上傳時間（InvoiceCategory=1 時為 null） |
| ConfirmDate | String | 20 | 退回確認日期（格式：yyyy-mm-dd，未設定時為 null） |
| ExchangeStatus | String | 1 | 退回確認狀態（未設定時為空值）：0=未確認、1=已確認 |
| Remark | String | 200 | 備註 |

### RtnData 參數範例

```json
{
    "MerchantID": "2000132",
    "InvoiceNumber": "VG11000002",
    "Buyer_Identifier": "23165448",
    "Seller_Identifier": "",
    "RejectDate": "2019-09-02",
    "RejectReason": "",
    "Upload_Status": "",
    "Upload_Date": "2019-09-24",
    "ConfirmDate": "2019-09-25",
    "ExchangeStatus": "1",
    "Remark": ""
}
```

## 重要注意事項

- 時間驗證：驗證時間區間為 10 分鐘內有效，超過此時間則訂單無法建立
- URLEncode：在加密前對 Data 參數值進行 URLEncode
- 時間校正：合作特店須進行主機時間校正
- 加密方法：Data 參數需按照綠界「參數加密方式說明」進行加密處理
- 平台商使用：若為特約合作平台商，MerchantID 欄位僅限帶入已綁定子廠商的特店編號
