# B2B 電子發票 API - 查詢作廢折讓發票確認

## 應用場景

特店（營業人）可使用此 API 查詢已作廢折讓發票是否完成確認資訊，綠界會以回傳參數方式回覆該張發票資料。此方式可協助特店（營業人）將查詢發票作廢折讓確認機制整合至營業人網站，提供快速查詢服務。

## API 端點

| 環境 | URL |
|------|-----|
| 測試環境 | https://einvoice-stage.ecpay.com.tw/B2BInvoice/GetAllowanceInvalidConfirm |
| 正式環境 | https://einvoice.ecpay.com.tw/B2BInvoice/GetAllowanceInvalidConfirm |

## Request 參數說明（JSON 格式）

### 外層參數

| 欄位名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| PlatformID | String | 10 | 否 | 特約合作平台商代號，一般廠商介接請放空值 |
| MerchantID | String | 10 | 是 | 特店編號 |
| RqHeader | Object | - | 是 | 傳入資料 |
| RqHeader.Timestamp | Number | - | 是 | 傳入時間（Unix TimeStamp），驗證時間區間為 10 分鐘內有效 |
| Data | String | - | 是 | 加密資料（加密過 JSON 格式） |

### Request 範例

```json
{
  "MerchantID": "2000132",
  "RqHeader": {
    "Timestamp": 1234567890
  },
  "Data": "…"
}
```

## Data 參數說明（加密前，JSON 格式）

注意事項：請在加密前對參數值進行 URLEncode。

| 欄位名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| MerchantID | String | 10 | 是 | 特店編號 |
| AllowanceNo | String | 16 | 否 | 綠界折讓編號（固定 16 碼） |

### Data 參數範例

```json
{
  "MerchantID": "2000132",
  "AllowanceNo": "1909241702402030"
}
```

## Response 參數說明（JSON 格式）

### 外層參數

| 欄位名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| PlatformID | String | 10 | 特約合作平台商代號 |
| MerchantID | String | 10 | 特店編號 |
| RpHeader | Object | - | 回傳資料 |
| RpHeader.Timestamp | Number | - | 回傳時間（Unix timestamp） |
| TransCode | Int | - | 回傳代碼（1=API 傳輸資料接收成功） |
| TransMsg | String | 200 | 回傳訊息 |
| Data | String | - | 加密資料（加密過 JSON 格式） |

### Response 範例

```json
{
  "MerchantID": "2000132",
  "RpHeader": {
    "Timestamp": "1525169058"
  },
  "TransCode": 1,
  "TransMsg": "",
  "Data": "…"
}
```

## Data 參數說明（解密後，JSON 格式）

| 欄位名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| RtnCode | Int | - | 回應代碼（1=成功，其餘為失敗） |
| RtnMsg | String | 200 | 回應訊息 |
| RtnData | String | - | 回應資料 |

### Data 參數範例

```json
{
  "RtnCode": 1,
  "RtnMsg": "查詢成功",
  "RtnData": "…"
}
```

## RtnData 參數說明（JSON 格式）

| 欄位名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| MerchantID | String | 10 | 特店編號 |
| Seller_Identifier | String | 8 | 賣方統編 |
| Buyer_Identifier | String | 8 | 買方統編 |
| CancelDate | String | 20 | 作廢日期（yyyy-mm-dd） |
| Upload_Status | String | 1 | 上傳狀態：0=未上傳、1=已上傳、2=上傳失敗（B2B 發票種類=1 時為空值） |
| Upload_Date | String | 20 | 上傳時間（yyyy-mm-dd，B2B 發票種類=1 時為 null） |
| ExchangeStatus | String | - | 交換狀態 |
| ConfirmRemark | String | 200 | 備註 |

### RtnData 參數範例

```json
{
  "MerchantID": "2000132",
  "Seller_Identifier": "23165448",
  "Buyer_Identifier": "",
  "CancelDate": "2019-09-26",
  "Upload_Status": "",
  "Upload_Date": "null",
  "ExchangeStatus": "1",
  "ConfirmRemark": ""
}
```
