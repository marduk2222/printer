# B2B 電子發票 API - 查詢折讓發票

## 應用場景

特店可透過此 API 查詢發票折讓資訊，綠界以回傳參數方式提供該張發票折讓資料，協助特店將查詢機制整合至網站。

## API 介接網址

- 測試環境：https://einvoice-stage.ecpay.com.tw/B2BInvoice/GetAllowance
- 正式環境：https://einvoice.ecpay.com.tw/B2BInvoice/GetAllowance

## Request 參數說明（JSON 格式）

| 欄位 | 型別 | 長度 | 必填 | 說明 |
|------|------|------|------|------|
| PlatformID | String | 10 | 否 | 特約合作平台商代號，一般廠商放空值 |
| MerchantID | String | 10 | 是 | 特店編號 |
| RqHeader | Object | - | 是 | 傳入資料物件 |
| RqHeader.Timestamp | Number | - | 是 | Unix TimeStamp，驗證區間 10 分鐘內有效 |
| Data | String | - | 是 | 加密過的 JSON 格式資料 |

## Data 參數說明（JSON 格式）

| 欄位 | 型別 | 長度 | 必填 | 說明 |
|------|------|------|------|------|
| MerchantID | String | 10 | 是 | 特店編號 |
| AllowanceNo | String | 16 | 是 | 綠界折讓編號（固定 16 碼） |

注意：參數值須在加密前進行 URLEncode。

## Response 參數說明（JSON 格式）

| 欄位 | 型別 | 說明 |
|------|------|------|
| PlatformID | String | 特約合作平台商代號 |
| MerchantID | String | 特店編號 |
| RpHeader | Object | 回傳資料物件 |
| RpHeader.Timestamp | Number | 回傳時間（Unix timestamp） |
| TransCode | Int | 回傳代碼：1 表示接收成功 |
| TransMsg | String | 回傳訊息 |
| Data | String | 加密過的 JSON 格式資料 |

## Data 參數說明（回傳）

| 欄位 | 型別 | 說明 |
|------|------|------|
| RtnCode | Int | 回應代碼：1 為成功 |
| RtnMsg | String | 回應訊息 |
| RtnData | String | 回應資料 |

## RtnData 參數說明（JSON 格式）

| 欄位 | 型別 | 長度 | 說明 |
|------|------|------|------|
| MerchantID | String | 10 | 特店編號 |
| AllowanceNo | String | 16 | 綠界折讓編號（固定 16 碼） |
| AllowanceNumber | String | 16 | 廠商折讓單號碼 |
| AllowanceType | String | 20 | 折讓類型 |
| Buyer_Identifier | String | 8 | 買方統編 |
| Buyer_Name | String | 60 | 買方名稱 |
| Buyer_Address | String | 100 | 買方地址 |
| Buyer_TelephoneNumber | String | 26 | 買方電話 |
| Buyer_EmailAddress | String | 200 | 買方電子信箱 |
| Seller_Identifier | String | 8 | 賣方統編（B2B 種類=0 時為空值） |
| Seller_Name | String | 60 | 賣方名稱（B2B 種類=0 時為空值） |
| AllowanceDate | String | 20 | 折讓單日期 |
| TotalAmount | Number | - | 折讓金額總計（未稅），最多 12 位整數 |
| TaxAmount | Number | - | 營業稅額，最多 11 位整數 |
| IP | String | 15 | 折讓開立 IP（IPV4） |
| Upload_Status | String | 1 | 上傳狀態：0=未上傳、1=已上傳、2=上傳失敗（B2B 種類=1 時為空值） |
| Upload_Date | String | 20 | 上傳時間（yyyy-mm-dd，B2B 種類=1 時為 null） |
| ConfirmDate | String | 20 | 退回確認日期（yyyy-mm-dd，未設定時為 null） |
| Invalid_Status | String | 1 | 作廢狀態：0=未作廢、1=已作廢 |
| ExchangeStatus | String | 1 | 發票確認狀態：0=未確認、1=已確認（空值表示未設定） |
| Items | Array | - | 傳入資料陣列 |
| Remark | String | 200 | 備註 |

### Items 陣列物件欄位

| 欄位 | 型別 | 說明 |
|------|------|------|
| OriginalInvoiceDate | String | 原發票日期（yyyy-mm-dd hh:mm:ss） |
| OriginalInvoiceNumber | String | 原發票號碼 |
| OriginalSequenceNumber | String | 發票商品明細排序（1~999 整數值） |
| OriginalDescription | String | 原商品名稱 |
| InvoiceType | String | 字軌類別：07=一般稅額計算、08=特種稅額計算 |
| TaxType | Int | 課稅別：1=一般應稅、2=零稅率、3=免稅、4=特種應稅 |
| AllowanceSequenceNumber | String | 折讓單排序 |
| Quantity | Number | 商品數量（最多整數 8 位，小數 7 位） |
| Unit | String | 商品單位（最多 6 碼） |
| UnitPrice | Number | 商品價格（最多整數 10 位，小數 7 位） |
| Tax | Number | 商品稅額（最多 11 位整數） |
| Amount | Number | 商品合計（最多整數 12 位，小數 7 位） |
| BalanceAmount | Number | 發票可折讓金額（最多 12 位整數） |
