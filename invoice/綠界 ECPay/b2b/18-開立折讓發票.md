# B2B 電子發票 API - 開立折讓發票

## 應用場景

賣方根據財政部電子發票 MIG 4.1 版規定開立折讓單。當發生銷貨退回、調換貨物或折讓情形時，由賣方發起折讓流程並傳送參數至綠界科技。

關鍵注意事項：

- 折讓僅能由原發票開立人（賣方）發動
- 上傳後需等待交易相對人確認才完成交換
- 應依財政部規定請交易相對人完成確認

## API 介接網址

| 環境 | URL |
|------|-----|
| 測試環境 | https://einvoice-stage.ecpay.com.tw/B2BInvoice/Allowance |
| 正式環境 | https://einvoice.ecpay.com.tw/B2BInvoice/Allowance |

## Request 參數說明（JSON 格式）

### 頂層參數

| 參數名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| PlatformID | String | 10 | 否 | 特約合作平台商代號，一般廠商放空值 |
| MerchantID | String | 10 | 是 | 特店編號 |
| RqHeader | Object | - | 是 | 傳入資料 |
| Data | String | - | 是 | 加密資料（JSON 格式） |

### RqHeader 物件

| 參數名稱 | 型別 | 必填 | 說明 |
|---------|------|------|------|
| Timestamp | Number | 是 | 傳入時間，Unix TimeStamp 格式 |

時間驗證注意事項：驗證時間區間為 10 分鐘內有效，超過則訂單無法建立。合作特店須進行主機時間校正，避免時差導致 API 無法運作。

### Data 參數說明（加密前的 JSON 格式）

前置處理：在加密前對參數值進行 URLEncode。

| 參數名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| MerchantID | String | 10 | 是 | 特店編號 |
| AllowanceDate | String | 20 | 否 | 折讓單時間，格式 yyyy-mm-dd hh:mm:ss，僅接受 6 天內日期，無值時開立當下日期 |
| CustomerEmail | String | 200 | 否 | 買方電子信箱，多組以半形分號區隔，無值時自動帶入交易對象維護 API 設定資料 |
| CustomerAddress | String | 100 | 否 | 買方公司地址 |
| TaxAmount | Number | - | 是 | 營業稅額，帶整數最多 11 位 |
| TotalAmount | Number | - | 是 | 折讓金額總計（未稅），帶整數最多 12 位，金額不可為 0 元 |
| Details | Array[Object] | - | 是 | 折讓明細（見下表） |

TaxAmount 計算規則：定義【折讓金額總計（未稅）[TotalAmount] × 開立發票 API 的稅率[TaxRate] 四捨五入至整數】為 C，則 TaxAmount 與 C 的差距不可大於 2。

TotalAmount 計算規則：需等於每張發票折讓的商品金額[ItemAmount] 加總後四捨五入至整數的值。

CustomerEmail 驗證規則：僅接受標準 Email 格式，測試環境請勿帶入真實信箱避免個資外洩；測試環境僅驗規則，不提供發信測試。

特種稅額發票注意事項：如發票僅含特種稅額請直接帶 0。

### Details 物件陣列 - 商品折讓明細

| 參數名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| OriginalInvoiceNumber | String | 10 | 是 | 原發票號碼 |
| OriginalInvoiceDate | String | 20 | 是 | 原發票日期，格式 yyyy-mm-dd |
| OriginalSequenceNumber | Int | - | 是 | 原發票號碼排序，帶 1~999 整數值，商品排序需與原發票開立時相同 |
| ItemName | String | 500 | 是 | 商品名稱，需與原發票號碼排序的對應商品名稱相同 |
| ItemCount | Number | - | 是 | 商品數量，不可超過原發票商品數量，支援整數最多 8 位小數 7 位 |
| ItemPrice | Number | - | 是 | 商品價格，不可超過原發票商品價格，支援整數最多 10 位小數 7 位 |
| ItemAmount | Number | - | 是 | 商品合計，支援整數最多 12 位小數 7 位 |
| Tax | Number | - | 否 | 商品稅額，須為整數最多 11 位 |

ItemAmount 計算規則：定義【折讓的商品數量[ItemCount] × 折讓的商品價格[ItemPrice]】=A，則 ItemAmount 與 A 的差距不可大於 1。

Tax 計算規則：定義【折讓的商品合計[ItemAmount] × 開立發票 API 的稅率[TaxRate]】=B，則 Tax 與 B 四捨五入至整數的差距不可大於 1；特種稅額發票請帶 0。

## Response 參數說明（JSON 格式）

### 頂層參數

| 參數名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| PlatformID | String | 10 | 特約合作平台商代號 |
| MerchantID | String | 10 | 特店編號 |
| RpHeader | Object | - | 回傳資料 |
| TransCode | Int | - | 回傳代碼，1=API 傳輸資料接收成功，實際執行結果見 RtnCode |
| TransMsg | String | 200 | 回傳訊息 |
| Data | String | - | 加密資料（JSON 格式） |

### RpHeader 物件

| 參數名稱 | 型別 | 說明 |
|---------|------|------|
| Timestamp | Number | 回傳時間（Unix timestamp） |
| RqID | String | 請求 ID |

### Data 參數說明（解密後的 JSON 格式）

| 參數名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| RtnCode | Int | - | 回應代碼，1=成功，其餘為失敗 |
| RtnMsg | String | 200 | 回應訊息 |
| AllowanceNo | String | 16 | 綠界折讓編號，成功時回傳，失敗時回傳空值 |
| AllowanceNumber | String | 16 | 折讓單號碼（廠商自訂） |
