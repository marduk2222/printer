# B2B 電子發票 API - 查詢發票確認

## 應用場景

特店可透過此 API 查詢已開立發票的確認狀態，包括銷項發票及進項發票，綠界以回傳參數方式提供發票資料。

## API 端點

| 環境 | URL |
|------|-----|
| 測試 | `https://einvoice-stage.ecpay.com.tw/B2BInvoice/GetIssueConfirm` |
| 正式 | `https://einvoice.ecpay.com.tw/B2BInvoice/GetIssueConfirm` |

## 關鍵技術要點

- 時間驗證：時間戳須在 10 分鐘內有效，超時查詢失敗
- 數據加密：所有 Data 參數均需加密處理
- URLEncode：加密前須對參數值進行 URLEncode

## 核心查詢參數

支援按發票號碼、自訂編號、日期區間、號碼區間等方式查詢，並可篩選發票狀態、作廢狀態、上傳模式及進度。

## 抓取狀況

WebFetch 受限於引用字元上限，未能取得完整參數表。詳細欄位請至 https://developers.ecpay.com.tw/14940/ 查閱。

預期參數結構（依與「查詢發票」(GetIssue) API 對稱推測）：

### Request

- MerchantID（必填）
- RqHeader.Timestamp
- Data（加密 JSON）：MerchantID、InvoiceCategory（0=銷項/1=進項）、InvoiceNumber、InvoiceDate（yyyy-mm-dd）、RelateNumber

### Response RtnData

包含發票主檔（買方/賣方資訊、稅務金額）+ 確認狀態（ConfirmDate、ConfirmRemark、ExchangeStatus）。
