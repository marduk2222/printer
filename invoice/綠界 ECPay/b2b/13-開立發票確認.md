# B2B 電子發票 API - 開立發票確認

## 應用場景

特店收到開立發票通知後，傳送確認參數給綠界。綠界於隔日上傳至財政部平台，完成發票開立交換，並通知交易相對人。

## API 端點

- **測試環境**：https://einvoice-stage.ecpay.com.tw/B2BInvoice/IssueConfirm
- **正式環境**：https://einvoice.ecpay.com.tw/B2BInvoice/IssueConfirm

## 請求參數（JSON）

| 欄位 | 型別 | 長度 | 必填 | 說明 |
|------|------|------|------|------|
| PlatformID | String | 10 | 否 | 特約合作平台商代號，一般廠商放空值 |
| MerchantID | String | 10 | 是 | 特店編號 |
| RqHeader | Object | - | 是 | 傳入資料物件 |
| RqHeader.Timestamp | Number | - | 是 | Unix TimeStamp，驗證區間 10 分鐘內有效 |
| Data | String | - | 是 | 加密 JSON 資料 |

### Data 內容參數

| 欄位 | 型別 | 長度 | 必填 | 說明 |
|------|------|------|------|------|
| MerchantID | String | 10 | 是 | 特店編號 |
| InvoiceNumber | String | 10 | 是 | 發票號碼 |
| InvoiceDate | String | 20 | 是 | 發票開立日期（格式：yyyy-mm-dd） |
| Remark | String | 200 | 否 | 備註 |

## 回應參數（JSON）

| 欄位 | 型別 | 長度 | 說明 |
|------|------|------|------|
| MerchantID | String | 10 | 特店編號 |
| RpHeader | Object | - | 回傳資料物件 |
| RpHeader.Timestamp | Number | - | Unix timestamp 回傳時間 |
| TransCode | Int | - | 1 表示資料接收成功，參考 RtnCode 看執行結果 |
| TransMsg | String | 200 | 回傳訊息 |
| Data | String | - | 加密 JSON 資料 |

### Data 內容參數

| 欄位 | 型別 | 長度 | 說明 |
|------|------|------|------|
| RtnCode | Int | - | 1 為成功，其餘為失敗 |
| RtnMsg | String | 200 | 回應訊息 |

## 重要注意事項

- 時間驗證區間暫訂為 10 分鐘內有效，若超過此驗證時間則此次訂單將無法建立。
- 合作特店須進行主機時間校正，避免時差導致 API 無法正常運作。
