# B2B 電子發票 API - 退回發票

## 應用場景

特店發現發票內容錯誤（數量、單價或品名），拒絕確認。特店傳送退回參數給綠界，綠界隔日上傳至財政部平台並通知交易相對人。

## API 介接網址

| 環境 | URL |
|------|-----|
| 測試環境 | https://einvoice-stage.ecpay.com.tw/B2BInvoice/Reject |
| 正式環境 | https://einvoice.ecpay.com.tw/B2BInvoice/Reject |

## 特店 Request 參數說明（JSON 格式）

| 欄位名 | 型別 | 長度 | 必填 | 說明 |
|-------|------|------|------|------|
| PlatformID | String | 10 | 否 | 特約合作平台商代號，一般廠商放空值 |
| MerchantID | String | 10 | 是 | 特店編號 |
| RqHeader | Object | - | 是 | 傳入資料 |
| RqHeader.Timestamp | Number | - | 是 | 傳入時間（Unix TimeStamp），驗證區間 10 分鐘 |
| Data | String | - | 是 | 加密資料（JSON 格式） |

### Request 範例

```json
{
  "MerchantID": "2000132",
  "RqHeader": {
    "Timestamp": 1234567890
  },
  "Data": "…"
}
```

## Data 參數說明（JSON 格式）

注意事項：加密前對參數值進行 URLEncode。

| 欄位名 | 型別 | 長度 | 必填 | 說明 |
|-------|------|------|------|------|
| MerchantID | String | 10 | 是 | 特店編號 |
| InvoiceNumber | String | 10 | 是 | 發票號碼 |
| InvoiceDate | String | 10 | 是 | 發票開立日期（yyyy-mm-dd） |
| Reason | String | 20 | 是 | 退回原因 |
| Remark | String | 200 | 否 | 備註 |

### Data 範例

```json
{
  "MerchantID": "2000132",
  "InvoiceNumber": "VG11000002",
  "InvoiceDate": "2019-09-23",
  "Reason": "Reject_Reason",
  "Remark": "Buyer_Reject_Remark"
}
```

## 綠界 Response 參數說明（JSON 格式）

| 欄位名 | 型別 | 長度 | 說明 |
|-------|------|------|------|
| PlatformID | String | 10 | 特約合作平台商代號 |
| MerchantID | String | 10 | 特店編號 |
| RpHeader | Object | - | 回傳資料 |
| RpHeader.Timestamp | Number | - | 回傳時間（Unix timestamp） |
| TransCode | Int | - | 1=傳輸成功；參考 RtnCode 了解執行結果 |
| TransMsg | String | 200 | 回傳訊息 |
| Data | String | - | 加密資料（JSON 格式） |

### Response 範例

```json
{
  "MerchantID": "3002607",
  "RpHeader": {
    "Timestamp": 1234564848
  },
  "TransCode": 1,
  "TransMsg": "Success",
  "Data": "…"
}
```

## Data 參數說明（Response）（JSON 格式）

| 欄位名 | 型別 | 長度 | 說明 |
|-------|------|------|------|
| RtnCode | Int | - | 1=成功；其餘為失敗 |
| RtnMsg | String | 200 | 回應訊息 |

### Data 參數範例

```json
{
  "RtnCode": 1,
  "RtnMsg": "新增成功"
}
```
