# B2B 電子發票 API - 查詢作廢發票

## 概述

此 API 提供特店（營業人）查詢已作廢發票資訊。

## API 端點

| 環境 | URL |
|------|-----|
| 測試環境 | https://einvoice-stage.ecpay.com.tw/B2BInvoice/GetInvalid |
| 正式環境 | https://einvoice.ecpay.com.tw/B2BInvoice/GetInvalid |

## 核心功能

可協助特店（營業人）將查詢發票作廢機制整合至特店（營業人）網站，提供快速查詢服務，支援銷項與進項發票查詢。

## 關鍵參數概覽

### Request 層級參數

- MerchantID
- RqHeader（含 Timestamp）
- Data（加密）

### Data 解密後參數

- InvoiceCategory（0=銷項；1=進項）
- InvoiceNumber + InvoiceDate 或 RelateNumber 之一必填

### Response RtnData 關鍵欄位

- CancelDate、CancelTime、CancelReason
- Upload_Status（0=未上傳、1=已上傳、2=失敗）
- ExchangeStatus（0=未確認、1=已確認）

## 重要注意事項

- 時間驗證區間為暫訂 10 分鐘內有效
- 特店須進行主機時間校正以避免時差問題
