# B2B 電子發票 API - 字軌與配號設定

## 概述

營業人在取得財政部配號結果後，建立並設定發票字軌。

## API 端點

- **測試環境**：https://einvoice-stage.ecpay.com.tw/B2BInvoice/AddInvoiceWordSetting
- **正式環境**：https://einvoice.ecpay.com.tw/B2BInvoice/AddInvoiceWordSetting

## 請求參數結構（JSON 格式）

### 外層參數

| 欄位 | 型別 | 長度 | 必填 | 說明 |
|------|------|------|------|------|
| MerchantID | String | 10 | Y | 特店編號 |
| PlatformID | String | 10 | N | 平台商代號（一般廠商留空） |
| RqHeader | Object | - | Y | 傳入資料容器 |
| Data | String | - | Y | 加密的 JSON 資料 |

### RqHeader 參數

| 欄位 | 型別 | 必填 | 說明 |
|------|------|------|------|
| Timestamp | Number | Y | Unix TimeStamp（GMT+8），驗證區間 10 分鐘內有效 |

### Data 參數（加密前的 JSON）

| 欄位 | 型別 | 長度 | 必填 | 說明 |
|------|------|------|------|------|
| MerchantID | String | 10 | Y | 特店編號 |
| InvoiceYear | String | 3 | Y | 發票年度。僅可設定當年與次年（如：111） |
| InvoiceTerm | Int | - | Y | 發票期別 1-6（1:1-2月、2:3-4月、3:5-6月、4:7-8月、5:9-10月、6:11-12月），不可小於當年期別 |
| InvType | String | 2 | Y | 字軌類別：07=一般稅額發票、08=特種稅額發票 |
| InvoiceCategory | String | 1 | Y | 發票種類，B2B 固定填寫 2 |
| InvoiceHeader | String | 2 | Y | 發票字軌 |
| InvoiceStart | String | 8 | Y | 起始發票號碼。8 碼，尾數須為 00 或 50（如：10000000） |
| InvoiceEnd | String | 8 | Y | 結束發票號碼。8 碼，尾數須為 49 或 99（如：10000049） |

### 請求範例

```json
{
    "MerchantID": "2000132",
    "RqHeader": {
        "Timestamp": 1234567890
    },
    "Data": "enter your data"
}
```

### Data 參數範例（加密前）

```json
{
    "MerchantID": "2000132",
    "InvoiceTerm": "1",
    "InvoiceYear": "109",
    "InvType": "07",
    "InvoiceCategory": "2",
    "InvoiceHeader": "TW",
    "InvoiceStart": "10000000",
    "InvoiceEnd": "10000049"
}
```

## 回應參數結構（JSON 格式）

### 外層回應參數

| 欄位 | 型別 | 長度 | 說明 |
|------|------|------|------|
| MerchantID | String | 10 | 特店編號 |
| PlatformID | String | 10 | 平台商代號 |
| RpHeader | Object | - | 回傳資料容器 |
| TransCode | Int | - | 1=API 傳輸成功，詳見 RtnCode |
| TransMsg | String | 200 | 回傳訊息 |
| Data | String | - | 加密的 JSON 回應 |

### RpHeader 參數

| 欄位 | 型別 | 說明 |
|------|------|------|
| Timestamp | Number | 回傳時間（Unix timestamp） |

### Data 參數（加密前的回應 JSON）

| 欄位 | 型別 | 長度 | 說明 |
|------|------|------|------|
| RtnCode | Int | - | 1=成功，其他=失敗 |
| RtnMsg | String | 200 | 回應訊息 |
| TrackID | String | 10 | 字軌號碼 ID（用於後續啟用設定） |

### 回應範例

```json
{
    "MerchantID": "3002607",
    "RpHeader": {
        "Timestamp": 1234564848
    },
    "TransCode": 1,
    "TransMsg": "Success",
    "Data": "…"
}
```

### Data 參數範例（加密前的回應）

```json
{
    "RtnCode": 1,
    "RtnMsg": "成功",
    "TrackID": "1234567890"
}
```

## 重要注意事項

1. 新增字軌前須自行檢核字軌正確性
2. 新增字軌後預設為「已審核通過但未啟用」，需使用「設定字軌號碼狀態 API」進行啟用
3. 時間戳驗證區間為 10 分鐘內
4. 合作特店須進行主機時間校正
5. 加密方法：[參數加密方式說明](https://developers.ecpay.com.tw/?p=15008)
6. 期別限制：不可帶入小於當年的期別
