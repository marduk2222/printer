# B2B 電子發票 API - 作廢發票

## 應用場景

當交易雙方因銷貨退回或發票內容錯誤時，特店可向綠界傳送作廢發票參數。綠界暫存資料後，隔日將發票上傳至財政部電子發票整合服務平台，並根據設定通知交易相對人。

重要注意：需等待交易相對人確認後才完成交換，否則不屬於有效憑證。

## API 介接網址

| 環境 | URL |
|------|-----|
| 測試環境 | https://einvoice-stage.ecpay.com.tw/B2BInvoice/Invalid |
| 正式環境 | https://einvoice.ecpay.com.tw/B2BInvoice/Invalid |

## 特店 Request 參數說明（JSON 格式）

| 欄位名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| PlatformID | String | 10 | 否 | 特約合作平台商代號；一般廠商請放空值 |
| MerchantID | String | 10 | 是 | 特店編號 |
| RqHeader | Object | - | 是 | 傳入資料 |
| RqHeader.Timestamp | Number | - | 是 | 傳入時間（Unix TimeStamp，驗證區間 10 分鐘內有效） |
| Data | String | - | 是 | 加密資料（加密過的 JSON 格式） |

### Request 參數範例

```json
{
    "MerchantID": "2000132",
    "RqHeader": {
        "Timestamp": 1234567890
    },
    "Data": "…"
}
```

## Data 參數說明（JSON 格式）

注意事項：請在加密前對參數值進行 URLEncode。

| 欄位名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| MerchantID | String | 10 | 是 | 特店編號 |
| InvoiceNumber | String | 10 | 是 | 發票號碼 |
| InvoiceDate | String | 10 | 是 | 發票開立日期（格式：yyyy-mm-dd） |
| Reason | String | 20 | 是 | 作廢原因 |
| Remark | String | 200 | 否 | 備註 |

### Data 參數範例

```json
{
    "MerchantID": "2000132",
    "InvoiceNumber": "VG11000002",
    "InvoiceDate": "2019-09-23",
    "Reason": "Invalid_Reason",
    "Remark": "Seller_Invalid_Remark"
}
```

## 綠界 Response 參數說明（JSON 格式）

| 欄位名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| PlatformID | String | 10 | 特約合作平台商代號 |
| MerchantID | String | 10 | 特店編號 |
| RpHeader | Object | - | 回傳資料 |
| RpHeader.Timestamp | Number | - | 回傳時間（Unix timestamp） |
| TransCode | Int | - | 回傳代碼（1=傳輸成功；實際執行結果參考 RtnCode） |
| TransMsg | String | 200 | 回傳訊息 |
| Data | String | - | 加密資料（加密過的 JSON 格式） |

### Response 參數範例

```json
{
    "MerchantID": "3002607",
    "RpHeader": {
        "Timestamp": 1234564848
    },
    "TransCode": 1,
    "TransMsg": "Success",
    "Data": "…"
}
```

## Data 參數說明（Response JSON 格式）

| 欄位名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| RtnCode | Int | - | 回應代碼（1=成功；其餘為失敗） |
| RtnMsg | String | 200 | 回應訊息 |

### Data 參數範例

```json
{
    "RtnCode": 1,
    "RtnMsg": "新增成功"
}
```
