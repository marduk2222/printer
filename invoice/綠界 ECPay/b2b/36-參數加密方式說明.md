# B2B 電子發票 API - 參數加密方式說明

## 抓取狀況

WebFetch 受版權保護限制，未能逐字重現原文。以下為摘要與已知規格。

## 加密演算法

- 演算法：**AES**
- 金鑰長度：**128 bit**
- 加密模式：**CBC**
- Padding：**PKCS7**

## 處理流程

### 加密（特店 → 綠界）

1. 將 Data 物件序列化為 JSON 字串
2. 對 JSON 字串進行 **URLEncode**（注意：採用 .NET 風格，空格編碼為 `+`，少數字元差異請對照官方範例）
3. 以 HashKey、HashIV、AES-128-CBC、PKCS7 對 URLEncode 後的字串進行加密
4. 將加密結果（Base64）放入外層 Request 的 `Data` 欄位

### 解密（綠界 → 特店）

1. 取出 Response 的 `Data`（Base64 字串）
2. 以相同的 HashKey、HashIV、AES-128-CBC、PKCS7 解密
3. 對解密結果做 **URLDecode**
4. 反序列化為 JSON 物件

## 重要注意事項

- **大小寫敏感**：URLEncode 後的字元大小寫須與綠界範例一致（PHP 預設為小寫，.NET 預設為大寫，需特別處理）
- **JSON 序列化**：建議避免額外空白，避免不同語言序列化結果差異
- **金鑰安全**：勿將 HashKey、HashIV 存放於前端或公開儲存庫
- **時間戳**：Timestamp 為 Unix TimeStamp（GMT+8），驗證區間 10 分鐘
