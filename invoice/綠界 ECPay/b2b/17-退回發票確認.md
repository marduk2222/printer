# B2B 電子發票 API - 退回發票確認

## 應用場景

交易雙方因發生發票訊息內容錯誤（如數量、單價或品名錯誤），特店收到退回發票訊息通知後，傳送退回發票確認參數給綠界，由綠界暫存相關資料。隔日將此訊息上傳至財政部電子發票整合服務平台，完成發票退回交換。

## API 介接網址

| 環境 | URL |
|------|-----|
| 測試環境 | https://einvoice-stage.ecpay.com.tw/B2BInvoice/RejectConfirm |
| 正式環境 | https://einvoice.ecpay.com.tw/B2BInvoice/RejectConfirm |

## 特店 Request 參數說明（JSON 格式）

| 欄位名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| PlatformID | String | 10 | 否 | 特約合作平台商代號，一般廠商請放空值 |
| MerchantID | String | 10 | 是 | 特店編號 |
| RqHeader | Object | - | 是 | 傳入資料 |
| RqHeader.Timestamp | Number | - | 是 | 傳入時間（Unix TimeStamp），驗證時間區間為 10 分鐘內有效 |
| Data | String | - | 是 | 加密過 JSON 格式的資料 |

### Request 參數範例

```json
{
    "MerchantID": "2000132",
    "RqHeader": {
        "Timestamp": "1525168923"
    },
    "Data": "…"
}
```

## Data 參數說明（JSON 格式）

| 欄位名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| MerchantID | String | 10 | 是 | 特店編號 |
| InvoiceNumber | String | 10 | 是 | 發票號碼 |
| InvoiceDate | String | 20 | 是 | 發票開立日期（格式：yyyy-mm-dd） |
| Remark | String | 200 | 否 | 備註 |

### Data 參數範例

```json
{
    "MerchantID": "2000132",
    "InvoiceNumber": "VG11000001",
    "InvoiceDate": "2019-09-22",
    "Remark": "Buyer_Reject_Remark"
}
```

## 綠界 Response 參數說明（JSON 格式）

| 欄位名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| PlatformID | String | 10 | 特約合作平台商代號 |
| MerchantID | String | 10 | 特店編號 |
| RpHeader | Object | - | 回傳資料 |
| RpHeader.Timestamp | Number | - | 回傳時間（Unix timestamp） |
| TransCode | Int | - | 回傳代碼（1=API 傳輸資料接收成功） |
| TransMsg | String | 200 | 回傳訊息 |
| Data | String | - | 加密過 JSON 格式的資料 |

### Response 參數範例

```json
{
    "MerchantID": "3002607",
    "RpHeader": {
        "Timestamp": 1234564848
    },
    "TransCode": 1,
    "TransMsg": "Success",
    "Data": "…"
}
```

## Data 回傳參數說明（JSON 格式）

| 欄位名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| RtnCode | Int | - | 回應代碼（1=成功，其餘為失敗） |
| RtnMsg | String | 200 | 回應訊息 |

### Data 回傳參數範例

```json
{
    "RtnCode": 1,
    "RtnMsg": "新增成功"
}
```

## 注意事項

- 時間驗證：驗證時間區間為 10 分鐘內有效
- 時間校正：合作特店須進行主機時間校正
- 加密方法：詳見[參數加密方式說明](https://developers.ecpay.com.tw/?p=15008)
