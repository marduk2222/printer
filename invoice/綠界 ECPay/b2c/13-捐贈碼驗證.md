# 綠界 B2C 電子發票 捐贈碼驗證 API

## 應用場景

特店系統可使用此 API 來驗證捐贈碼是否存在。資料來源為財政部捐贈碼資料庫，綠界會定期下載進行更新。

## API 介接網址

- **測試環境**：https://einvoice-stage.ecpay.com.tw/B2CInvoice/CheckLoveCode
- **正式環境**：https://einvoice.ecpay.com.tw/B2CInvoice/CheckLoveCode

## HTTPS 傳輸協定

- **Content Type**：application/json
- **HTTP Method**：POST

## 特店傳入參數 (Json 格式)

| 參數名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| PlatformID | String | 10 | 否 | 特約合作平台商代號（一般廠商保留為空） |
| MerchantID | String | 10 | 是 | 特店編號 |
| RqHeader | Object | - | 是 | 傳入資料標頭 |
| RqHeader.Timestamp | Number | - | 是 | 傳入時間（Unix TimeStamp, GMT+8），驗證時間區間為 10 分鐘內有效 |
| Data | String | - | 是 | 加密資料（AES 加密後的 JSON） |

### 特店傳入參數範例

```json
{
  "MerchantID": "2000132",
  "RqHeader": {
    "Timestamp": 1525168923
  },
  "Data": "加密資料"
}
```

## Data 參數說明 (Json 格式)

**處理方式**：先將 Json 字串進行 urlencode 後再進行 AES 加密

| 參數名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| MerchantID | String | 10 | 是 | 特店編號 |
| LoveCode | String | 7 | 是 | 受贈單位之捐贈碼（阿拉伯數字，最少 3 碼，最多 7 碼，首位可為零） |

### Data 參數範例

```json
{
  "MerchantID": "2000132",
  "LoveCode": "1680000"
}
```

## 綠界回傳參數格式

- **Content Type**：application/json
- **HTTP Method**：POST

## 綠界回傳參數 (Json 格式)

| 參數名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| PlatformID | String | 10 | 特約合作平台商代號 |
| MerchantID | String | 10 | 特店編號 |
| RpHeader | Object | - | 回傳資料標頭 |
| RpHeader.Timestamp | Number | - | 回傳時間（Unix timestamp, GMT+8） |
| TransCode | Int | - | 回傳代碼（1 = API 傳輸資料接收成功，實際執行結果參考 RtnCode） |
| TransMsg | String | 200 | 回傳訊息 |
| Data | String | - | 加密資料（AES 加密後的 JSON） |

### 綠界回傳參數範例

```json
{
  "MerchantID": "2000132",
  "RpHeader": {
    "Timestamp": 1525169058
  },
  "TransCode": 1,
  "TransMsg": "",
  "Data": "加密資料"
}
```

## Data 參數說明 (回傳)

**處理方式**：先將 Data 進行 AES 解密後再做 urldecode

| 參數名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| RtnCode | Int | - | 回應代碼（1 = 有取得查詢結果，其餘均為失敗） |
| RtnMsg | String | 200 | 回應訊息 |
| IsExist | String | 1 | 捐贈碼是否存在（Y = 存在；N = 不存在，僅在 RtnCode 為 1 時參考此欄位） |
| OrganName | String | 100 | 組織名稱（當 IsExist 為 Y 時才有值） |

### Data 參數範例 (回傳)

```json
{
  "RtnCode": 1,
  "RtnMsg": "成功取得查詢結果",
  "IsExist": "Y",
  "OrganName": "綠界科技"
}
```

## 注意事項

1. 使用捐贈碼時，可先呼叫此 API 進行檢核，降低輸入錯誤造成無法捐贈
2. 資料來源為財政部捐贈碼資料庫，綠界定期更新
3. 驗證時間區間為 10 分鐘內有效，超過此區間則無法建立
4. 合作特店須進行主機「時間校正」，避免時差導致 API 無法正常運作
5. 平台商需在 MerchantID 欄位中填入已綁定子廠商的特店編號
