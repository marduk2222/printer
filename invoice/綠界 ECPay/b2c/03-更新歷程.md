# 綠界 B2C 電子發票 API 更新歷程

## 2025-Q3

### 8月
- **2025-08-05**：新增參數 TaxAmount<稅額合計>
  - 一般開立發票API
  - 延遲開立發票(預約開立發票) API
  - 編輯延遲開立發票 API
  - 註銷重開 API

## 2025-Q2

### 4月
- **2025-04-17**：新增支援實體載具 悠遊卡/一卡通
- **2025-04-28**：支援 MIG 4.0

## 2025-Q1

### 1月
- **2025-01-16**：新增編輯延遲開立發票API

## 2024-Q4

### 11月
- **2024-11-8**：發票列印API – 新增參數 IsReprintInvoice<是否顯示補印發票>

## 2024-Q2

### 6月
- **2024-06-18**：新增參數 ProductServiceId<產品服務別代號>
  - 字軌與配號設定API
  - 查詢字軌 API
  - 一般開立發票 API
  - 延遲開立發票 API

## 2023-Q4

### 10月
- **2023-10-12**：調整發送發票通知API參數[NotifyMail]大小，由String(80)調整至String(200)
- **2023-10-03**：新增通路商參數(支援蝦皮)

## 2023-Q3

### 8月
- **2023-08-15**：新增統一編號驗證API
- **2023-08-01**：新增首頁注意事項說明

### 7月
- **2023-07-13**：[線上開立折讓API] 新增參數 [CheckMacValue]檢查碼
- **2023-07-05**：[發票列印API] 新增參數 [IsShowingDetail]是否顯示明細

## 2023-Q2

### 5月
- **2023-05-30**：[一般開立發票API]、[延遲開立發票API]、[註銷重開API] 參數 CustomerIdentifier 說明欄位調整檢核內容描述

## 2023-Q1

### 3月
- **2023-03-15**：新增Email相關參數格式檢核正規表達式
