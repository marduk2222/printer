# 綠界 B2C 電子發票 查詢特定多筆發票 API

## 服務概述

### 應用場景
特店可使用此 API 查詢各種類別多筆發票資訊，綠界提供 Json/CSV 格式回傳。

### 應用流程
此 API 採用分頁顯示的回傳機制，查詢結果會依照開立發票的時間由新到舊進行排序。

**步驟說明：**
- **Step1**：執行第一次 API 呼叫，設定每頁回傳筆數`[NumPerPage]`及設定顯示的頁數`[ShowingPage，固定帶 1]`，即取得綠界回應的資料總筆數`[TotalCount]`。
- **Step2**：根據 Step1 取得的資料總筆數`[TotalCount]`，以及所需的分頁筆數來決定 API 的查詢次數

**分頁範例**（TotalCount=300，每頁 100 筆時）：

| API 呼叫 | ShowingPage | NumPerPage |
|---------|------------|-----------|
| 第一次 | 1 | 100 |
| 第二次 | 2 | 100 |
| 第三次 | 3 | 100 |

### API 網址

| 環境 | 網址 |
|-----|------|

### HTTPS 傳輸協定
- **Content Type**：`application/json`
- **HTTP Method**：`POST`

## 特店傳入參數 (Json 格式)

### 頂層參數

| 參數名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| **PlatformID** | String | 10 | 否 | 特約合作平台商代號。專為與綠界簽約的指定平台商設計，只有在申請開通後才能使用。一般廠商請保留為空。對於平台商，在使用時需要在 MerchantID 欄位中填入已綁定子廠商的 MerchantID。 |
| **MerchantID** | String | 10 | **必填** | 特店編號 |
| **RqHeader** | Object | - | **必填** | 傳入資料 |
| **Data** | String | - | **必填** | 加密資料（加密過 JSON 格式的資料） |

### RqHeader 物件參數

| 參數名稱 | 型別 | 必填 | 說明 |
|---------|------|------|------|
| **Timestamp** | Number | **必填** | 傳入時間。請將傳輸時間轉換為時間戳(GMT+8)，綠界會利用此參數將當下的時間轉為 Unix TimeStamp 來驗證此次介接的時間區間。 |

**時間驗證注意事項**：
- 驗證時間區間暫訂為 **10 分鐘內有效**，若超過此驗證時間則此次訂單將無法建立
- 參考資料：http://www.epochconverter.com/
- 合作特店須進行主機「時間校正」，避免主機產生時差，導致 API 無法正常運作

### 傳入參數範例 (Json 格式)

```json
{
  "MerchantID": "2000132",
  "RqHeader": {
    "Timestamp": 1525168923
  },
  "Data": "加密資料"
}
```

## Data 參數說明 (Json 格式)

**加密方式**：請先將 Json 字串進行 urlencode 後再進行 AES 加密

### Data 參數詳細說明

| 參數名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| **MerchantID** | String | 10 | **必填** | 特店編號 |
| **BeginDate** | String | 10 | **必填** | 查詢起始日期。要查詢的發票開立開始日期，格式為「yyyy-MM-dd」或「yyyy/MM/dd」 |
| **EndDate** | String | 10 | **必填** | 查詢結束日期。要查詢的發票開立結束日期，格式為「yyyy-MM-dd」或「yyyy/MM/dd」 |
| **NumPerPage** | Int | - | **必填** | 單頁顯示筆數。**注意事項**：單頁上限為 200 筆。為了保證系統效能和響應速度，建議每頁的顯示筆數不要超過 30 筆。 |
| **ShowingPage** | Int | - | **必填** | 顯示的頁數。**注意事項**：查詢結果資料，會根據第一次開立發票的時間，按時間序較新排列至較舊。 |
| **DataType** | Int | - | 否 | 回傳資料類型。1：Json(預設)；2：CSV |
| **ChannelPartner** | String | 1 | 否 | 通路商編號。1:蝦皮；其餘數值忽略無效 |
| **Query_Award** | String | 1 | 否 | 中獎。0：全部(預設)；1：是；2：否 |
| **Query_Invalid** | String | 1 | 否 | 作廢。0：全部(預設)；1：是；2：否 |
| **Query_Print** | String | 1 | 否 | 索取紙本。0：全部(預設)；1：要；2：不要；3：已處理 |
| **Query_Upload** | String | 1 | 否 | 上傳狀態。0：全部(預設)；1：已上傳；2：未上傳；3：上傳失效 |
| **Query_Identifier** | String | 1 | 否 | 發票開立統編。0：全部(預設)；1：是；2：否 |
| **Query_TaxType** | String | 1 | 否 | 課稅別。0：全部(預設)；1：應稅；2：零稅；3：免稅；4：特種稅率；9：混合稅率 |
| **Query_Category** | String | 1 | 否 | 發票類別。0：全部(預設)；1：B2C；2：POS；3：離線 |
| **Query_Customer_Name** | String | 60 | 否 | 買受人姓名 |
| **Query_Customer_Phone** | String | 20 | 否 | 買受人手機號碼 |

### Data 參數範例 (Json 格式)

```json
{
  "MerchantID": "2000132",
  "BeginDate": "2018-10-28",
  "EndDate": "2018-11-10",
  "NumPerPage": "200",
  "ShowingPage": "2",
  "DataType": "1"
}
```

## 綠界回傳參數格式

### HTTPS 傳輸協定
- **Content Type**：`application/json`
- **HTTP Method**：`POST`

### 綠界回傳參數 (Json 格式)

| 參數名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| **PlatformID** | String | 10 | 特約合作平台商代號 |
| **MerchantID** | String | 10 | 特店編號 |
| **RpHeader** | Object | - | 回傳資料 |
| **TransCode** | Int | - | 回傳代碼。1 代表 API 傳輸資料(MerchantID, RqHeader, Data)接收成功，實際的 API 執行結果狀態請參考 RtnCode。 |
| **TransMsg** | String | 200 | 回傳訊息 |
| **Data** | String | - | 回傳要求資料，此為未加密過 JSON 格式的資料。 |

### RpHeader 物件參數

| 參數名稱 | 型別 | 說明 |
|---------|------|------|
| **Timestamp** | Number | 回傳時間。Unix timestamp(GMT+8) |

### 綠界回傳參數範例

```json
{
  "MerchantID": "2000132",
  "RpHeader": {
    "Timestamp": 1525169058
  },
  "TransCode": 1,
  "TransMsg": "",
  "Data": "..."
}
```

## Data 參數說明 (回傳 Json 格式)

**解密方式**：請先將 Data 進行 AES 解密後再做 urldecode

### 回傳參數詳細說明

| 參數名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| **RtnCode** | Int | - | 回應代碼。1 代表 API 執行成功，其餘代碼均為失敗。 |
| **RtnMsg** | String | 200 | 回應訊息 |
| **TotalCount** | Number | - | 總筆數 |
| **ShowingPage** | Int | - | 顯示的頁數 |
| **InvoiceData** | Array[Object] | - | 發票資料 |

| **IIS_Clearance_Mark** | String | 1 | 通關方式。**注意事項**：只有零稅率才會回傳以下資料。1：非經海關出口；2：經海關出口 |
| **IIS_Category** | String | 10 | 發票類別。B2B：表示開立發票時有含統編；B2C：表示開立發票時沒有含統編 |

| **IIS_Issue_Status** | String | 1 | 發票開立狀態。1：發票開立；0：發票註銷 |
| **IIS_Invalid_Status** | String | 1 | 發票作廢狀態。1：已作廢時；0：未作廢 |
| **IIS_Upload_Status** | String | 1 | 發票上傳狀態。1：已上傳；0：未上傳 |
| **IIS_Upload_Date** | String | 20 | 發票上傳時間。格式為「yyyy-MM-dd」或 「yyyy/MM/dd」 |
| **IIS_Turnkey_Status** | String | 1 | 發票上傳後接收狀態。C：成功；E：失敗。**注意事項**：當 IIS_Upload_Status = 0(未上傳)，IIS_Turnkey_Status 不會有值；當 IIS_Upload_Status = 1(已上傳)，IIS_Turnkey_Status 可能是 C(成功)或 E(失敗) |

## 加解密說明

### 參數加密方式

Data 參數需進行下列步驟加密：
1. 將 Json 字串進行 **urlencode**
2. 進行 **AES 加密**

### 參數解密方式

回傳 Data 參數需進行下列步驟解密：
1. 進行 **AES 解密**
2. 進行 **urldecode**
