# 綠界 B2C 電子發票 查詢折讓明細 API

## 應用場景

此 API 用於查詢已開立折讓之發票資訊，但不包含消費者尚未同意之線上折讓單。

## API 介接網址

- **測試環境**：https://einvoice-stage.ecpay.com.tw/B2CInvoice/GetAllowanceList
- **正式環境**：https://einvoice.ecpay.com.tw/B2CInvoice/GetAllowanceList

## HTTPS 傳輸協定

- **Content Type**：application/json
- **HTTP Method**：POST

## 特店傳入參數 (Json 格式)

| 參數 | 型別 | 長度 | 必填 | 說明 |
|------|------|------|------|------|
| **PlatformID** | String | 10 | 否 | 特約合作平台商代號。專為與綠界簽約的平台商設計，一般廠商保留為空 |
| **MerchantID** | String | 10 | 是 | 特店編號 |
| **RqHeader** | Object | - | 是 | 傳入資料 |
| **RqHeader.Timestamp** | Number | - | 是 | 傳入時間，Unix TimeStamp (GMT+8)。驗證時間區間為 10 分鐘內有效 |
| **Data** | String | - | 是 | 加密資料，加密過 JSON 格式的資料 |

### 特店傳入參數範例

```json
{
    "MerchantID": "2000132",
    "RqHeader": {
        "Timestamp": 1525168923
    },
    "Data": "加密資料"
}
```

## Data 參數說明 (Json 格式)

**處理方式**：請先將 Json 字串進行 urlencode 後再進行 AES 加密

| 參數 | 型別 | 長度 | 必填 | 說明 |
|------|------|------|------|------|
| **MerchantID** | String | 10 | 是 | 特店編號 |
| **SearchType** | String | 1 | 是 | 查詢方式。0: 折讓編號查詢；1: 發票號碼+發票開立日期查詢；2: 發票號碼+發票折讓日期查詢 |
| **AllowanceNo** | String | 16 | 條件式 | 折讓編號。當 SearchType=0 時必填 |
| **InvoiceNo** | String | 10 | 條件式 | 發票號碼。當 SearchType=1 或 2 時必填 |
| **Date** | String | 10 | 條件式 | 日期。SearchType=1 時為發票開立日期，SearchType=2 時為發票折讓日期。格式為「yyyy-MM-dd」或「yyyy/MM/dd」 |

### Data 參數範例

```json
{
    "MerchantID": 2000132,
    "SearchType": "0",
    "AllowanceNo": "2019091719477262"
}
```

## 綠界回傳參數格式

- **Content Type**：application/json
- **HTTP Method**：POST

## 綠界回傳參數 (Json 格式)

| 參數 | 型別 | 長度 | 說明 |
|------|------|------|------|
| **PlatformID** | String | 10 | 特約合作平台商代號 |
| **MerchantID** | String | 10 | 特店編號 |
| **RpHeader** | Object | - | 回傳資料 |
| **RpHeader.Timestamp** | Number | - | 回傳時間，Unix timestamp (GMT+8) |
| **TransCode** | Int | - | 回傳代碼。1 代表 API 傳輸資料接收成功，實際執行結果請參考 RtnCode |
| **TransMsg** | String | 200 | 回傳訊息 |
| **Data** | String | - | 加密資料，加密過 JSON 格式的資料 |

### 綠界回傳參數範例

```json
{
    "MerchantID": "2000132",
    "RpHeader": {
        "Timestamp": 1525169058
    },
    "TransCode": 1,
    "TransMsg": "",
    "Data": "加密資料"
}
```

## Data 參數說明 (回傳)

**處理方式**：請先將 Data 進行 AES 解密後再做 urldecode

| 參數 | 型別 | 長度 | 說明 |
|------|------|------|------|
| **RtnCode** | Int | - | 回應代碼。1 代表 API 執行成功，其餘代碼均為失敗 |
| **RtnMsg** | String | 200 | 回應訊息 |
| **AllowanceInfo** | Array | - | 折讓資訊列表 |

### Data 參數範例

```json
{
    "RtnCode": 1,
    "RtnMsg": "成功",
    "AllowanceInfo": [
        {...},
        {...}
    ]
}
```

| **IA_Tax_Type** | String | 1 | 課稅別。1: 應稅；2: 零稅率；3: 免稅；4: 應稅(特種稅率) |

## 加解密說明

- **加密方法**：詳見[參數加密方式說明](https://developers.ecpay.com.tw/7958/)
- 傳入 Data 參數：先將 Json 字串進行 urlencode 後再進行 AES 加密
- 回傳 Data 參數：先進行 AES 解密後再做 urldecode

## 注意事項

### 時間戳相關
- 驗證時間區間暫訂為 10 分鐘內有效，若超過此驗證時間則此次訂單將無法建立
- 合作特店須進行主機「時間校正」，避免主機產生時差，導致 API 無法正常運作

### 平台商相關
- PlatformID 參數專為與綠界簽約的指定平台商所設計，只有在申請開通後才能使用
- 一般廠商請將此參數欄位保留為空
- 平台商使用時需在 MerchantID 欄位中填入已綁定子廠商的 MerchantID
- 只能使用已綁定的子廠商編號，以避免操作失敗
