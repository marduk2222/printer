# 綠界 B2C 電子發票 API - 字軌與配號設定

## 應用場景

營業人取得財政部配號結果後，可建立當年度或下個年度的字軌。在開立發票之前，需先設定字軌區間，並可設定多組。

## 重要注意事項

### 電子發票號碼分配規則
- 電子發票號碼為 50 個一組
- 起始號碼尾數必為 00 或 50
- 結尾號碼尾數必為 49 或 99
- 分配時應以 50 個號碼為單位

### 字軌設定限制
- 不可於多個發票系統設定相同字軌號碼
- 新增字軌前需自行檢核正確性
- 新增後字軌狀態預設為已審核但未啟用，須使用「設定字軌號碼狀態」進行啟用

## API 介接資訊

| 項目 | 內容 |
|------|------|
| 測試環境 | https://einvoice-stage.ecpay.com.tw/B2CInvoice/AddInvoiceWordSetting |
| 正式環境 | https://einvoice.ecpay.com.tw/B2CInvoice/AddInvoiceWordSetting |
| Content Type | application/json |
| HTTP Method | POST |
| 傳輸協定 | HTTPS |

## 特店傳入參數（JSON）

| 參數名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| PlatformID | String | 10 | 否 | 特約合作平台商代號；一般廠商保留為空 |
| MerchantID | String | 10 | **是** | 特店編號 |
| RqHeader | Object | - | **是** | 傳入資料 |
| Timestamp | Number | - | **是** | 傳入時間（Unix TimeStamp GMT+8）；驗證時間區間為 10 分鐘內有效 |
| Data | String | - | **是** | 加密資料（加密前需進行 urlencode） |

## Data 參數說明（JSON）

| 參數名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| MerchantID | String | 10 | **是** | 特店編號 |
| InvoiceTerm | Int | - | **是** | 發票期別；1:1-2月、2:3-4月、3:5-6月、4:7-8月、5:9-10月、6:11-12月；不可帶入小於當年的期別 |
| InvoiceYear | String | 3 | **是** | 發票年度（ROC年份）；僅可設定當年與明年 |
| InvType | String | 2 | **是** | 字軌類別；07:一般稅額發票、08:特種稅額發票 |
| InvoiceCategory | String | 1 | **是** | 發票種類；B2C 固定為 1 |
| ProductServiceId | String | 10 | 否 | 產品服務別代號；需啟用【B2C系統多組字軌】開關才會處理 |
| InvoiceHeader | String | 2 | **是** | 發票字軌 |
| InvoiceStart | String | 8 | **是** | 起始發票編號；8碼，尾數需為 00 或 50 |
| InvoiceEnd | String | 8 | **是** | 結束發票編號；8碼，尾數需為 49 或 99 |

## 特店傳入參數範例

```json
{
  "MerchantID": "2000132",
  "RqHeader": {
    "Timestamp": 1525168923
  },
  "Data": "加密資料"
}
```

## Data 參數範例

```json
{
  "MerchantID": "2000132",
  "InvoiceTerm": "1",
  "InvoiceYear": "109",
  "InvType": "07",
  "InvoiceCategory": "1",
  "InvoiceHeader": "TW",
  "InvoiceStart": "10000000",
  "InvoiceEnd": "10000049"
}
```

## 綠界回傳參數（JSON）

| 參數名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| PlatformID | String | 10 | 特約合作平台商代號 |
| MerchantID | String | 10 | 特店編號 |
| RpHeader | Object | - | 回傳資料 |
| Timestamp | Number | - | 回傳時間（Unix timestamp GMT+8） |
| TransCode | Int | - | 回傳代碼；1 代表 API 傳輸接收成功 |
| TransMsg | String | 200 | 回傳訊息 |
| Data | String | - | 加密資料（加密過JSON格式） |

## 綠界回傳參數範例

```json
{
  "MerchantID": "2000132",
  "RpHeader": {
    "Timestamp": 1525169058
  },
  "TransCode": 1,
  "TransMsg": "",
  "Data": "加密資料"
}
```

## Data 參數說明（回傳）

| 參數名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| RtnCode | Int | - | 回應代碼；1 代表 API 執行成功 |
| RtnMsg | String | 200 | 回應訊息 |
| TrackID | String | 10 | 字軌號碼ID；需留存作為設定字軌號碼啟用狀態用 |

## Data 參數範例（回傳）

```json
{
  "RtnCode": 1,
  "RtnMsg": "成功",
  "TrackID": "1234567890"
}
```

## 加解密說明

- **加密流程**：先將 JSON 字串進行 urlencode，再進行 AES 加密
- **解密流程**：先將 Data 進行 AES 解密，再做 urldecode

詳細加密方法請參考「參數加密方式說明」文件。
