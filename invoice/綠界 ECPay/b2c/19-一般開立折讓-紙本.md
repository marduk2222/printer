# 綠界 B2C 電子發票 一般開立折讓（紙本開立）API

## 功能概述

營業人可使用此功能將折讓開立參數傳送至綠界，由綠界暫存折讓資料。綠界於隔日將折讓資料上傳至財政部電子發票整合服務平台，並通知消費者折讓已開立。

## 應用場景

商品因質量、規格等不符合消費者要求時，特店可使用此 API 將開立折讓發票參數傳送至綠界，暫存折讓發票資料。綠界會於隔日將折讓資料上傳至財政部電子發票整合服務平台。

**重要注意事項**：根據財政部規定，API 送出紙本折讓資料後，還需買受人確認折讓單內容，您必須郵寄紙本折讓單給消費者簽名後寄回自行存檔，以備主管機關不定期查核。

## 特店傳入參數（Json 格式）

### PlatformID
- **型別**：String(10)
- **欄位名稱**：特約合作平台商代號
- **說明**：此參數專為與綠界簽約的指定平台商設計，只有申請開通後才能使用。一般廠商請保留為空。平台商需在 MerchantID 欄位填入已綁定子廠商的 MerchantID。

### MerchantID
- **型別**：String(10)
- **欄位名稱**：特店編號
- **必填**：是

### RqHeader
- **型別**：Object
- **欄位名稱**：傳入資料
- **必填**：是

#### Timestamp
- **型別**：Number
- **欄位名稱**：傳入時間
- **必填**：是
- **說明**：將傳輸時間轉換為時間戳（GMT+8）。綠界利用此參數將時間轉為 Unix TimeStamp 驗證介接時間區間。驗證時間區間暫訂為 10 分鐘內有效，超過此時間則訂單無法建立。合作特店須進行主機「時間校正」，避免時差導致 API 無法正常運作。

### Data
- **型別**：String
- **欄位名稱**：加密資料
- **必填**：是
- **說明**：此為加密過 JSON 格式的資料，需先進行 urlencode 後再進行 AES 加密。

### 特店傳入參數範例

```json
{
  "MerchantID": "2000132",
  "RqHeader": {
    "Timestamp": 1525168923
  },
  "Data": "加密資料"
}
```

## Data 參數說明（Json 格式）

**前置作業**：請先將 Json 字串進行 urlencode 後再進行 AES 加密

### MerchantID
- **型別**：String(10)
- **欄位名稱**：特店編號
- **必填**：是

### InvoiceNo
- **型別**：String(10)
- **欄位名稱**：發票號碼
- **必填**：是
- **說明**：長度固定為 10 碼

### InvoiceDate
- **型別**：String(10)
- **欄位名稱**：發票開立日期
- **必填**：是
- **格式**：「yyyy-MM-dd」或「yyyy/MM/dd」

### AllowanceNotify
- **型別**：String(1)
- **欄位名稱**：通知類別
- **必填**：是
- **列舉值**：
  - S：簡訊
  - E：電子郵件
  - A：皆通知時
  - N：皆不通知
- **說明**：開立折讓後，寄送相關發票折讓資訊通知消費者

### CustomerName
- **型別**：String(60)
- **欄位名稱**：客戶名稱
- **說明**：格式為中、英文及數字等

### NotifyMail
- **型別**：String(100)
- **欄位名稱**：通知電子信箱
- **說明**：
  - 若通知類別（AllowanceNotify）為電子郵件（E），此欄位須有值
  - 需為有效的 Email 格式
  - 可帶入多組 Email，並以分號區隔（例：aa@aa.aa;bb@bb.bb）

### NotifyPhone
- **型別**：String(20)
- **欄位名稱**：通知手機號碼
- **說明**：
  - 若通知類別（AllowanceNotify）為簡訊方式（S），此欄位須有值
  - 格式為數字組成

### AllowanceAmount
- **型別**：Number
- **欄位名稱**：折讓單總金額（含稅）
- **必填**：是
- **規格**：支援整數 12 位
- **注意事項**：
  - 該筆折讓單總金額應該大於 0 元
  - 如此張發票未折讓過，則應小於或等於原發票總金額
  - 如此張發票已折讓過，則應小於或等於折讓剩餘金額
  - 折讓單總金額設 0 元不被允許，因為此代表此張發票不需折讓

### Reason
- **型別**：String(50)
- **欄位名稱**：折讓原因

### Items
- **型別**：Array[Object]
- **欄位名稱**：商品

#### ItemSeq
- **型別**：Int
- **欄位名稱**：商品序號
- **必填**：是

#### ItemName
- **型別**：String(500)
- **欄位名稱**：商品名稱
- **必填**：是
- **說明**：不可為空字串

#### ItemCount
- **型別**：Number
- **欄位名稱**：商品數量
- **必填**：是
- **規格**：支援整數 8 位，小數 7 位

#### ItemWord
- **型別**：String(6)
- **欄位名稱**：商品單位
- **必填**：是

#### ItemPrice
- **型別**：Number
- **欄位名稱**：商品單價
- **必填**：是
- **規格**：支援整數 10 位，小數 7 位

#### ItemTaxType
- **型別**：String(1)
- **欄位名稱**：商品課稅別
- **列舉值**：
  - 1：應稅
  - 2：零稅率
  - 3：免稅
- **注意事項**：
  - 預設為空字串，當課稅類別（TaxType）= 9 時，此欄位不可為空
  - 課稅類別為混合稅率時，需含二筆或以上的商品課稅別，且至少需有一筆商品課稅別為應稅及至少需有一筆商品課稅別為免稅或零稅率
  - 混稅發票只能：
    - 應稅 + 免稅
    - 應稅 + 零稅率
  - 免稅和零稅率發票不能同時開立

#### ItemAmount
- **型別**：Number
- **欄位名稱**：商品合計
- **必填**：是
- **說明**：此為含稅小計金額，支援整數 12 位，小數 7 位
- **注意事項**：
  - 假設 A = 商品單價（ItemPrice）× 商品數量（ItemCount），則 A 與商品合計（ItemAmount）允許 1 元以內的誤差
  - 各商品之商品合計（ItemAmount）加總需等於折讓單總金額（AllowanceAmount）
  - 依營業稅電子資料申報繳稅作業要點，電子發票銷貨退回、進貨退出或折讓證明單之「金額（不含稅之進貨額）」及「營業稅額」欄位須為整數，建議此欄位請帶入整數

### Data 參數範例

```json
{
  "MerchantID": "2000132",
  "InvoiceNo": "UV11100013",
  "InvoiceDate": "2019/09/17",
  "AllowanceNotify": "E",
  "CustomerName": "綠界科技股份有限公司",
  "NotifyMail": "test@ecpay.com.tw",
  "NotifyPhone": "0912345678",
  "AllowanceAmount": 50,
  "Items": [
    {
      "ItemSeq": 1,
      "ItemName": "item01",
      "ItemCount": 1,
      "ItemWord": "件",
      "ItemPrice": 50,
      "ItemTaxType": "2",
      "ItemAmount": 50
    }
  ]
}
```

## 綠界回傳參數格式

- **Content Type**：application/json
- **HTTP Method**：POST

## 綠界回傳參數（Json 格式）

### PlatformID
- **型別**：String(10)
- **欄位名稱**：特約合作平台商代號

### MerchantID
- **型別**：String(10)
- **欄位名稱**：特店編號

### RpHeader
- **型別**：Object
- **欄位名稱**：回傳資料

#### Timestamp
- **型別**：Number
- **欄位名稱**：回傳時間
- **說明**：Unix timestamp（GMT+8）

### TransCode
- **型別**：Int
- **欄位名稱**：回傳代碼
- **說明**：1 代表 API 傳輸資料（MerchantID, RqHeader, Data）接收成功，實際的 API 執行結果狀態請參考 RtnCode

### TransMsg
- **型別**：String(200)
- **欄位名稱**：回傳訊息

### Data
- **型別**：String
- **欄位名稱**：加密資料
- **說明**：回傳相關資料，此為加密過 JSON 格式的資料。請先將 Data 進行 AES 解密後再做 urldecode

### 綠界回傳參數範例

```json
{
  "MerchantID": "2000132",
  "RpHeader": {
    "Timestamp": 1525169058
  },
  "TransCode": 1,
  "TransMsg": "",
  "Data": "加密資料"
}
```

## Data 參數說明（Json 格式）

**前置作業**：請先將 Data 進行 AES 解密後再做 urldecode

### RtnCode
- **型別**：Int
- **欄位名稱**：回應代碼
- **說明**：1 代表 API 執行成功，其餘代碼均為失敗

### RtnMsg
- **型別**：String(200)
- **欄位名稱**：回應訊息

### IA_Allow_No
- **型別**：String(16)
- **欄位名稱**：折讓單號
- **說明**：
  - 開立成功，會回傳折讓單號
  - 開立失敗，則會回傳空值

### IA_Invoice_No
- **型別**：String(10)
- **欄位名稱**：發票號碼
- **說明**：
  - 開立成功，會回傳當初開立的發票號碼
  - 開立失敗，則會回傳空值

### IA_Date
- **型別**：String(20)
- **欄位名稱**：折讓時間
- **說明**：
  - 開立成功，會回傳開立折讓時間，回傳格式為「yyyy-MM-dd HH:mm:ss」
  - 開立失敗，則會回傳空值

### IA_Remain_Allowance_Amt
- **型別**：Number
- **欄位名稱**：折讓剩餘金額
- **規格**：支援整數 12 位
- **說明**：
  - 開立成功，會回傳開立折讓後剩餘金額
  - 開立失敗，則會回傳空值

### Data 參數範例

```json
{
  "IA_Allow_No": "2019091717363987",
  "IA_Invoice_No": "UV11100013",
  "IA_Date": "2019-09-17 17:36:18",
  "IA_Remain_Allowance_Amt": 50,
  "RtnCode": 1,
  "RtnMsg": "折讓單資料新增成功"
}
```

## 使用流程圖

營業人將折讓開立參數傳送至綠界 → 綠界暫存折讓資料 → 隔日綠界上傳折讓資料至財政部電子發票整合服務平台 → 通知消費者折讓已開立
