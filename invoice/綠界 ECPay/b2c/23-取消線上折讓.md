# 綠界 B2C 電子發票 取消線上折讓 API

## 功能概述

此 API 允許營業人（特店）取消已申請的線上折讓。「綠界收到後會將該筆折讓申請取消並返還額度至該發票可折讓金額」。

## 應用場景

特店開立線上折讓後，若欲取消折讓，可使用此 API。綠界系統將取消該筆申請，並將折讓金額返還至該發票可折讓額度。

## API 連接位址

| 環境 | URL |
|------|-----|
| 測試環境 | `https://einvoice-stage.ecpay.com.tw/B2CInvoice/AllowanceInvalidByCollegiate` |
| 正式環境 | `https://einvoice.ecpay.com.tw/B2CInvoice/AllowanceInvalidByCollegiate` |

## 傳輸協定

- **Content Type**：application/json
- **HTTP Method**：POST

## 特店傳入參數（JSON 格式）

| 欄位名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| PlatformID | String | 10 | 否 | 特約合作平台商代號，非平台商請保留空值 |
| MerchantID | String | 10 | **是** | 特店編號 |
| RqHeader | Object | - | **是** | 傳入資料 |
| RqHeader.Timestamp | Number | - | **是** | 傳入時間（Unix timestamp，GMT+8），驗證時間區間為 10 分鐘內有效 |
| Data | String | - | **是** | 加密資料（AES 加密的 JSON） |

## 特店傳入參數範例

```json
{
    "MerchantID": "2000132",
    "RqHeader": {
        "Timestamp": 1525168923
    },
    "Data": "加密資料"
}
```

## Data 參數說明（JSON 格式）

> 請先將 JSON 字串進行 urlencode 後再進行 AES 加密

| 欄位名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| MerchantID | String | 10 | **是** | 特店編號 |
| InvoiceNo | String | 10 | **是** | 發票號碼（固定 10 碼） |
| AllowanceNo | String | 16 | **是** | 折讓編號 |
| Reason | String | 20 | **是** | 取消原因 |

## Data 參數範例

```json
{
    "MerchantID": 2000132,
    "InvoiceNo": "AA123456",
    "AllowanceNo": "2016022615195209",
    "Reason": ""
}
```

## 綠界回傳參數格式

- **Content Type**：application/json
- **HTTP Method**：POST

## 綠界回傳參數（JSON 格式）

| 欄位名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| PlatformID | String | 10 | 特約合作平台商代號 |
| MerchantID | String | 10 | 特店編號 |
| RpHeader | Object | - | 回傳資料 |
| RpHeader.Timestamp | Number | - | 回傳時間（Unix timestamp，GMT+8） |
| TransCode | Int | - | 回傳代碼（1 表示 API 傳輸資料接收成功，實際執行結果請參考 RtnCode） |
| TransMsg | String | 200 | 回傳訊息 |
| Data | String | - | 加密資料（AES 加密的 JSON） |

## 綠界回傳參數範例

```json
{
    "MerchantID": "2000132",
    "RpHeader": {
        "Timestamp": 1525169058
    },
    "TransCode": 1,
    "TransMsg": "",
    "Data": "加密資料"
}
```

## Data 參數說明（回應）

> 請先將 Data 進行 AES 解密後再做 urldecode

| 欄位名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| RtnCode | Int | - | 回應代碼（1 表示 API 執行成功，其餘代碼均為失敗） |
| RtnMsg | String | 200 | 回應訊息 |
| IA_Invoice_No | String | 10 | 發票號碼（取消成功則回傳發票號碼；失敗則回傳空值） |

## Data 參數範例（回應）

```json
{
    "RtnCode": "1",
    "RtnMsg": "取消成功",
    "IA_Invoice_No": "AA123456"
}
```

## 重要注意事項

- **時間校正**：合作特店須進行主機「時間校正」，避免時差導致 API 無法正常運作
- **時間驗證**：驗證時間區間為 10 分鐘內有效，超過此時間則訂單無法建立
- **加密方式**：[參數加密方式說明](https://developers.ecpay.com.tw/7958/)
- **平台商使用**：若為平台商，需在 MerchantID 欄位填入已綁定的子廠商編號
