# 綠界 B2C 電子發票 作廢發票 API

## 功能概述

營業人(特店)可透過此 API 將發票作廢參數傳送至綠界，由綠界暫存資料並「於隔日將作廢資料上傳至財政部電子發票整合服務平台，並通知消費者電子發票已作廢」。

## 應用場景

適用於商品不符要求、退貨或發票開立錯誤等情況下作廢已開立發票。

## 重要注意事項

1. 「發票若已被折讓過，無法直接作廢發票並請確認該發票所開立的折讓單是否全部已作廢」
2. 每年奇數月 13 號 23:59:59 後因已申報至財政部，「無法作廢前兩個月開立的發票」

## API 介接網址

- **測試環境**：https://einvoice-stage.ecpay.com.tw/B2CInvoice/Invalid
- **正式環境**：https://einvoice.ecpay.com.tw/B2CInvoice/Invalid

## 傳輸協定

- Content Type：application/json
- HTTP Method：POST

## 特店傳入參數說明

| 參數 | 型別 | 長度 | 必填 | 說明 |
|------|------|------|------|------|
| PlatformID | String | 10 | ✗ | 特約合作平台商代號（平台商專用） |
| MerchantID | String | 10 | ✓ | 特店編號 |
| RqHeader | Object | - | ✓ | 傳入資料 |
| Timestamp | Number | - | ✓ | 傳入時間(Unix TimeStamp GMT+8)，驗證時間區間 10 分鐘內有效 |
| Data | String | - | ✓ | 加密資料(JSON 格式) |

### Data 參數內容說明

| 參數 | 型別 | 長度 | 必填 | 說明 |
|------|------|------|------|------|
| MerchantID | String | 10 | ✓ | 特店編號 |
| InvoiceNo | String | 10 | ✓ | 發票號碼（固定 10 碼） |
| InvoiceDate | String | 10 | ✓ | 發票開立日期(yyyy-MM-dd or yyyy/MM/dd) |
| Reason | String | 20 | ✓ | 作廢原因 |

## Request 參數範例

```json
{
  "MerchantID": "2000132",
  "RqHeader": {
    "Timestamp": 1525168923
  },
  "Data": "加密資料"
}
```

## Data 參數範例（加密前）

```json
{
  "MerchantID": 2000132,
  "InvoiceNo": "AA123456",
  "InvoiceDate": "2019-09-17",
  "Reason": ""
}
```

## 綠界回傳參數說明

| 參數 | 型別 | 長度 | 說明 |
|------|------|------|------|
| PlatformID | String | 10 | 特約合作平台商代號 |
| MerchantID | String | 10 | 特店編號 |
| RpHeader | Object | - | 回傳資料 |
| Timestamp | Number | - | 回傳時間(Unix timestamp GMT+8) |
| TransCode | Int | - | 回傳代碼(1 代表傳輸成功) |
| TransMsg | String | 200 | 回傳訊息 |
| Data | String | - | 加密資料(JSON 格式) |

## Response 參數範例

```json
{
  "MerchantID": "2000132",
  "RpHeader": {
    "Timestamp": 1525169058
  },
  "TransCode": 1,
  "TransMsg": "",
  "Data": "加密資料"
}
```

## Data 回傳參數說明（解密後）

| 參數 | 型別 | 長度 | 說明 |
|------|------|------|------|
| RtnCode | Int | - | 回應代碼(1 代表執行成功) |
| RtnMsg | String | 200 | 回應訊息 |
| InvoiceNo | String | 10 | 發票號碼(成功時回傳，失敗時為空值) |

## Data 回傳參數範例

```json
{
  "RtnCode": "1",
  "RtnMsg": "作廢發票成功",
  "InvoiceNo": "AA123456"
}
```

## 加解密說明

- **加密流程**：先將 Data 參數(JSON 格式)進行 urlencode，再進行 AES 加密
- **解密流程**：先將回傳 Data 進行 AES 解密，再做 urldecode
