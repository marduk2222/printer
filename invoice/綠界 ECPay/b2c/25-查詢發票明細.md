# 綠界 B2C 電子發票 查詢發票明細 API

## 應用場景

特店可使用此 API 查詢已開立發票資訊，綠界以回傳參數方式回覆該張發票資料。此方式協助營業人將查詢發票機制整合至營業人網站，「提供買受人可於營業人網站快速查詢」。如有多筆大量查詢需求，建議使用查詢特定多筆發票。

## API 介接網址

- **測試環境**：https://einvoice-stage.ecpay.com.tw/B2CInvoice/GetIssue
- **正式環境**：https://einvoice.ecpay.com.tw/B2CInvoice/GetIssue

## HTTPS 傳輸協定

- **Content Type**：application/json
- **HTTP Method**：POST

## 特店傳入參數（Json 格式）

| 欄位名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| PlatformID | String | 10 | 否 | 特約合作平台商代號。僅限與綠界簽約的指定平台商使用；一般廠商保留為空 |
| MerchantID | String | 10 | **是** | 特店編號 |
| RqHeader | Object | - | **是** | 傳入資料物件 |
| RqHeader.Timestamp | Number | - | **是** | 傳入時間（Unix TimeStamp, GMT+8）。驗證時間區間為 10 分鐘內有效 |
| Data | String | - | **是** | 加密資料（AES 加密的 JSON 格式） |

### 特店傳入參數範例

```json
{
  "MerchantID": "2000132",
  "RqHeader": {
    "Timestamp": 1525168923
  },
  "Data": "加密資料"
}
```

## 情境一：以特店自訂編號 [RelateNumber] 做查詢

### Data 參數說明（Json 格式）

*請先將 Json 字串進行 urlencode 後再進行 AES 加密*

| 欄位名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| MerchantID | String | 10 | **是** | 特店編號 |
| RelateNumber | String | 50 | **是** | 特店自訂編號。需為唯一值不可重複使用，勿使用特殊符號 |

### Data 參數範例

```json
{
  "MerchantID": 2000132,
  "RelateNumber": "20181028000000020"
}
```

## 情境二：以發票號碼 [InvoiceNo] 與發票開立日期 [InvoiceDate] 做查詢

### Data 參數說明（Json 格式）

*請先將 Json 字串進行 urlencode 後再進行 AES 加密*

| 欄位名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| MerchantID | String | 10 | **是** | 特店編號 |
| InvoiceNo | String | 10 | **是** | 發票號碼 |
| InvoiceDate | String | 10 | **是** | 發票開立日期。格式為「yyyy-MM-dd」或「yyyy/MM/dd」 |

### Data 參數範例

```json
{
  "MerchantID": "2000132",
  "InvoiceNo": "AA123456",
  "InvoiceDate": "2018-10-28"
}
```

## 綠界回傳參數格式

- **Content Type**：application/json
- **HTTP Method**：POST

## 綠界回傳參數（Json 格式）

| 欄位名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| PlatformID | String | 10 | 特約合作平台商代號 |
| MerchantID | String | 10 | 特店編號 |
| RpHeader | Object | - | 回傳資料物件 |
| RpHeader.Timestamp | Number | - | 回傳時間（Unix timestamp, GMT+8） |
| TransCode | Int | - | 回傳代碼。1 代表 API 傳輸資料接收成功 |
| TransMsg | String | 200 | 回傳訊息 |
| Data | String | - | 加密資料（AES 加密的 JSON 格式） |

### 綠界回傳參數範例

```json
{
  "MerchantID": "2000132",
  "RpHeader": {
    "Timestamp": 1525169058
  },
  "TransCode": 1,
  "TransMsg": "",
  "Data": "加密資料"
}
```

## 電子發票 QRCODE 示意圖說明

QRCODE 僅顯示前 2 個商品品項，完整商品品項請以上傳財政部內容為主。

## 加密方式說明

Data 參數需進行以下處理：
1. 將 JSON 字串進行 **urlencode**
2. 進行 **AES 加密**
3. 回傳時需進行 **AES 解密**
4. 再進行 **urldecode**

詳細說明請參考「參數加密方式說明」文件。

## 重要注意事項

- **時間校正**：合作特店須進行主機「時間校正」，避免主機產生時差，導致 API 無法正常運作
- **驗證時間區間**：暫訂為 10 分鐘內有效
- **RelateNumber 特殊符號**：勿使用特殊符號
- **QRCode 顯示限制**：為避免 QR Code 過於複雜無法辨識，僅顯示前 2 個商品品項
