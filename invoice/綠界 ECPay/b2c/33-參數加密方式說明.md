# 綠界 B2C 電子發票 參數加密方式說明

## 概述

綠界會提供 AES 加解密用的 Key 及 IV，請將要加密資料先做 URL Encode 編碼，再進行 AES 加密。

## AES 加密規格

加密設定包含以下參數：
- **加密強度**：128 bit
- **CipherMode**：CBC
- **PaddingMode**：PKCS7

## 重要注意事項

1. 範例資訊僅供測試使用，不應用於正式環境
2. 正式環境需使用特店自有的密鑰資訊

## 加密流程演示

### 測試範例認證資料
- MerchantID：2000132
- HashKey：ejCk326UnaZWKisg
- HashIV：q9jcZX8Ib9LM8wYk

### 加密步驟

**原始資料**：
```json
{"Name":"Test","ID":"A123456789"}
```

**步驟一**：URLEncode 編碼（注意大小寫差異會造成不同結果）

**步驟二**：使用 HashKey、HashIV 進行 AES 加密（128 bit、CBC、PKCS7）

**步驟三**：得到加密後的字串作為 Data 欄位送出

## 解密流程演示

解密過程為加密的逆向操作：

加密文本 → AES 解密 → URLDecode 解碼 → 原始資料

## 加密重點摘要

- **加密順序**：先 URLEncode、再 AES 加密
- **解密順序**：先 AES 解密、再 URLDecode
- 多數綠界範例採大寫 URLEncode 結果（與 .NET HttpUtility.UrlEncode 行為一致）
- 各語言實作差異請參考「URLEncode 轉換表」進行字元替換
