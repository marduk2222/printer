# 綠界 B2C 電子發票 作廢折讓 API

## 功能概述

此 API 允許營業人(特店)將折讓作廢參數傳送至綠界，綠界於隔日將作廢資料上傳至財政部電子發票整合服務平台，並通知消費者折讓已作廢。

## 應用場景

特店開立折讓後若需取消或修正，可使用此功能將已開立的折讓部分作廢(非整張發票作廢)。

## API 接口資訊

| 項目 | 內容 |
|------|------|
| **測試環境** | https://einvoice-stage.ecpay.com.tw/B2CInvoice/AllowanceInvalid |
| **正式環境** | https://einvoice.ecpay.com.tw/B2CInvoice/AllowanceInvalid |
| **Content Type** | application/json |
| **HTTP Method** | POST |

## 特店傳入參數(Json 格式)

### 頂層參數

| 欄位名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| PlatformID | String | 10 | 否 | 特約合作平台商代號(非平台商請留空) |
| MerchantID | String | 10 | 是 | 特店編號 |
| RqHeader | Object | - | 是 | 傳入資料 |
| Data | String | - | 是 | 加密資料(AES 加密的 urlencode JSON 字串) |

### RqHeader 物件

| 欄位名稱 | 型別 | 必填 | 說明 |
|---------|------|------|------|
| Timestamp | Number | 是 | 傳入時間(Unix TimeStamp, GMT+8) |

**時間驗證說明**：
- 驗證時間區間為 10 分鐘內有效
- 超過驗證時間則訂單無法建立
- 特店須進行主機時間校正

### Data 參數(加密前的 Json 格式)

| 欄位名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| MerchantID | String | 10 | 是 | 特店編號 |
| InvoiceNo | String | 10 | 是 | 發票號碼(固定 10 碼) |
| AllowanceNo | String | 16 | 是 | 折讓編號 |
| Reason | String | 20 | 是 | 作廢折讓原因 |

## 特店傳入參數範例

```json
{
    "MerchantID": "2000132",
    "RqHeader": {
        "Timestamp": 1525168923
    },
    "Data": "加密資料"
}
```

## Data 參數範例(加密前)

```json
{
    "MerchantID": 2000132,
    "InvoiceNo": "AA123456",
    "AllowanceNo": "2016022615195209",
    "Reason": ""
}
```

**加密步驟**：
1. 將 Json 字串進行 urlencode
2. 進行 AES 加密

## 綠界回傳參數(Json 格式)

### 頂層回傳參數

| 欄位名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| PlatformID | String | 10 | 特約合作平台商代號 |
| MerchantID | String | 10 | 特店編號 |
| RpHeader | Object | - | 回傳資料 |
| TransCode | Int | - | 回傳代碼(1=接收成功) |
| TransMsg | String | 200 | 回傳訊息 |
| Data | String | - | 加密資料(AES 加密) |

### RpHeader 物件

| 欄位名稱 | 型別 | 說明 |
|---------|------|------|
| Timestamp | Number | 回傳時間(Unix timestamp, GMT+8) |

### TransCode 說明

| 代碼 | 說明 |
|------|------|
| 1 | API 傳輸資料接收成功(實際執行結果請參考 RtnCode) |
| 其他 | 接收失敗 |

## 綠界回傳參數範例

```json
{
    "MerchantID": "2000132",
    "RpHeader": {
        "Timestamp": 1525169058
    },
    "TransCode": 1,
    "TransMsg": "",
    "Data": "加密資料"
}
```

## Data 回傳參數(解密後的 Json 格式)

| 欄位名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| RtnCode | Int | - | 回應代碼(1=執行成功,其餘=失敗) |
| RtnMsg | String | 200 | 回應訊息 |
| IA_Invoice_No | String | 10 | 發票號碼(成功時回傳;失敗時回傳空值) |

## Data 回傳參數範例

```json
{
    "RtnCode": "1",
    "RtnMsg": "該折讓單已作廢",
    "IA_Invoice_No": "AA123456"
}
```

**解密步驟**：
1. 將 Data 進行 AES 解密
2. 再做 urldecode

## 重要注意事項

**作廢時限限制**：
- 每年奇數月的 13 號 23:59:59 以後，因已申報至財政部，無法作廢前兩個月開立的發票折讓
- 例：3 月 14 號時，不能作廢 1、2 月所開立的發票折讓
