# 綠界 B2C 電子發票 查詢作廢折讓明細 API

## 應用場景

特店系統可使用此 API 查詢已作廢折讓明細資訊。

## API 介接網址

- **測試環境**：https://einvoice-stage.ecpay.com.tw/B2CInvoice/GetAllowanceInvalid
- **正式環境**：https://einvoice.ecpay.com.tw/B2CInvoice/GetAllowanceInvalid

## HTTPS 傳輸協定

- **Content Type**：application/json
- **HTTP Method**：POST

## 特店傳入參數 (Json 格式)

| 參數名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| PlatformID | String | 10 | 否 | 特約合作平台商代號。一般廠商請保留為空 |
| MerchantID | String | 10 | **是** | 特店編號 |
| RqHeader | Object | - | **是** | 傳入資料物件 |
| RqHeader.Timestamp | Number | - | **是** | 傳入時間（Unix TimeStamp，GMT+8）。驗證時間區間為 10 分鐘內有效 |
| Data | String | - | **是** | 加密資料（加密過的 JSON 格式） |

## 特店傳入參數範例

```json
{
  "MerchantID": "2000132",
  "RqHeader": {
    "Timestamp": 1525168923
  },
  "Data": "加密資料"
}
```

## Data 參數說明 (Json 格式)

**處理步驟**：先將 Json 字串進行 urlencode 後再進行 AES 加密

| 參數名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| MerchantID | String | 10 | **是** | 特店編號 |
| InvoiceNo | String | 10 | **是** | 發票號碼 |
| AllowanceNo | String | 16 | **是** | 折讓編號 |

## Data 參數範例

```json
{
  "MerchantID": 2000132,
  "InvoiceNo": "UV11100016",
  "AllowanceNo": "2019091719477262"
}
```

## 綠界回傳參數格式

- **Content Type**：application/json
- **HTTP Method**：POST

## 綠界回傳參數 (Json 格式)

| 參數名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| PlatformID | String | 10 | 特約合作平台商代號 |
| MerchantID | String | 10 | 特店編號 |
| RpHeader | Object | - | 回傳資料物件 |
| RpHeader.Timestamp | Number | - | 回傳時間（Unix timestamp，GMT+8） |
| TransCode | Int | - | 回傳代碼。1 代表 API 傳輸資料接收成功，實際執行結果請參考 RtnCode |
| TransMsg | String | 200 | 回傳訊息 |
| Data | String | - | 加密資料（加密過的 JSON 格式） |

## 綠界回傳參數範例

```json
{
  "MerchantID": "2000132",
  "RpHeader": {
    "Timestamp": 1525169058
  },
  "TransCode": 1,
  "TransMsg": "",
  "Data": "加密資料"
}
```

## Data 參數說明 (Json 格式)

**處理步驟**：先將 Data 進行 AES 解密後再做 urldecode

| 參數名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| RtnCode | Int | - | 回應代碼。1 代表 API 執行成功，其餘代碼均為失敗 |
| RtnMsg | String | 200 | 回應訊息 |
| AI_Allow_Date | String | 20 | 折讓單日期（格式：yyyy-MM-dd HH:mm:ss） |
| AI_Allow_No | String | 16 | 折讓單號 |
| AI_Buyer_Identifier | String | 10 | 買方統編（0000000000 代表沒有統編） |
| AI_Date | String | 20 | 作廢時間（格式：yyyy-MM-dd HH:mm:ss） |
| AI_Invoice_No | String | 10 | 發票號碼 |
| AI_Mer_ID | String | 10 | 特店代號 |
| Reason | String | 20 | 作廢原因 |
| AI_Seller_Identifier | String | 10 | 賣方統編 |
| AI_Upload_Date | String | 20 | 上傳時間（格式：yyyy-MM-dd HH:mm:ss） |
| AI_Upload_Status | String | 1 | 上傳狀態（1：已上傳；0：未上傳） |

## Data 參數範例

```json
{
  "AI_Allow_Date": "2019-09-17 19:47:19",
  "AI_Allow_No": "2019091719477262",
  "AI_Buyer_Identifier": "0000000000",
  "AI_Date": "2019-09-17 19:52:58",
  "AI_Invoice_No": "UV11100016",
  "AI_Mer_ID": "2000132",
  "Reason": "Reson",
  "AI_Seller_Identifier": "11456006",
  "AI_Upload_Date": "",
  "AI_Upload_Status": "0",
  "RtnCode": 1,
  "RtnMsg": "查詢成功"
}
```

## 加解密說明

- **Request 加密**：先將 Data 參數的 Json 字串進行 urlencode，再進行 AES 加密
- **Response 解密**：先將回傳的 Data 進行 AES 解密，再做 urldecode

詳細加密方法請參考：[參數加密方式說明](https://developers.ecpay.com.tw/7958/)

## 重要注意事項

1. 「驗證時間區間暫訂為 10 分鐘內有效，若超過此驗證時間則此次訂單將無法建立」
2. 合作特店須進行主機「時間校正」，避免主機產生時差，導致 API 無法正常運作
3. 平台商需在 MerchantID 欄位填入已綁定子廠商的特定編號，只能使用已綁定的子廠商編號
