# 綠界 B2C 電子發票 觸發開立發票 API

## 功能概述

營業人(特店)可預先暫存發票參數至綠界，待消費者付款完成後，再觸發開立暫存的發票資料。系統會依設定的延遲開立天數自動上傳財政部並通知消費者。

## 使用流程

- **觸發開立發票**：付款完成後呼叫 API 觸發先前暫存的發票參數
- **觸發後延遲開立**：根據預先設定的延遲開立天數，系統自動在指定時間開立

## API 端點

| 環境 | 網址 |
|------|------|
| 測試 | `https://einvoice-stage.ecpay.com.tw/B2CInvoice/TriggerIssue` |
| 正式 | `https://einvoice.ecpay.com.tw/B2CInvoice/TriggerIssue` |

## 傳輸設定

- **Content Type**：application/json
- **HTTP Method**：POST
- **協定**：HTTPS

## 請求參數 (JSON)

| 欄位 | 型別 | 長度 | 必填 | 說明 |
|------|------|------|------|------|
| MerchantID | String | 10 | ✓ | 特店編號 |
| RqHeader | Object | - | ✓ | 傳入資料 |
| RqHeader.Timestamp | Number | - | ✓ | 傳入時間(Unix TimeStamp, GMT+8) |
| Data | String | - | ✓ | 加密資料(AES加密) |
| PlatformID | String | 10 | - | 特約合作平台商代號(保留為空或填入) |

### Data 參數說明 (加密前 JSON)

需先進行 URLencode，再進行 AES 加密

| 欄位 | 型別 | 長度 | 必填 | 說明 |
|------|------|------|------|------|
| MerchantID | String | 10 | ✓ | 特店編號 |
| Tsr | String | 30 | ✓ | 交易單號(唯一值，不可重複) |
| PayType | String | 1 | ✓ | 交易類別(固定帶'2') |

### 請求範例

```json
{
  "MerchantID": "2000132",
  "RqHeader": {
    "Timestamp": 1525168923
  },
  "Data": "加密資料"
}
```

### Data 加密前內容範例

```json
{
  "MerchantID": "2000132",
  "Tsr": "201909170001",
  "PayType": "2"
}
```

## 回傳參數 (JSON)

| 欄位 | 型別 | 長度 | 說明 |
|------|------|------|------|
| MerchantID | String | 10 | 特店編號 |
| RpHeader | Object | - | 回傳資料 |
| RpHeader.Timestamp | Number | - | 回傳時間(Unix timestamp, GMT+8) |
| TransCode | Int | - | 回傳代碼(1=傳輸成功，請參考 RtnCode) |
| TransMsg | String | 200 | 回傳訊息 |
| Data | String | - | 加密資料(AES加密) |
| PlatformID | String | 10 | 特約合作平台商代號 |

### Data 參數說明 (解密後 JSON)

需先進行 AES 解密，再進行 URLdecode

| 欄位 | 型別 | 長度 | 說明 |
|------|------|------|------|
| RtnCode | Int | - | 回應代碼：4000003(延後開立成功)；4000004(開立發票成功)；其他為失敗 |
| RtnMsg | String | 200 | 回應訊息 |
| Tsr | String | 20 | 交易單號(成功時回傳；失敗時為空值) |

### 回傳範例

```json
{
  "MerchantID": "2000132",
  "RpHeader": {
    "Timestamp": 1525169058
  },
  "TransCode": 1,
  "TransMsg": "",
  "Data": "加密資料"
}
```

### Data 解密後範例

```json
{
  "RtnCode": 4000003,
  "RtnMsg": "延後開立成功",
  "Tsr": "201909170001"
}
```

## 重要注意事項

- 使用此 API 前需先呼叫暫存開立發票 API，且延遲註記欄位為 2(觸發開立)
- 驗證時間區間為 10 分鐘內有效
- 合作特店需進行主機時間校正，避免時差問題
- 當 DelayDay > 0 時，RtnCode 為 4000003 代表延後開立成功
- 當 DelayDay = 0 時，RtnCode 為 4000004 代表開立發票成功

## 加密相關說明

- 加密方法：AES
- 加密前步驟：先將 JSON 字串進行 URLencode，再進行 AES 加密
- 解密後步驟：先進行 AES 解密，再進行 URLdecode
