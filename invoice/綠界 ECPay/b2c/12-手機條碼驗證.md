# 綠界 B2C 電子發票 手機條碼驗證 API

## 應用場景

特店系統可使用此 API 驗證手機條碼的有效性。

## 重要注意事項

1. **驗證輔助性質**：「若載具編號為手機條碼載具時，可先呼叫手機條碼驗證API進行檢核」，但建議勿作為開立發票前的唯一驗證機制，因財政部系統可能進行不預期維護。

2. **系統依賴**：本 API 調用財政部系統進行驗證，財政部維護作業會影響 API 穩定性。

## API 連線資訊

| 環境 | 網址 |
|------|------|
| 測試 | `https://einvoice-stage.ecpay.com.tw/B2CInvoice/CheckBarcode` |
| 正式 | `https://einvoice.ecpay.com.tw/B2CInvoice/CheckBarcode` |

- **Content Type**：application/json
- **HTTP Method**：POST

## 請求參數（JSON 格式）

### 最外層結構

| 欄位名 | 型別 | 長度 | 必填 | 說明 |
|--------|------|------|------|------|
| PlatformID | String | 10 | 否 | 特約合作平台商代號，一般廠商留空 |
| MerchantID | String | 10 | **是** | 特店編號 |
| RqHeader | Object | - | **是** | 傳入資料容器 |
| Data | String | - | **是** | 加密資料（AES 加密之 JSON） |

### RqHeader 物件

| 欄位名 | 型別 | 必填 | 說明 |
|--------|------|------|------|
| Timestamp | Number | **是** | 傳輸時間戳（GMT+8），Unix TimeStamp 格式 |

**時間驗證**：驗證時間區間為 10 分鐘內有效，超過則訂單無法建立。建議進行主機時間校正。

### Data 參數內容（解密後 JSON）

| 欄位名 | 型別 | 長度 | 必填 | 說明 |
|--------|------|------|------|------|
| MerchantID | String | 10 | **是** | 特店編號 |
| BarCode | String | 8 | **是** | 手機條碼 |

**BarCode 格式規則**：
- 必須為 8 碼字元
- 第 1 碼固定為「/」
- 其餘 7 碼由數字（0-9）、大寫英文（A-Z）、特殊符號（+、-、.）組成
- 僅接受半形字元

## 請求參數範例

### 最外層 JSON

```json
{
    "MerchantID": "2000132",
    "RqHeader": {
        "Timestamp": 1525168923
    },
    "Data": "加密資料"
}
```

### Data 解密後內容

```json
{
    "MerchantID": 2000132,
    "BarCode": "/1234567"
}
```

## 回應參數（JSON 格式）

### 最外層結構

| 欄位名 | 型別 | 長度 | 說明 |
|--------|------|------|------|
| PlatformID | String | 10 | 特約合作平台商代號 |
| MerchantID | String | 10 | 特店編號 |
| RpHeader | Object | - | 回傳資料容器 |
| TransCode | Int | - | 傳輸代碼（1=接收成功，其餘=失敗） |
| TransMsg | String | 200 | 傳輸訊息 |
| Data | String | - | 加密回傳資料（AES 加密之 JSON） |

### RpHeader 物件

| 欄位名 | 型別 | 說明 |
|--------|------|------|
| Timestamp | Number | 回傳時間戳（Unix timestamp，GMT+8） |

### Data 解密後內容

| 欄位名 | 型別 | 長度 | 說明 |
|--------|------|------|------|
| RtnCode | Int | - | 回應代碼（1=成功，其他=失敗） |
| RtnMsg | String | 200 | 回應訊息 |
| IsExist | String | 1 | 手機條碼存在狀態（Y=存在，N=不存在） |

**RtnCode 說明**：
- **1**：API 執行成功（需檢查 IsExist 判斷條碼是否存在）
- **9000001**：呼叫財政部 API 失敗（財政部系統維護中，請稍後重試）

**IsExist 判斷**：需在 RtnCode 為 1 時才具參考價值

## 回應參數範例

### 最外層 JSON

```json
{
    "MerchantID": "2000132",
    "RpHeader": {
        "Timestamp": 1525169058
    },
    "TransCode": 1,
    "TransMsg": "",
    "Data": "加密資料"
}
```

### Data 解密後內容

```json
{
    "RtnCode": 1,
    "RtnMsg": "",
    "IsExist": "Y"
}
```

## 加密/解密說明

- **加密方向**：Data 參數需先進行 URL encode，再使用 AES 加密
- **解密方向**：回傳 Data 參數需先進行 AES 解密，再進行 URL decode
- 詳細加密方法請參考：[參數加密方式說明](https://developers.ecpay.com.tw/?p=7958)
