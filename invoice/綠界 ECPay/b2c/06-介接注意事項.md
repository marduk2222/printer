# 綠界 B2C 電子發票 介接注意事項

## 呼叫綠界API

### 重要注意事項

以下是特店系統開發人員在接收傳送綠界科技API通知時需確認的事項：

- **服務申請**：使用電子發票服務需與綠界提出申請

- **防火牆設定**：確認特店伺服器防火牆已開通，避免回傳通知被阻擋

- **連線協定**：
  - 僅提供 HTTPS（443 port）連線方式
  - 使用合法DNS進行介接
  - 特店伺服器需開放 HTTP 80 port 與 HTTPS 443 port

- **交易參數**：確認各項交易參數以 HTTP POST 方式傳送至綠界API

- **金鑰安全**：勿將 HashKey、HashIV 等金鑰資訊存放於前端網頁（Javascript、HTML、CSS等）

- **網址編碼**：回傳網址不支援中文，須使用 punycode 編碼（例：中文.tw 改為 xn--fiq228c.tw）

- **加密通訊**：支援 TLS 1.2 加密通訊協定

- **列印需求**：
  - 超商KIOSK事務機列印需向業務申請
  - 自行列印電子發票需申請密碼種子

- **主機連線**（因IP不固定，建議以FQDN設定）：
  - einvoice.ecpay.com.tw TCP 443（正式環境）
  - einvoice-stage.ecpay.com.tw TCP 443（測試環境）

- **API呼叫速度**：過快會收到 HTTP Status Code 403，需降速並等候30分鐘後重試

- **HTTP Status Code 500**：可能原因為資料格式錯誤、MerchantID與Key/IV不匹配或加解密錯誤
