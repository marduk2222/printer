# 綠界 B2C 電子發票 發送發票通知 API

## 應用場景

此 API 適用於以下情境：

**情景一**：廠商後台發票通知方式設定中，通知選項未開啟時，可透過本 API 完全處理電子發票各類通知。

**情景二**：通知失敗需要補送，可使用此 API 來補送各類發票通知。

## 重要注意事項

- 測試環境下，綠界不會主動發送任何通知
- 串接本 API 時，務必於廠商後台將通知選項設為「不要開啟」，否則會收到重複通知
- 綠界系統於奇數月份 29 號核對中獎發票

## API 介接網址

| 環境 | URL |
|------|-----|
| 測試環境 | `https://einvoice-stage.ecpay.com.tw/B2CInvoice/InvoiceNotify` |
| 正式環境 | `https://einvoice.ecpay.com.tw/B2CInvoice/InvoiceNotify` |

## HTTPS 傳輸協定

- **Content Type**：`application/json`
- **HTTP Method**：`POST`

## 特店傳入參數（JSON 格式）

| 欄位 | 型別 | 長度 | 必填 | 說明 |
|------|------|------|------|------|
| PlatformID | String | 10 | 否 | 特約合作平台商代號，僅供簽約平台商使用；一般廠商保留為空 |
| MerchantID | String | 10 | **是** | 特店編號 |
| RqHeader | Object | - | **是** | 傳入資料物件 |
| RqHeader.Timestamp | Number | - | **是** | 傳輸時間（Unix TimeStamp，GMT+8）；驗證時間區間為 10 分鐘內有效 |
| Data | String | - | **是** | AES 加密的 JSON 資料 |

## 特店傳入參數範例

```json
{
  "MerchantID": "2000132",
  "RqHeader": {
    "Timestamp": 1525168923
  },
  "Data": "加密資料"
}
```

## Data 參數說明（JSON 格式）

**前置作業**：先將 JSON 字串進行 URL encode，再進行 AES 加密

| 欄位 | 型別 | 長度 | 必填 | 說明 |
|------|------|------|------|------|
| MerchantID | String | 10 | **是** | 特店編號 |
| InvoiceNo | String | 10 | **是** | 發票號碼（固定 10 碼） |
| AllowanceNo | String | 16 | 條件 | 折讓編號；當 InvoiceTag 為 A、AI 或 OA 時為必填 |
| Phone | String | 20 | 條件 | 發送簡訊號碼（數字格式）；與 NotifyMail 擇一選填 |
| NotifyMail | String | 200 | 條件 | 發送電子郵件；與 Phone 擇一選填；可填多組 Email 以分號區隔（如：aa@aa.aa;bb@bb.bb） |
| Notify | String | 1 | **是** | 發送方式：S（簡訊）、E（電子郵件）、A（皆通知）；當 InvoiceTag=OA 時限填 E |
| InvoiceTag | String | 2 | **是** | 發送內容類型：I（發票開立）、II（發票作廢）、A（折讓開立）、AI（折讓作廢）、AW（發票中獎）、OA（線上折讓） |
| Notified | String | 1 | **是** | 發送對象：C（客戶）、M（特店）、A（皆發送）；當 InvoiceTag=OA 時限填 C |

## Data 參數範例

```json
{
  "MerchantID": 2000132,
  "InvoiceNo": "UV11100016",
  "AllowanceNo": "2019091719477262",
  "Phone": "0912345678",
  "NotifyMail": "test@ecpay.com.tw",
  "Notify": "E",
  "InvoiceTag": "I",
  "Notified": "A"
}
```

## 綠界回傳參數（JSON 格式）

| 欄位 | 型別 | 長度 | 說明 |
|------|------|------|------|
| PlatformID | String | 10 | 特約合作平台商代號 |
| MerchantID | String | 10 | 特店編號 |
| RpHeader | Object | - | 回傳資料物件 |
| RpHeader.Timestamp | Number | - | 回傳時間（Unix TimeStamp，GMT+8） |
| TransCode | Int | - | 回傳代碼：1 表示傳輸成功；實際執行結果請參考 RtnCode |
| TransMsg | String | 200 | 回傳訊息 |
| Data | String | - | AES 加密的 JSON 回傳資料 |

## 綠界回傳參數範例

```json
{
  "MerchantID": "2000132",
  "RpHeader": {
    "Timestamp": 1525169058
  },
  "TransCode": 1,
  "TransMsg": "",
  "Data": "加密資料"
}
```

## Data 參數說明（回傳資料）

**前置作業**：先將 Data 進行 AES 解密，再做 URL decode

| 欄位 | 型別 | 長度 | 說明 |
|------|------|------|------|
| RtnCode | Int | - | 回應代碼：1 代表 API 執行成功；其餘代碼均為失敗 |
| RtnMsg | String | 200 | 回應訊息 |
| MerchantID | String | 10 | 特店編號 |

## Data 參數範例（回傳）

```json
{
  "MerchantID": 2000132,
  "RtnMsg": "發送通知成功",
  "RtnCode": 1
}
```
