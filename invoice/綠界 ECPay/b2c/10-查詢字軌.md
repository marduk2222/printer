# 綠界 B2C 電子發票查詢字軌 API

## 應用場景
特店系統可使用此 API 查詢字軌號碼以及字軌的使用情況

## API 介接網址

| 環境 | URL |
|------|-----|
| 測試環境 | https://einvoice-stage.ecpay.com.tw/B2CInvoice/GetInvoiceWordSetting |
| 正式環境 | https://einvoice.ecpay.com.tw/B2CInvoice/GetInvoiceWordSetting |

## HTTPS 傳輸協定
- **Content Type**: application/json
- **HTTP Method**: POST

## 特店傳入參數 (Json 格式)

### 必填參數

| 參數 | 型別 | 長度 | 說明 |
|------|------|------|------|
| MerchantID | String | 10 | 特店編號 (必填) |
| RqHeader | Object | - | 傳入資料 (必填) |
| Data | String | - | 加密資料 (必填) |

### 選填參數

| 參數 | 型別 | 長度 | 說明 |
|------|------|------|------|
| PlatformID | String | 10 | 特約合作平台商代號，一般廠商留空 |

### RqHeader 物件

| 參數 | 型別 | 說明 |
|------|------|------|
| Timestamp | Number | 傳入時間 (必填)，Unix TimeStamp (GMT+8)，驗證時間區間為 10 分鐘內有效 |

### 特店傳入參數範例

```json
{
  "MerchantID": "2000132",
  "RqHeader": {
    "Timestamp": 1525168923
  },
  "Data": "加密資料"
}
```

## Data 參數說明 (Json 格式)

**注意**: 請先將 Json 字串進行 urlencode 後再進行 AES 加密

| 參數 | 型別 | 長度 | 必填 | 說明 |
|------|------|------|------|------|
| MerchantID | String | 10 | 是 | 特店編號 |
| InvoiceYear | String | 3 | 是 | 發票年度，格式為民國年 (ex: 109)，僅可查詢去年、當年與明年 |
| InvoiceTerm | Int | - | 是 | 發票期別：0(全部)、1(1-2月)、2(3-4月)、3(5-6月)、4(7-8月)、5(9-10月)、6(11-12月) |
| UseStatus | Int | - | 是 | 字軌使用狀態：0(全部)、1(未啟用)、2(使用中)、3(已停用)、4(暫停中)、5(待審核)、6(審核不通過) |
| InvoiceCategory | Int | - | 是 | 發票類別：1(B2C)，請固定填寫為 1 |
| InvType | String | 2 | 否 | 字軌類別：07(一般稅額發票)、08(特種稅額發票) |
| ProductServiceId | String | 10 | 否 | 產品服務別代號，英文字母與數字組成，長度 1-10，需啟用【B2C系統多組字軌】開關 |
| InvoiceHeader | String | 2 | 否 | 字軌名稱 |

### Data 參數範例

```json
{
  "MerchantID": 2000132,
  "InvoiceTerm": 0,
  "InvoiceYear": "109",
  "UseStatus": 1,
  "InvoiceCategory": 1
}
```

## 綠界回傳參數 (Json 格式)

### 回傳格式
- **Content Type**: application/json
- **HTTP Method**: POST

### 綠界回傳參數

| 參數 | 型別 | 長度 | 說明 |
|------|------|------|------|
| PlatformID | String | 10 | 特約合作平台商代號 |
| MerchantID | String | 10 | 特店編號 |
| RpHeader | Object | - | 回傳資料 |
| TransCode | Int | - | 回傳代碼，1 代表 API 傳輸資料接收成功，實際執行結果請參考 RtnCode |
| TransMsg | String | 200 | 回傳訊息 |
| Data | String | - | 加密資料 (AES 加密的 JSON 格式) |

### RpHeader 物件

| 參數 | 型別 | 說明 |
|------|------|------|
| Timestamp | Number | 回傳時間，Unix timestamp (GMT+8) |

### 綠界回傳參數範例

```json
{
  "MerchantID": "2000132",
  "RpHeader": {
    "Timestamp": 1525169058
  },
  "TransCode": 1,
  "TransMsg": "",
  "Data": "加密資料"
}
```

## Data 參數說明 (回傳格式)

**注意**: 請先將 Data 進行 AES 解密後再做 urldecode

| 參數 | 型別 | 長度 | 說明 |
|------|------|------|------|
| RtnCode | Int | - | 回應代碼，1 代表 API 執行成功，其餘代碼均為失敗 |
| RtnMsg | String | 200 | 回應訊息 |
| InvoiceInfo | Array | - | 發票資訊陣列 |

### InvoiceInfo 物件

| 參數 | 型別 | 長度 | 說明 |
|------|------|------|------|
| TrackID | String | 10 | 字軌號碼 ID |
| InvoiceYear | String | 3 | 發票年度 |
| InvoiceTerm | Int | - | 發票期別：1(1-2月)、2(3-4月)、3(5-6月)、4(7-8月)、5(9-10月)、6(11-12月) |
| InvoiceCategory | Int | - | 發票類別：1(B2C) |
| InvType | String | 2 | 字軌類別：07(一般稅額發票)、08(特種稅額發票) |
| ProductServiceId | String | 10 | 產品服務別代號，英文字母與數字組成，長度 1-10 |
| InvoiceHeader | String | 2 | 字軌名稱 |
| InvoiceStart | String | 8 | 起始發票編號 |
| InvoiceEnd | String | 8 | 結束發票編號 |
| InvoiceNo | String | 8 | 目前已使用號碼 |
| UseStatus | Int | - | 使用狀態：1(未啟用)、2(使用中)、3(已停用)、4(暫停中)、5(待審核)、6(審核不通過) |

## 重要注意事項

1. **時間校正**: 驗證時間區間暫訂為 10 分鐘內有效，若超過此驗證時間則此次訂單將無法建立
2. **主機時間**: 合作特店須進行主機「時間校正」，避免主機產生時差
3. **平台商**: PlatformID 參數專為與綠界簽約的指定平台商設計，一般廠商請保留為空
4. **多組字軌**: ProductServiceId 參數只有在【B2C系統多組字軌】開關為【啟用】時才會進行處理
