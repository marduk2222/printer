# 綠界 B2C 電子發票 - 查詢作廢發票明細 API

## 應用場景

特店系統可使用此 API 查詢已作廢的發票資訊。

## API 介接網址

| 環境 | URL |
|------|-----|
| 測試環境 | `https://einvoice-stage.ecpay.com.tw/B2CInvoice/GetInvalid` |
| 正式環境 | `https://einvoice.ecpay.com.tw/B2CInvoice/GetInvalid` |

## HTTPS 傳輸協定

- **Content Type**: `application/json`
- **HTTP Method**: `POST`

## 特店傳入參數 (JSON 格式)

| 參數名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| PlatformID | String | 10 | 否 | 特約合作平台商代號。僅限與綠界簽約的指定平台商使用；一般廠商請保留為空 |
| MerchantID | String | 10 | **是** | 特店編號 |
| RqHeader | Object | - | **是** | 傳入資料 |
| RqHeader.Timestamp | Number | - | **是** | 傳入時間 (Unix TimeStamp, GMT+8)。驗證時間區間為 10 分鐘內有效 |
| Data | String | - | **是** | 加密資料 (加密後的 JSON 格式) |

### 特店傳入參數範例

```json
{
  "MerchantID": "2000132",
  "RqHeader": {
    "Timestamp": 1525168923
  },
  "Data": "加密資料"
}
```

## Data 參數說明 (JSON 格式)

**處理步驟**: 先將 JSON 字串進行 urlencode，再進行 AES 加密

| 參數名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| MerchantID | String | 10 | **是** | 特店編號 |
| RelateNumber | String | 50 | **是** | 特店自訂編號。需為唯一值，不可重複使用；請勿使用特殊符號 |
| InvoiceNo | String | 10 | **是** | 發票號碼 |
| InvoiceDate | String | 10 | **是** | 發票開立日期。格式為「yyyy-MM-dd」或「yyyy/MM/dd」 |

### Data 參數範例

```json
{
  "MerchantID": 2000132,
  "RelateNumber": "123456789",
  "InvoiceNo": "UV11100016",
  "InvoiceDate": "2018-10-28"
}
```

## 綠界回傳參數格式

- **Content Type**: `application/json`
- **HTTP Method**: `POST`

## 綠界回傳參數 (JSON 格式)

| 參數名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| PlatformID | String | 10 | 特約合作平台商代號 |
| MerchantID | String | 10 | 特店編號 |
| RpHeader | Object | - | 回傳資料 |
| RpHeader.Timestamp | Number | - | 回傳時間 (Unix Timestamp, GMT+8) |
| TransCode | Int | - | 回傳代碼。1 代表 API 傳輸資料接收成功；實際執行結果狀態請參考 RtnCode |
| TransMsg | String | 200 | 回傳訊息 |
| Data | String | - | 加密資料 (加密後的 JSON 格式) |

### 綠界回傳參數範例

```json
{
  "MerchantID": "2000132",
  "RpHeader": {
    "Timestamp": 1525169058
  },
  "TransCode": 1,
  "TransMsg": "",
  "Data": "加密資料"
}
```

## Data 參數說明 (回傳資料)

**處理步驟**: 先將 Data 進行 AES 解密，再做 urldecode

| 參數名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| RtnCode | Int | - | 回應代碼。1 代表 API 執行成功；其餘代碼均為失敗 |
| RtnMsg | String | 200 | 回應訊息 |
| ChannelPartner | String | 1 | 通路商編號 (1: 蝦皮) |
| IIS_Mer_ID | String | 10 | 特店編號 |
| II_Invoice_No | String | 10 | 發票號碼 |
| II_Date | String | 20 | 作廢時間 (格式: 「yyyy-MM-dd HH:mm:ss」) |
| II_Upload_Status | String | 1 | 上傳狀態 (1: 已上傳；0: 未上傳) |
| II_Upload_Date | String | 20 | 上傳時間 (格式: 「yyyy-MM-dd HH:mm:ss」) |
| Reason | String | 20 | 作廢原因 |
| II_Seller_Identifier | String | 10 | 賣方統編 |
| II_Buyer_Identifier | String | 10 | 買方統編 (0000000000 代表沒有統編) |

### Data 參數範例

```json
{
  "RtnCode": 1,
  "RtnMsg": "查詢成功",
  "ChannelPartner": "",
  "IIS_Mer_ID": "2000132",
  "II_Invoice_No": "UV11100018",
  "II_Date": "2019-09-17 20:00:50",
  "II_Upload_Status": "0",
  "II_Upload_Date": "",
  "Reason": "Invalid_Reason",
  "II_Seller_Identifier": "11456006",
  "II_Buyer_Identifier": "0000000000"
}
```
