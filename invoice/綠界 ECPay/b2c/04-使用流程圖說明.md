# 綠界 B2C 電子發票使用流程圖說明

根據頁面內容，該文件呈現三個主要流程部分：

## 1. 前置設定

頁面包含「前置設定」流程圖，說明在開立發票前需要完成的準備工作。

## 2. 開立發票

提供「開立發票」的流程圖示，展示發票開立的步驟說明。

## 3. 開立折讓 / 作廢發票 / 註銷重開

這部分涵蓋三項操作的流程：
- 開立折讓程序
- 作廢發票處理
- 註銷重開流程

## 導航結構

文件內容組織包含以下主要功能模組：
- 準備事項（測試資訊、注意事項）
- 前置作業（配號查詢、字軌設定）
- 資料驗證（統一編號、手機條碼、捐贈碼）
- 發票作業（多項開立、修改、作廢操作）
- 發票查詢（查詢各類發票明細）
- 發送通知與列印功能

該頁面作為技術文件導覽，提供了 B2C 電子發票 API 的完整流程視覺化說明。
