# 綠界 B2C 電子發票 API 簡介

## 核心功能概述

根據官方技術文件，綠界提供了一套完整的電子發票整合解決方案。該平台允許商家透過 API 介接方式，在 48 小時內將發票上傳至台灣財政部。

## 主要特點

**消費者權益方面**：消費者可利用「載具」（例如自然人憑證）儲存電子發票，「便不需列印紙本發票可直接將發票儲存於載具中」。

**商家功能**：平台支援多項操作，包括：
- 發票開立與管理
- 折讓處理
- 作廢與重開
- 發票查詢與列印
- 電子郵件或簡訊通知

## 重要提醒

文件特別說明，若開立對象為營業人且需輸入買方統一編號，使用本 B2C 規格即可，「不需要特別串接 B2B 電子發票 API 技術文件」。

## 技術支援工具

綠界提供「AI Skill 套件」供開發者使用，可整合至 Claude Code、GitHub Copilot 等開發工具，協助快速產生 API 串接程式碼。
