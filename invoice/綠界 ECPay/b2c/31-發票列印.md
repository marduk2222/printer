# 綠界 B2C 電子發票 發票列印 API

## 應用場景

特店可使用此 API 取得發票列印網址

## API 介接網址

- **測試環境**：https://einvoice-stage.ecpay.com.tw/B2CInvoice/InvoicePrint
- **正式環境**：https://einvoice.ecpay.com.tw/B2CInvoice/InvoicePrint

## HTTPS 傳輸協定

- **Content Type**：application/json
- **HTTP Method**：POST

## 特店傳入參數 (Json 格式)

| 參數名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| **PlatformID** | String | 10 | 否 | 特約合作平台商代號。專為與綠界簽約的指定平台商設計，只有申請開通後才能使用。一般廠商請保留為空。平台商需在 MerchantID 欄位填入已綁定的子廠商編號。 |
| **MerchantID** | String | 10 | 是 | 特店編號 |
| **RqHeader** | Object | - | 是 | 傳入資料 |
| **Timestamp** | Number | - | 是 | 傳入時間。將傳輸時間轉換為時間戳 (GMT+8)，綠界利用此參數驗證介接的時間區間。驗證時間區間為 10 分鐘內有效。 |
| **Data** | String | - | 是 | 加密資料 (加密過的 JSON 格式資料) |

### 特店傳入參數範例

```json
{
  "MerchantID": "2000132",
  "RqHeader": {
    "Timestamp": 1525168923
  },
  "Data": "加密資料"
}
```

## Data 參數說明 (Json 格式)

| 參數名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| **MerchantID** | String | 10 | 是 | 特店編號 |
| **InvoiceNo** | String | 10 | 是 | 發票號碼 (2 碼字軌 + 8 碼數字) |
| **InvoiceDate** | String | 20 | 是 | 發票開立日期。格式為「yyyy-MM-dd」或「yyyy/MM/dd」 |
| **PrintStyle** | Int | - | 否 | 發票列印格式。1：一般列印(單面)，預設；2：一般列印(雙面)；3：熱感應紙列印；4：B2B A4(僅限帶有統編的發票)；5：B2B A5(僅限帶有統編的發票) |
| **IsReprintInvoice** | String | 1 | 否 | 是否顯示補印發票。Y：顯示為「電子發票證明聯補印」。僅當 PrintStyle 為 1、2、3 時有效，B2B 發票格式無補印選項。如未帶此參數或 PrintStyle 為 4 或 5，一律顯示為「電子發票證明聯」。 |
| **IsShowingDetail** | Int | - | 否 | 是否顯示明細。1：顯示明細；2：隱藏明細。帶統編的發票一律顯示明細。如未帶此參數，帶統編發票預設顯示明細，不帶統編發票預設不顯示明細。PrintStyle 為 B2B A4 或 B2B A5 時一律顯示明細。 |

### Data 參數範例

```json
{
  "MerchantID": "2000132",
  "InvoiceNo": "UV11100016",
  "InvoiceDate": "2018-10-28"
}
```

## 綠界回傳參數格式

- **Content Type**：application/json
- **HTTP Method**：POST

## 綠界回傳參數 (Json 格式)

| 參數名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| **PlatformID** | String | 10 | 特約合作平台商代號 |
| **MerchantID** | String | 10 | 特店編號 |
| **RpHeader** | Object | - | 回傳資料 |
| **Timestamp** | Number | - | 回傳時間 (Unix timestamp, GMT+8) |
| **TransCode** | Int | - | 回傳代碼。1 代表 API 傳輸資料接收成功，實際執行結果狀態請參考 RtnCode |
| **TransMsg** | String | 200 | 回傳訊息 |
| **Data** | String | - | 加密資料 (加密過的 JSON 格式資料) |

### 綠界回傳參數範例

```json
{
  "MerchantID": "2000132",
  "RpHeader": {
    "Timestamp": 1525169058
  },
  "TransCode": 1,
  "TransMsg": "",
  "Data": "加密資料"
}
```

## 回傳 Data 參數說明 (Json 格式)

| 參數名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| **RtnCode** | Int | - | 回應代碼。1 代表 API 執行成功，其餘代碼均為失敗 |
| **RtnMsg** | String | 200 | 回應訊息 |
| **InvoiceHtml** | String | - | 發票列印網址。有效時間從呼叫此列印 API 開始計算 1 小時內有效 |

### 回傳 Data 參數範例

```json
{
  "RtnCode": 1,
  "RtnMsg": "成功",
  "InvoiceHtml": "https://aa.aa.aa"
}
```

## 重要注意事項

- **時間驗證**：驗證時間區間暫訂為 10 分鐘內有效，超過此驗證時間則訂單無法建立
- **時間校正**：合作特店須進行主機「時間校正」，避免主機產生時差導致 API 無法正常運作
- **加密方法**：詳見[參數加密方式說明](https://developers.ecpay.com.tw/?p=7958)
