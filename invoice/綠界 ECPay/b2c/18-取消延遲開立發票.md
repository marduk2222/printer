# 綠界 B2C 電子發票 取消延遲開立發票 API

## 功能說明

營業人（特店）可使用此功能將預約開立時間未到或尚未觸發開立之發票取消延遲開立。

## API 介接資訊

### 環境 URL
- **測試環境**：https://einvoice-stage.ecpay.com.tw/B2CInvoice/CancelDelayIssue
- **正式環境**：https://einvoice.ecpay.com.tw/B2CInvoice/CancelDelayIssue

### 傳輸協定
- **Content Type**：application/json
- **HTTP Method**：POST

## 特店傳入參數（JSON 格式）

| 欄位名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| PlatformID | String | 10 | 否 | 特約合作平台商代號。一般廠商請保留為空 |
| MerchantID | String | 10 | 是 | 特店編號 |
| RqHeader | Object | - | 是 | 傳入資料 |
| RqHeader.Timestamp | Number | - | 是 | 傳入時間（Unix TimeStamp GMT+8），驗證時間區間為 10 分鐘內有效 |
| Data | String | - | 是 | 加密資料（AES 加密的 JSON） |

### Data 參數說明

需先將 JSON 字串進行 urlencode 後再進行 AES 加密。

| 欄位名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| MerchantID | String | 10 | 是 | 特店編號 |
| Tsr | String | 30 | 是 | 交易單號（用來呼叫付款完成觸發或延遲開立發票的依據，為唯一值不可重覆使用） |

### 傳入參數範例

```json
{
  "MerchantID": "2000132",
  "RqHeader": {
    "Timestamp": 1525168923
  },
  "Data": "加密資料"
}
```

### Data 參數範例（加密前）

```json
{
  "MerchantID": "2000132",
  "Tsr": "201909170001"
}
```

## 綠界回傳參數（JSON 格式）

| 欄位名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| PlatformID | String | 10 | 特約合作平台商代號 |
| MerchantID | String | 10 | 特店編號 |
| RpHeader | Object | - | 回傳資料 |
| RpHeader.Timestamp | Number | - | 回傳時間（Unix timestamp GMT+8） |
| TransCode | Int | - | 回傳代碼。1 代表 API 傳輸資料接收成功，實際執行結果狀態請參考 RtnCode |
| TransMsg | String | 200 | 回傳訊息 |
| Data | String | - | 加密資料（AES 加密的 JSON） |

### 回傳參數範例

```json
{
  "MerchantID": "2000132",
  "RpHeader": {
    "Timestamp": 1525169058
  },
  "TransCode": 1,
  "TransMsg": "",
  "Data": "加密資料"
}
```

### Data 參數說明（解密後）

需先將 Data 進行 AES 解密後再做 urldecode。

| 欄位名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| RtnCode | Int | - | 回應代碼。1 代表 API 執行成功，其餘代碼均為失敗 |
| RtnMsg | String | 200 | 回應訊息 |

### Data 參數範例（解密後）

```json
{
  "RtnCode": "1",
  "RtnMsg": "取消開立發票成功"
}
```

## 注意事項

- 驗證時間區間為 10 分鐘內有效，超過此驗證時間則此次訂單將無法建立
- 合作特店須進行主機「時間校正」，避免主機產生時差導致 API 無法正常運作
- 加密方法說明：參考官方文件 https://developers.ecpay.com.tw/?p=7958
