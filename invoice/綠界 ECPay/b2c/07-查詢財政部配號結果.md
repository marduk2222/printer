# 綠界 B2C 電子發票 查詢財政部配號結果 API

## 應用場景

特店可透過 API 查詢財政部整合服務平台授權於綠界之發票號碼配號結果。

## API 介接網址

- **測試環境**：https://einvoice-stage.ecpay.com.tw/B2CInvoice/GetGovInvoiceWordSetting
- **正式環境**：https://einvoice.ecpay.com.tw/B2CInvoice/GetGovInvoiceWordSetting

## HTTPS 傳輸協定

- **Content Type**：application/json
- **HTTP Method**：POST

## 注意事項

1. 查無資料可能原因：取字軌號碼時未授權於綠界，或字軌尚未取號完成
2. 授權方式可參照綠界科技電子發票系統操作手冊
3. 驗證時間區間為 10 分鐘內有效
4. 合作特店須進行主機「時間校正」，避免時差導致 API 無法正常運作
5. 僅可查詢去年、當年與明年的發票年度

## 特店傳入參數 (JSON 格式)

| 參數名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| PlatformID | String | 10 | 否 | 特約合作平台商代號 |
| MerchantID | String | 10 | 是 | 特店編號 |
| RqHeader | Object | - | 是 | 傳入資料 |
| RqHeader.Timestamp | Number | - | 是 | 傳入時間（時間戳 GMT+8） |
| Data | String | - | 是 | 加密資料（AES 加密） |

### 特店傳入參數範例

```json
{
  "MerchantID": "2000132",
  "RqHeader": {
    "Timestamp": 1525168923
  },
  "Data": "加密資料"
}
```

## Data 參數說明 (JSON 格式)

*請先將 Json 字串進行 urlencode 後再進行 AES 加密*

| 參數名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| MerchantID | String | 10 | 是 | 特店編號 |
| InvoiceYear | String | 3 | 是 | 發票年度（民國年，例：110） |

### Data 參數範例

```json
{
  "MerchantID": "2000132",
  "InvoiceYear": "110"
}
```

## 綠界回傳參數格式

- **Content Type**：application/json
- **HTTP Method**：POST

## 綠界回傳參數 (JSON 格式)

| 參數名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| PlatformID | String | 10 | 特約合作平台商代號 |
| MerchantID | String | 10 | 特店編號 |
| RpHeader | Object | - | 回傳資料 |
| RpHeader.Timestamp | Number | - | 回傳時間（Unix timestamp GMT+8） |
| TransCode | Int | - | 回傳代碼（1 表示傳輸成功） |
| TransMsg | String | 200 | 回傳訊息 |
| Data | String | - | 加密資料（AES 加密） |

### 綠界回傳參數範例

```json
{
  "MerchantID": "2000132",
  "RpHeader": {
    "Timestamp": 1525169058
  },
  "TransCode": 1,
  "TransMsg": "",
  "Data": "加密資料"
}
```

## Data 參數說明 (回傳)

*請先將 Data 進行 AES 解密後再做 urldecode*

| 參數名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| RtnCode | Int | - | 回應代碼（1 表示執行成功） |
| RtnMsg | String | 200 | 回應訊息 |
| InvoiceInfo | Array | - | 發票配號結果清單 |
| InvoiceInfo.InvoiceTerm | Int | - | 發票期別（1:1-2月, 2:3-4月, 3:5-6月, 4:7-8月, 5:9-10月, 6:11-12月） |
| InvoiceInfo.InvType | String | 2 | 字軌類別（07:一般稅額發票, 08:特種稅額發票） |
| InvoiceInfo.InvoiceHeader | String | 2 | 發票字軌名稱（例：KK） |
| InvoiceInfo.InvoiceStart | String | 8 | 起始發票編號（8 碼，尾數需為 00 或 50） |
| InvoiceInfo.InvoiceEnd | String | 8 | 結束發票編號（8 碼，尾數需為 49 或 99） |
| InvoiceInfo.Number | Int | - | 申請本數（一本為 50 個發票號碼） |

### Data 參數範例 (回傳)

```json
{
  "RtnCode": 1,
  "RtnMsg": "成功",
  "InvoiceInfo": [
    {
      "InvoiceTerm": 1,
      "InvType": "07",
      "InvoiceHeader": "KK",
      "InvoiceStart": "10000000",
      "InvoiceEnd": "10000049",
      "Number": 1
    }
  ]
}
```
