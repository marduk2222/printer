# 綠界 B2C 電子發票 設定字軌號碼狀態 API

## 應用場景

營業人新增字軌後，預設狀態為已審核且未啟用。欲使用字軌必須先設定狀態將其啟用。在開立發票前，需將已新增的字軌進行狀態設定。

## API 介接網址

- **測試環境**：https://einvoice-stage.ecpay.com.tw/B2CInvoice/UpdateInvoiceWordStatus
- **正式環境**：https://einvoice.ecpay.com.tw/B2CInvoice/UpdateInvoiceWordStatus

## 傳輸協定

- **Content Type**：application/json
- **HTTP Method**：POST

## 特店傳入參數（Json 格式）

| 欄位名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| PlatformID | String | 10 | 否 | 特約合作平台商代號，一般廠商保留為空 |
| MerchantID | String | 10 | 是 | 特店編號 |
| RqHeader | Object | - | 是 | 傳入資料 |
| RqHeader.Timestamp | Number | - | 是 | 傳入時間（時間戳 GMT+8），驗證時間區間為 10 分鐘內有效 |
| Data | String | - | 是 | 加密資料（AES 加密後之 Json 格式） |

## 特店傳入參數範例

```json
{
    "MerchantID": "2000132",
    "RqHeader": {
        "Timestamp": 1525168923
    },
    "Data": "加密資料"
}
```

## Data 參數說明（Json 格式）

**須先進行 urlencode 後再進行 AES 加密**

| 欄位名稱 | 型別 | 長度 | 必填 | 說明 |
|---------|------|------|------|------|
| MerchantID | String | 10 | 是 | 特店編號 |
| TrackID | String | 10 | 是 | 字軌號碼ID（新增字軌後取得） |
| InvoiceStatus | Int | - | 是 | 發票字軌狀態：0=停用、1=暫停、2=啟用 |

## Data 參數範例

```json
{
    "MerchantID": "2000132",
    "TrackID": "1123456",
    "InvoiceStatus": 1
}
```

**注意**：狀態設定為停用時，該字軌區間無法上傳發票。

## 綠界回傳參數（Json 格式）

| 欄位名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| PlatformID | String | 10 | 特約合作平台商代號 |
| MerchantID | String | 10 | 特店編號 |
| RpHeader | Object | - | 回傳資料 |
| RpHeader.Timestamp | Number | - | 回傳時間（時間戳 GMT+8） |
| TransCode | Int | - | 回傳代碼（1=資料接收成功） |
| TransMsg | String | 200 | 回傳訊息 |
| Data | String | - | 加密資料（AES 加密後之 Json 格式） |

## 綠界回傳參數範例

```json
{
    "MerchantID": "2000132",
    "RpHeader": {
        "Timestamp": 1525169058
    },
    "TransCode": 1,
    "TransMsg": "",
    "Data": "加密資料"
}
```

## Data 解密參數說明（Json 格式）

**須先進行 AES 解密後再做 urldecode**

| 欄位名稱 | 型別 | 長度 | 說明 |
|---------|------|------|------|
| RtnCode | Int | - | 回應代碼（1=執行成功） |
| RtnMsg | String | 200 | 回應訊息 |

## Data 參數範例

```json
{
    "RtnCode": 1,
    "RtnMsg": "成功"
}
```

## 重要注意事項

- 驗證時間區間為 10 分鐘內有效，超過此時間則無法建立
- 合作特店須進行主機「時間校正」，避免時差導致 API 無法正常運作
- 時間戳轉換參考：http://www.epochconverter.com/
